## 视频号

**标题**：为什么一到深夜就 emo？不是你矫情

**文案**：深夜的难过不全是“终于说出了真心话”。研究发现，一整夜没睡的人看负面图片时，杏仁核的反应比睡够的人高 60% 以上，与前额叶的连接变弱（Yoo 等，Current Biology，2007）；也有研究者提出“午夜后的大脑”假说：人的积极情绪在凌晨 1–4 点最低，更容易往坏处想（Tubbs 等，2022，属于假说）。再加上夜里没有消息、没有待办，白天压下去的事会排着队回来。一个小办法：凌晨想发的，先存草稿，早上再决定。

**话题**：#情绪 #睡眠 #心理学
