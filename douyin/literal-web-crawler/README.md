## 出处（不上屏、不进发布文案）

- 项目：adampog/literal-web-crawler（MIT）https://github.com/adampog/literal-web-crawler ；在线 demo https://adampog.github.io/literal-web-crawler/ 。片中录屏是用户自己录的这个公开 demo。
- 事实（项目 README + demo 页面，2026-10-21 核对）：交替四足步态（四条走、四条抓稳）、三段腿 IK、撕下碎片的物理效果、`core/crawler.js` 是无依赖的纯脚本；demo 控件 Roam / Follow cursor、Rip、Size（0.6–2）、Pause、Repair page、Use your own page；Omarchy（Linux）插件可抓取屏幕快照、可替换屏保。

## 和脚本不一样的地方

- 口播逐字照脚本，只把结尾“短片——这才叫”的破折号换成逗号（读音停顿一样）。成片 46.1 秒，比脚本估的 40 秒略长（脚本按每秒约 6 字估，本人音色约 5 字/秒），没删句子。
- 录屏标签放在右下角（仓库规定的外部画面位置），文字照脚本用「网页演示录屏」，不写作者账号；项目链接只在上面的出处里。
- 特写不是固定裁切，而是按追踪出来的蜘蛛位置跟拍；两段 0.5× 慢放做了补帧，避免 12.5 fps 的卡顿。
- 镜头 4 的“鼠标光圈”：录屏里没有录到光标，琥珀圈画在蜘蛛 0.6 秒后要到的位置，表示它在追的方向。
- 镜头 5 在“小到像只蚂蚁”时切到缩小后的那段（源 36.4 秒），镜头 6 在“点一下修复”时切到点击那一刻，让画面和口播对上。
- 录屏里贴进去的文字带 `https://example.com`、`https://douyin.com` 字样（示例地址），字很小，没有遮。
