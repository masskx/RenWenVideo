## 抖音

**标题**：AI说好让他少干活，结果8月一个月427次贡献

**文案**：一位技术副总裁翻了自己的 GitHub：2026 年 8 月 427 次贡献，是他 2019 年以来最多的一个月——而他现在本该是写代码最少的人。他说累的不是哪件事更难，而是同时开着好几个 agent，每个都“有时”需要他；写代码便宜了，他就给自己接了多得多的活。今年已经三轮“猛干—累到不想再开 agent”。他不反对 AI，只是发现：能做的更多，总会变成做得更多。（据作者本人文章，个人数据）
