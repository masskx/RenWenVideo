## 小红书

**标题**：AI组队挑战P vs NP｜Lean检查器怎么判AI写的证明

**正文**：
- P vs NP 在问什么：答案好验的问题，是不是也一定好找？（找路线 vs 验路线）
- 这个实验怎么分工：想思路的 AI、专门找反例的 AI（红队）、把步骤写成 Lean 证明的 AI
- 裁判只有一个：Lean 检查器，只接受恰好证明登记命题、没有缺口和额外公理的证明
- 现状：看板显示有小命题通过，主问题仍然开放
