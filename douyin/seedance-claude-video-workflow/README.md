## 抖音

**标题**：AI视频里杯子自己变大？问题在生成之前

**文案**：一篇 AI 拍片长文的做法：Claude 当导演，写分镜、写所有提示词、检查每张图；Codex 画设定图和每个镜头的首尾帧；Seedance 把首尾帧变成几秒钟的视频；人负责选方向、批准花钱、看动态、听声音。关键在生成之前——中间的画面由模型补，首尾帧里不一样的东西，视频里就会慢慢变：杯子大一点，视频里杯子就慢慢变大；墙色不同，墙就慢慢变色。所以提交前把首尾帧叠起来看。导演这边还开了四个 agent：主做、审核、监督、代理，审核只挑错、写下“通过”才提交。生成后每个镜头取多张全分辨率帧，切点前后各取 3 帧；动态手感和声音，模型查不了，交给人。（据原作者长文整理；咖啡广告为网友案例展示）
