# 个人信息大扫除 · 提示词包（5 条 + 自查清单）

> 视频结尾说的「资料包」就是这份。只查、只删**你自己**的信息；所有操作只走官方渠道，验证码不给任何人。入口和路径核实于 2026-10-21，App 改版后以 App 内为准。

## 四步总流程

① **查**：一证通查（互联网账号）+ 云闪付「一键查卡」 → ② **排**：把结果和记得的 App 丢给 AI，分三类、排风险 → ③ **删**：注销前先问 AI 要清什么；没有注销入口就按个保法第 47 条申请删除 → ④ **投诉**：平台不理，12321 投诉选「账号注销难」

## 自查入口

| 工具 | 能查什么 | 入口 |
|---|---|---|
| 一证通查 · 互联网账号 | 本人手机号关联了多少个 App 账号（覆盖微信、支付宝、抖音、美团、京东、小红书、拼多多等 25 款）；48 小时内由 10699000 短信回复，**只给数量**，明细去各平台查 | 微信搜「工信微报」→ 服务 → 政务服务 → 一证通查 → 选「互联网账号」，填姓名、身份证后六位、手机号、验证码；也可用「国务院客户端」「国家政务服务平台」小程序、支付宝「一证通查」小程序 |
| 一证通查 · 电话卡 | 本人名下有几张手机卡 | 同上，选「电话卡」；或带身份证去运营商营业厅 |
| 云闪付「一键查卡」 | 本人名下各银行的银行卡（数量、银行、借记 / 贷记、脱敏卡号）；24 小时内出报告，7 天可查一次 | 云闪付 App 首页搜「一键查卡」→ 人脸 + 短信验证。**只在云闪付 App 内**，别的渠道说帮你查卡的都是骗子 |

## 提示词（任何大模型都行；方括号换成你自己的内容）

### P1 账号盘点清单

```
我要做一次个人账号大扫除。下面是我能想起来的注册过的App/网站、一证通查短信结果（只有数量）、以及我手机里装过的App列表：
[粘贴]
请：1）按「在用/半年没用/完全不记得」分三类做成表格；2）每个标出风险高低（是否绑了银行卡、实名、存了地址）；3）给出处理建议：保留并加固 / 解绑手机号 / 注销；4）按优先级排序，高风险的排前面。
```

### P2 注销前检查 + 彻底删除

```
我想注销【平台名】账号，要求是数据真的删除，不只是停用。请告诉我：1）注销前要先处理什么（余额、绑定的支付、第三方授权、会员自动续费、我是管理员的群/店铺）；2）该平台一般的注销入口路径（提示我以App内为准）；3）冷静期是多久、期间不要做什么；4）注销后还可能保留哪些数据、依据什么。
```

### P3 删除个人信息申请函（个保法）

```
帮我写一封给【公司/平台名】的个人信息删除申请，依据《个人信息保护法》第四十七条和第五十条。我的情况：【账号已不用/我撤回同意/它在没必要的情况下还保存我的信息】。要求：语气正式克制；写明需要删除的信息范围；说明我可以配合身份核验（不要在函里直接写身份证号全号）；请对方在合理期限内书面答复，如拒绝请说明理由；控制在400字内。
```

### P4 隐私政策审查

```
下面是【App名】的隐私政策全文：[粘贴]
请用大白话告诉我：1）它收集了我哪些信息，哪些是非必要的；2）会共享给谁；3）保存多久；4）在哪里、用什么方式能申请查阅/删除/注销；5）有没有我应该马上去设置里关掉的选项。
```

### P5 自己公开信息的脱敏自查

```
下面是我自己的朋友圈/主页简介/最近发布内容的文字和截图描述：[粘贴，只放我自己的]
请帮我找出可能暴露我隐私的点（真实全名、手机号、住址/小区、单位、学校、车牌、快递单、定位、孩子信息、作息规律），每条给出风险等级和改法（删掉/打码/设为仅自己可见）。
```

## 法律依据和投诉

- 《个人信息保护法》第四十七条：处理目的已实现或不再必要、停止提供服务、你撤回同意、违法违约处理等情形下，平台应当主动删除；平台未删除的，个人有权请求删除。
- 第五十条：平台应当建立便捷的申请受理和处理机制；拒绝的，应当说明理由；被拒绝可以依法向人民法院起诉。法律没有写固定的答复天数，申请函写「请在合理期限内书面答复」，不要写「法定 30 天」。
- 12321 举报受理中心：www.12321.cn → 投诉；或公众号「12321受理中心」→ 我要投诉；咨询电话 010-12321。类型可选「账号注销难」「未提供更正或删除个人信息功能」等。

## 以后少留痕

- 不用主手机号注册不常用的小 App；少用「手机号一键登录」。
- 每半年用一证通查复查一次。
- 在各 App 设置里关掉「通过手机号搜索到我」「通讯录匹配」等选项。
