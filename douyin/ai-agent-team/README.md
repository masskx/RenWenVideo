## 作品描述

还在一个窗口查资料、另一个窗口写稿、自己复制粘贴？
把 4 个 agent 拉进一个群：调研员找数据、文案写字、开发建站、审核员挑刺。群规里写清每个 agent 管什么、输入从哪来、做完交接给谁，最后一句留给自己：我说 ship it 之前，什么都不许上线。
审核员两次拦下上线，连一个引错的词都没放过；人只在最后拍板。群规模板见置顶评论 👇

## 置顶评论（群规模板，按原文改写）

```
群规（第一条消息发）：
@趋势调研员 —— 你管调研。只用我贴的数据，拿不准的标 UNCONFIRMED。做完交接给 @文案
@文案 —— 页面上每个字归你。照调研报告写，不要从零编。需求太弱就先说。做完交接给 @网页开发
@网页开发 —— 你管网站。只用最新文案，动手前先发方案；每次改动都说明改了什么
@审核编辑 —— 你管质量。逐条核对说法、提示词和链接，有弱的、错的、过时的就顶回去
我说 “ship it” 之前，什么都不许上线。

原文的 3 条教训：
① 第一条消息就给真数据（不然调研会去网上找，得重做）
② 一开工就关掉 Agent Proactivity（开着时中途纠正一句，会再起一条链）
③ 给审核员一个终点：“线上终审，5 行内给 PASS 或 FAIL”
```
