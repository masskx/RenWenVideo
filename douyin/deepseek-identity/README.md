DeepSeek 连问 5 次都说“我是 ChatGPT”，评论区说实锤蒸馏？先别急：
1️⃣ 反过来也有：今年 2 月 Claude 用中文问，会说自己是 DeepSeek

3️⃣ 原理：模型叫自己什么靠系统提示；不给提示，就按网上最常见的说法答
4️⃣ 网友复现对不上：中文问多数说 DeepSeek，英文直调才常说 ChatGPT（网友自测，条件未公开）
结论：蒸馏争议一直有，但“自称”证明不了模型怎么来的。
