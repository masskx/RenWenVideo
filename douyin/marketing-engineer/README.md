## 旁白稿

**开场**

- 下一个最值钱的岗位，可能叫营销工程师
- 一个人，带着一群AI Agent
- 做营销实验的速度，是传统团队的上百倍

**引子**

- 广告狂人时代，一年只有几次出手机会
- 搜索广告出现后，每次点击都能算清
- 增长黑客时代，每个点子都要排队等工程师
- 现在，提想法的人自己就能做出来
- 营销的单位，从一次活动变成一套系统

> 原文金句：谁跑的好实验最多，谁就学得最快；谁学得最快，谁就赢。

**第1步 · 搭好你的工作台**

- 第一步，准备一个Agent工作台
- Claude Code、Codex、Cursor都行
- 把它当成住在文件夹里的高速实习生
- 再用MCP把CRM、收款、文档接进来
- 让它每周一早上自动开工
- 但对外发送前，一定要等你点头

**第2步 · 先给AI写一个大脑**

- 最常见的失败：一上来就开十个Agent
- 结果收获一堆千篇一律的废话
- 先建一个文件夹，像给新员工做入职培训
- 写清公司做什么、卖给谁、能承诺什么
- 品牌语气别写形容词，直接贴好坏样例
- 再写下创始人观点和踩过的坑

> 原文金句：Agent 没问题，问题是上下文太薄。

**第3步 · 每个活动一个编号**

- 接通通话录音、工单、成交和收入数据
- 一开始全部只读，写权限要慢慢挣
- 最关键的一件小事：每个活动一个编号
- 广告、链接、邮件、成交记录都带上它
- 才能算清：哪次营销带来了真付钱的客户

**第4步 · 先做客户语言Agent**

- 先把一个Agent做好，再做第二个
- 第一个，专门读客户原话
- 把最近20到50通销售录音交给它
- 第一版大概七成准，错了就改指令
- 比如客户总说：受够了吃饭时接电话
- 这句话，就是你的广告标题

> 原文金句：人们买的是那个场景，而不是功能。

**第5步 · 再加五个Agent**

- 稳定之后，一次只加一个
- 触发Agent：盯住刚开新店、刚融资的客户
- 搜索Agent：为买前问题做最有用的页面
- 创意Agent：换卖点，而不是换五十个标题
- 丢单Agent：客户要的功能上线就去提醒
- 效果Agent：每周一给出保留或砍掉的结论

**第6步 · 护栏写进工具里**

- 别指望提示词里那句“先问我”
- 真正的护栏，要写进工具权限
- 外联Agent只能存草稿，广告默认暂停
- 预算上限、黑名单这类硬规则交给代码
- 合不合适这种判断，才交给模型

> 原文金句：「发之前先问我」，对模型来说只是一句礼貌的建议。

**第7步 · 跑通一个完整活动**

- 比如一家记账公司想接电商客户
- 周一，报告发现店主总在问同一句话
- 扣掉退货和运费，我到底赚没赚钱？
- 周二，各个Agent用这句原话出广告和页面
- 周三，你一次审完，砍掉夸大的广告
- 两周后，计算器页面转化最好

**第8步 · 每周跑一遍循环**

- 系统搭好后，你的工作更像编辑
- 周一看备忘录做取舍，周四去听销售和客服
- 每次否掉一个东西，写下原因放回大脑
- 给每个Agent留十个样例，改完就重测

> 原文金句：如果你整天都在修Agent的输出，问题出在上游。

**结尾**

- 做市场的，先用20通录音做客户语言Agent
- 做工程的，先旁听5通销售电话
- 做老板的，花两小时写下你的观点
- 觉得有用，收藏起来，转给做营销的朋友
