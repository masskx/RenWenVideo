## 作品简介（可直接填进报名表）

1930 年底，红军在龙冈缴获了第一部电台——发报机已经坏了，只能收、不能发，史称“半部电台”。本片以这部电台为线索，把红色通信史讲成一条“电波”：1931 年红军第一支无线电队靠它监听敌台；1940 年延安王皮湾窑洞里，新华广播电台第一次播音，从“只能听”到“能说”；1950 年陕甘两省邮电人员训练班成立，这是西安邮电大学的前身；新时代，网络强国、北斗三号、525.4 万座 5G 基站，把这条电波连到了每个人身边。片尾，我们用真实的四位中文电码发出“请党放心，强国有我”，半部电台的另一半随之补完——当年他们只能听，今天轮到我们发报。

作为邮电院校的学生，我们心中理想的思政课，就从自己专业的历史讲起：AI 能帮我们把画面复原出来，但讲哪段历史、为什么讲，由我们自己决定。
