## 抖音

**标题**：只改0.016%权重，正确率7.9%跳到48.1%？

**文案**：MIT CSAIL 的一篇博客说：让 GPT-6 Astra 直接改小模型 Qwen3.5-0.8B 的 0.016% 权重、不训练，MATH-500 从 7.9% 涨到 48.1%。但它不是教会了数学——原来的模型 96 道练习里 85 道想到停不下来、撞上 token 上限；Astra 减掉第 15、19 层里的一个方向，撞上限从 93% 降到 33%。同样的办法用在很少打转的 Gemma 上，几乎没涨。博客未经同行评审，数字均为作者自报。

## 视频号

**标题**：只改 0.016% 的权重，正确率从 7.9% 跳到 48.1%？它修的是“死循环”

**文案**：11 月 2 日，MIT CSAIL 四位作者发布博客《Sparks of Weight-Space Programming》，称前沿模型可以直接读写另一个神经网络的权重。最受关注的结果：Astra 在 Python 环境里、不用梯度和训练，改了 Qwen3.5-0.8B 约 0.016% 的权重（131,072 个），MATH-500 从 7.9% 到 48.1%。作者解释，原模型开思考时大量陷入循环（前 96 道练习里 85 道撞上 32,768 token 上限），Astra 找到第 15、19 层的一个方向并减去，撞上限比例从 93.0% 降到 33.1%。同一方法在 Gemma 3 270M 上几乎没有提升。博客还展示了只看权重认出游戏、改 3.5% 权重让小车 1024 局全过等实验，条件各不相同。以上均为作者自报，博客未经同行评审。
