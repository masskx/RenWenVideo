**标题**：AI做表情包｜角色不跑偏+真透明底

**正文**：

一个角色 → 一整套透明表情包，任何生图模型都能用 🎨
1️⃣ 定角色：先出一张不带字的定稿（正面半身、纯色背景、粗线条平涂、下方留字），缩小看，糊了就减细节
2️⃣ 换动作：每次都附上同一张定稿当参考，只换最后一句动作
3️⃣ 做透明底：要的是 Alpha 通道；模型不支持就先出纯色底，再去背景
4️⃣ 验收：深色、浅色、彩色底上查白边；缩到1/4还认得出字
两个坑：
⚠️ 别拿上一张新图当参考，偏差会越传越大
⚠️ 棋盘格画进图里是假透明，换个底就露馅
