**文案**：两个多月里，四家大公司推出了同一类“主动型”AI 助理。别只看又出了什么，要看它凭什么能主动干活：① 记忆：沿用你在 Claude 里的记忆、技能和已连接的应用；② 定时任务：每隔几个小时检查一次，自带云端虚拟机，关了手机也能干；③ 关键步骤等你确认：发消息、付款、签文件、删除之前先给你看。AI 可以主动，但做主的是你。（目前是研究预览版，仅面向美国部分订阅用户排队开放。）

## 和脚本不一样的地方

- 时长 60.0 秒，比脚本估的约 57 秒多 3 秒：口播要求逐字，用户本人音色（已用较快的 fast 语速）读 310 字就是这么长；没有删字、没有改写。
- 脚本说背景亮度约 35%：钩子和两个机制场景用 30–35%，字多的场景压到 20–25%，保证字清楚。
- 第 6 镜的“光标”画成一个点按圆点；结尾素材里的手指没有明显的点按动作，所以「确认」按钮在念到“还得你来按”时点亮。
- 两个场景加了画面上的小标签帮助理解（不是口播）：钩子的「今天 / 3 件事 / 需要你」、第 6 镜结尾的「你批准了，它才动手」、第 7 镜的「该出手」「该停下来问你」。
