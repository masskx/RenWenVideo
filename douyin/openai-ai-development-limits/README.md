**文案**：OpenAI 首席科学家 Jakub Pachocki 公开了自家模型的对数困惑度（衡量模型猜下一个词有多准，越低越准）：GPT‑3.5 约 0.99，GPT‑4 约 0.91，后来的模型低于 0.8；他写道，约 0.76 的模型开始在数学开放问题上做出突破。他提议各家用这个分数和其他指标约定共同上限，在安全监测跟上之前不越过。但这些数来自 OpenAI 内部代码库的固定快照；微软 AI 负责人 Suleyman 公布了 MAI‑2 Base 在同一套题上的 0.819，也说拿到这套题是特例。如果真要画这条线，谁出题、谁验收？
