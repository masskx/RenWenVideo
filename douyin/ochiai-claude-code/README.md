## 作品描述

日本媒体艺术家落合阳一，为了写一篇介绍自己的文章，用 Claude Code 并行派出 6 个调查 Agent，还让核查 Agent 复核了 14 个关键项。
从他公开的笔记和开源项目里，拆出 6 个可以直接搬进日常工作的 AI 习惯：分工调查、换读者重写、先做原型、自己造工具、留下记录、把修改变成规则。
