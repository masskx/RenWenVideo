## 简报

- 钩子台词：装了一个AI工具包，你的大模型API Key，可能已经被偷了。（脚本原句）
- 钩子画面：第 0 帧就是自绘终端里已经打好的 `pip install litellm`，0.3 秒回车，安装日志滚动；大标题「装个AI工具包 / API Key 被偷了」（「被偷了」红色）；三张 Key 卡（DeepSeek / 豆包 / Kimi，值全是假的且打码）在「你的大模型API Key」时亮起金边，「被偷了」时飞走，原位只剩红色虚线空位。
- 核心看点：LiteLLM 1.107.0 发布包被投毒（10月21日，官方仓库已下架）；不 import 也会中招，任何 Python 一启动就运行；偷 SSH 密钥、云账号、浏览器密码、大模型 Key。三步自查：pip show litellm 看是不是 1.107.0 → site-packages 里有没有 cook.pth → 中了就重置所有 Key、卸载、换回 1.106.2。
- 结尾台词：开源工具很好用，但装之前，多看一眼版本号。
