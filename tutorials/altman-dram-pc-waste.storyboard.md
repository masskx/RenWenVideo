## 简报

- 钩子台词：奥特曼说，你电脑里的内存，只有5%的时间在用，相当糟糕。（hooks.md §一 第 5 种：一句原话 + 反转——反转在第 3 场“5% 是他随口一估”）

- 核心看点：奥特曼在 10-29 上线的 Cheeky Pint 播客里说，从全球分配角度看，每个人电脑里放着内存、只有 5% 的时间在用，“相当糟糕”——5% 是他随口估计、没给依据，也不是要收走谁的内存；真正的事是 AI 卡上的 HBM 和你的内存条抢同一批 DRAM 晶圆：同容量 HBM 约吃 3 倍晶圆（美光），HBM 占 22% 晶圆只出 9% 位元（TrendForce 估计），内存条因此涨价（单一型号 13 个月 +434%），不过涨幅在收敛（4Q26 合约价预计 +10–15%）。
- 收藏点：不需要（新闻）
- 结尾台词：所以，没人要收走你的内存；但你的内存条，确实在和AI抢晶圆。（抖音技巧.md §三 第 3 种：一句翻转的判断；画面回到第 0 帧的原片 + 5%，判定章落下）

- 模板：lemo/news-package（电视新闻包装）。为什么是它：选用指南 §〇 把“演讲 / 访谈 / 观点（有人、有原话、有录像）”给到 news-package——这条就是一段访谈原话 + 一串事实核对 + 一组数字。照搬了：§1 一套包装贯穿（台标、下三分之一条一直在、tab 换类别）、一屏一个事实；§3 引语卡（原话原文 + 关键词下划线跟着口播走）、分翻牌（前后两个价格在同一块板上）、比例卡（同一把尺）、印章（一条一个）、条带擦除换段落 + 段内硬切；§7 120 BPM 网格、段内每 0.5–1 秒一个包装动作；§8 新闻配乐、印章 thump、翻牌 click、最大转折前静一拍；§9 原生招式 2（tab = 类别）、5（条永远不离场）、6（分翻牌前后对比）、10（引语卡 + 判定章）；开场用 §12 的“冷开场在最大的画面上”。不照搬：片头台标动画（钩子要第 0 帧就有内容）、新闻目录 rundown、英文双语长句。
- 模板改造：配色：柠檬黄 + 墨黑 → 播客原片酒吧木墙的深棕 #1E0D06（底）/ #3A1D10（卡）+ SK 海力士展台上 HBM 堆叠的金 #E0B84D（强调色 = AI 的内存）+ SK 海力士展台的青 #267F91（第二色 = 你的内存条），报警红 #D2412F 只给“恶搞”（会改性格：从冷的新闻台变成暖的酒吧里聊天）；原片不走灰度双色调 → 保留酒吧的暖色，只压暗、加颗粒（颜色就是这段素材本身）；比例卡 → 晶圆卡：一块画出来的晶圆，按 22% 换成金色 die、旁边位元条只亮 9%（换掉“地图上的城市寄信”这一招，成为全片招牌）；借 lemo/visual-investigation 的“说法 → 核对 → 判定”顺序和来源灰度标签（核对场、辟谣场）；配乐 → 合成 news，高潮落在晶圆卡的 22% → 9%
