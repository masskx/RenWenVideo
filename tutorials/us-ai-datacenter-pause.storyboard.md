## 简报

- 钩子台词：据媒体统计，美国已有500多个地方在限制数据中心，现在三个州也踩了刹车，但踩的位置不一样。（hooks.md §一 第 1 种：规模数字 + 反常；数字标「媒体统计」）
- 钩子画面：第 0 帧——米色纸上一张点阵图正在被铅笔一格格点满（每点 = 1 个地方，500 点，已点到约三分之一），标题手写「美国限制数据中心的地方 · 500+（The Information 标题）」；右上三张小标签「纽约 · 得州 · 俄勒冈」。
- 核心看点：媒体统计美国已有 500 多个地方限制数据中心；EIA：2020–2025 美国用电需求年增约 1.7%，2005–2019 约 0.1%，数据中心是主因之一；纽约 EO 62：≥50 MW 的新项目暂停 DEC 酌情许可直到 GEIS 完成（50 MW 按 EIA 家庭平均用电折算约 4.2 万户，估算）；得州：≥75 MW 并网申请暂停审计，9 月起 TCEQ 空气 / 水许可也暂停；俄勒冈：州有土地交易暂停至 2027-07-01；Pew：认为对家庭电费不利 38% → 50%，60% 对家门口新建感到不舒服。
- 收藏点：不需要（新闻）；三州门槛那张图可截图。
- 结尾台词：AI缺的不只是芯片，还有电网、水，和邻居的同意。（抖音技巧.md §三 第 3 种：一句翻转的判断；画面回到 500 点阵）
- 标题·视频号：美国三个州给 AI 数据中心踩刹车：纽约卡许可、得州卡电网、俄勒冈卡土地

## 导演

- 模板：lemo/dataviz（数据讲故事：米色纸、红蓝铅笔、钉在数字上的手写注）。为什么是它：选用指南 §〇 把“跑分 / 价格 / 数据趋势 / A vs B”给到 dataviz；这条新闻的骨架是几个门槛和几组数字（500、0.1% → 1.7%、50 / 75 MW、38% → 50%）。照搬了：§1 一张图讲一件事、每个记号都是真数字、按数据选图（点阵 = 数量、斜率图 = 前后、数轴 = 门槛、时间轴 = 期限、哑铃 = 民调前后）；§2 米色纸 + 纤维噪声 + 点阵网格、墨色坐标、记号落下时一个小涟漪；§3 颜色只编码数值，红笔 = 记录 / 警示、蓝笔 = 人的看法；§4 字幕是图注（衬线、细线、小号等宽眉题）；§5 节奏跟着数据、轴随口播长出来、“空着的下一格”；§8 原生招式：轴随故事长出来、钉住的注、编码变形（兆瓦条变成 42 个家庭点）、空着的下一格（俄勒冈 2027-07-01）。不照搬：实体铅笔模型（画成一支简化的红蓝铅笔笔尖）、英文手写体。
- 模板改造：蓝铅笔的颜色取 Pew 原图的蓝 #0F6BA0（民调 / 人的看法），红铅笔保留红 #C8372D（用电 / 门槛 / 警示）；手写注用霞鹜文楷（中文）；“一个点 = 一个事实”变成 500 点的点阵，开场被铅笔一格格点满（声音 = 一下一下的点击）；兆瓦 → 家庭的换算用编码变形当招牌（50 MW 的红条碎成 42 个点，每点 = 1000 户，算法写在旁边）；借 lemo/archive-lighttable 的“出处钉在纸上”——每张图右下角一张小纸条写出处（州长令 / TCEQ 回函 / Pew / EIA）；配乐 → 合成 news，高潮落在“约 4 万户”
- 点子：观众以为是“美国禁止 AI 数据中心”，其实是三个州各卡一处（许可、电网、土地），共同的原因是电、水和电费；一个 50 MW 的项目，用电相当于 4 万户人家。
- 对标：dataviz 样片（`code/lemomo-ai__lemo-opuscar/3961ddb/styles/dataviz/demo`；学：铅笔、注、轴随口播长出来；不拿：温度条纹、英文手写）；我们的 suanli-hub-undersea-dc（8 分，同为数据中心题；学：问题 → 答案的结构、招牌落在配乐高潮；不拿：卫星底图、海底、国内算力枢纽——审稿要求区分开）。
- 结构候选：① 规模（500）→ 原因（电）→ 纽约（门槛 + 换算）→ 得州 → 俄勒冈 → 居民 → 判断；② 先讲 Pew 民意再讲三州——钩子弱；③ 只讲纽约 50 MW——丢了“三州手段不同”这个重点。选 ①。
- 风格：dataviz 系统。纸 #F3EBDD，卡纸 #FBF6EC，墨 #2B2420，灰 #8C8073，红笔 #C8372D，蓝笔 #0F6BA0；字：霞鹜文楷（手写注）、思源宋体（图注字幕）、IBM Plex Mono（刻度、出处）、Barlow Condensed（大数字）。
- 底色：全片一张米色纸；情绪靠红 / 蓝两支笔切换（红 = 用电和门槛，蓝 = 人）。
- 贯穿物件：那支红蓝铅笔——开场点满 500 个点，中间画轴、画门槛线、把红条碎成家庭点，民调那场翻到蓝色那头，结尾回到 500 点阵、离开画面。
- 招牌镜头：第 19–23 秒（mw 场）：纽约那条 50 MW 的红条在数轴上碎开，变成 42 个小房子点（每点 1000 户）排成方阵，旁边铅笔写出算法「50 MW × 8760 h ÷ 每户 10,380 kWh ≈ 4.2 万户（EIA 2024 家庭平均，估算）」——配乐高潮落在这一拍。
- 第0帧：点阵（已点到约 170 个）+ 手写标题「500+」+ 三州小标签 + 出处纸条「The Information 标题 · 媒体统计」。
- 高潮停留：42 个家庭点排好后停约 1.6 秒；最后一句说完 0.3 秒内结束。
- 配乐：news（100 BPM），climax = mw，lifts = tx、pew。
- 和上一支不同：最近三支 openssh-musl-auth-bypass-ai（ascii-crt）、openai-images-2-6-gif（dark-keynote）、chips-cpu-gpu-npu-tpu（teardown 3D）。结构（规模 → 原因 → 三州 → 居民，不是原话自查 / 演示原理 / 四颗芯片）、开场（点阵被点满，不是终端原帖 / 草图光扫 / 3D 芯片）、招牌（兆瓦碎成家庭点，不是电路命中 / 6 格循环 / 总线 35×）、镜头路线（一张纸上的 2D 推拉，不是字号推近 / 界面展开 / 3D 环绕）、配乐形状（news，高潮在换算）、结尾（回到点阵 + 判断）——六项都不同。
