## 简报

- 钩子台词：红军的第一部电台，只有半部。（hooks.md §一 第 2 种：一个具体到反常的东西 + 数字；11 个字，0.5 秒内开口）
- 钩子画面：第 0 帧就是那部电台（AI 生成的版画剪贴件，占画面宽 90%），右半边已经是虚线轮廓；左上巨大宋体「半部电台」带错版影。
- 核心看点：从“只能收、不能发”的半部电台，到 525.4 万座 5G 基站——同一条电波，接到了西邮人手里（第 8 秒前说出“只能收，不能发”；数字在高潮）。
- 结尾台词：当年的报务员只能听。今天，轮到我们发报：请党放心，强国有我。（抖音技巧 §三 第 2 种：回扣开头——半部电台的另一半被补上）
- 标题·视频号：半部电台：一堂西邮人的思政课
- 标题·抖音：红军第一部电台只有半部，后来呢？

## 导演

- 模板：lemo/halftone-dossier（复古半调案卷：纸面、网点、错版大标题、印章、一张案卷一页一页读）。题目是“一份档案”——一部电台的履历；照搬：整片是纸、阴影全用网点不用渐变、黑体宋体大标题 + 错版影（+8/+8）、印章砸下（相机震 + 闪 + 章声）、字幕条做成深墨色药丸 + 关键词换色、点擦转场、HUD 角标（案卷号 / 章节）、印章前先静音。
- 模板改造：配色——示例的奶油 / 藏青 / 粉 → 电报纸米黄 #EFE5CF + 墨 #1B2533 + 中国邮政绿 #0B6E4F + 印泥红 #C0392B（只给邮戳）+ 荧光黄 #F2C230（只给划线），全部来自题材里真有的东西（电报纸、邮政、印泥、Vox 荧光笔）；原生招式换一个——“印章”换成“邮戳”：圆形日期戳砸下，每个年代一枚（1930.12.30 龙冈 → 1940.12.30 延安 → 1950 西安 → 2026 西安）；借 huashu/editorial-collage 的 Vox 分层拼贴——剪贴件带白边和投影、撕纸边、荧光笔随口播画出、2D 相机推过三层视差；去掉样片的卡通角色和喜剧音效（题材庄重：只留打字、电码嘀嗒、纸、邮戳）；剪贴件用 AI 生成的铜版 / 网点剪贴件再做双色调（墨 → 底色映射），代码负责一切运动。
- 点子：大家以为红色通信是从一部完整的电台开始的，其实只有半部——只能收、不能发；九十多年，这条电波从“只能听”到“能说”到“连起来”，今天轮到我们把它补完、发出去。
- 对标：lemo/halftone-dossier 样片 *Case File: Chubby*（学：一张卡 2–4 秒、印章砸下的节奏、点擦转场、HUD 角标；不拿：卡通嫌犯、粉蓝配色、搞笑音效）；Vox 式分层拼贴解说（huashu editorial-collage：学剪贴件 + 撕纸 + 荧光笔 + 推过多层；不拿：任何具体的片子、版式和字体）。
- 结构候选：① 时间线：1930 → 1940 → 1950 → 2026，每个年代一枚邮戳；② 一部电台的履历：从“缺了什么”出发，每段补上一点，结尾补完另一半；③ 课堂框架：一节思政课的板书，老师提问、学生作答。选 ②（它包含 ① 的时间线，但多了一个会变的物件和一个结局：开头缺一半、结尾补上；③ 容易做成 PPT）。
- 风格：halftone-dossier 的纸 + 网点 + 错版大标题 + 印章，叠 Vox 分层拼贴；物件是 AI 生成的铜版画剪贴件（像从旧报纸上剪下来），双色调映射到墨色 / 邮政绿；题材本身就是“纸上的电报”——电报纸方格、四位中文电码、邮戳，视觉从邮电长出来。
- 底色：钩子、延安夜、结尾发报用深墨底（#16202C，网点用浅一号的同色）——“黑夜里只有电波”；红军监听、西邮、新时代、AI 用电报纸米黄底（讲事实）；高潮翻成邮政绿满屏一次。
- 贯穿物件：那部电台。第 0 帧右半边（发报机）是虚线轮廓；监听时左半边亮着、电波只往里进；延安时第一次有电波往外出；高潮时它缩小成画面角落一枚邮票，旁边长出 525 万个点；结尾发报时右半边一格一格印回来——补完。
- 招牌镜头：结尾（约第 95 秒）电报纸上逐格打出 8 组四位电码「6153 8093 2397 1800 / 1730 0948 2589 2053」，每组嘀嗒声落下，下面译出「请党放心 强国有我」；同时电台右半边按网点由疏到密印回来，电波第一次从发报机出去。
- 第0帧：深墨底 + 整部电台（右半虚线）+ 左上「半部电台」宋体大字带邮政绿错版影 + 右下邮戳轮廓（下一拍砸下）。
- 高潮停留：「1 → 525.4 万」：半部电台缩成一枚邮票，邮政绿满屏的网点每一点一座基站，数字落定后停 2 秒（可当封面）。
- 配乐：mood warm，climax 场景 climax（525.4 万落定那一拍），lifts yanan、end；印章 / 邮戳前静音。
- 和上一支不同：结构（一个物件的履历，缺一半到补完）/ 开场（第 0 帧一件 AI 剪贴件 + 虚线另一半，不是新闻截图）/ 招牌镜头（电码逐格译出 + 网点印回另一半）/ 镜头路线（三层视差推进，一场一个纸面世界）/ 配乐形状（温暖、递进、两次静音）/ 结尾（回扣开头补完）——六项都和最近三支（nvidia ×2、apache）不同。
