## 简报

- 钩子台词：你一定见过这种朋友圈：凌晨两点发，早上八点删。（hooks：“你 + 人人见过的场景”，第二人称共情 + 一个反差）
- 钩子画面：第 0 帧——深夜卧室，被窝里一个人举着手机，屏幕的冷光照亮脸和天花板；画面上方一张大“动态卡片”，时间戳「02:13」很大，卡片上一句示例文案。说到“早上八点删”时时间戳翻成「08:00」，窗外天亮、底色从夜蓝翻成早晨，卡片被揉皱、落进垃圾桶。
- 核心看点：深夜的你不是矫情——大脑的“刹车”（前额叶）累了，“油门”（杏仁核）更敏感：一夜不睡，杏仁核对负面图片的反应高六成多（Yoo 等 2007）；有假说认为凌晨 1–4 点好心情最低（Tubbs 等 2022）。
- 结尾台词：还想发，再发。那才是你真正想说的。
- 标题·视频号：为什么一到深夜就 emo？不是你矫情
- 标题·抖音：凌晨两点发的朋友圈，为什么早上八点就删了
- 标题·小红书：为什么越到深夜越emo｜熬夜情绪差的科学解释＋一个小办法

## 导演

- 点子：观众以为深夜的难过是“终于说出了真心话”，其实一部分是大脑累了——刹车没电、油门更灵、夜里又太安静，所以凌晨想通的道理多半不是答案，是累了。
- 对标：lemo `hd-2d`（学：光就是主角——一个大的冷环境光，加一个讲故事的“实用光源”；光会呼吸；俯视一个小场景；每个场景一个雾色 / 一个主光，一切就能认出“换地方了”。不拿：像素贴图、3D 引擎、衬线字体、RPG 对话框）；huashu `character`（学：眼睛演戏、预备动作、停顿给反应。不拿：吉祥物腔调）；我们自己的 agent-compute-hijack-v3（2D 纵深套件起步）。
- 结构候选：① 三条原因清单（生理 / 心理 / 环境，一条一屏——最常见，像 PPT，不选）；② 一夜的时间线：从 18:00 到 08:00，钟一直走，每个时段揭一个原因（太散，60 秒装不下 14 个小时）；③ 情绪曲线 + 一个闭环：钩子（人人见过的删动态）→ 共情（两种都是真的）→ 反转（不是矫情，是换班）→ 三个具体原因（刹车没电 / 杏仁变大 / 凌晨谷底，附一个“为什么会这样”的推测 / 夜里太安静）→ 金句（不是答案，是累了）→ 一个能马上用的办法，结尾回到开头那张卡片和「08:00」。选 ③：钩子的“02:13 → 08:00”本身就是全片的问题和答案，结尾回到它，观众带走的是一个动作。
- 风格：hd-2d 的“两种色温”语法放进 v3 的 2D 纵深套件（`Ground horizon/grain`、`ContactShadow`、`camAt`、视差 `Layer`）。夜里的大环境光是冷的深夜蓝，唯一讲故事的光源是手机屏（冷白蓝）；早上换成满屏暖阳光——色温的翻转就是情绪的翻转。颜色自编（没有素材；取自题材的世界：夜里关灯的卧室、手机屏光、早晨的窗光）：夜底 `#111A33`、远景 `#1C2750`、屏光 `#CFE3FF`、夜里的强调 `#8EC1FF`；早晨底 `#EAF3FC`、阳光 `#FFC94A`；墨 `#10131C`；红 `#F0525A` 只用在“电量见底”。不用藏青 + 金、不用米白 + 宋体 + 橙。字：思源黑体 900（数字、时间戳）+ 霞鹜文楷批注（账号层）。
- 底色：钩子、共情的“夜”半边、刹车、杏仁、表盘、安静——深夜蓝（低谷，越来越深）；“早上八点”、共情的“早”半边、草稿、结尾——早晨亮底 + 阳光（醒了）。翻底卡在“八点删”“删的时候”“睡一觉”三个词上。“累了”一句在夜里，但灯泡熄掉的瞬间整屏暗一档（全片最暗）。
- 贯穿物件：那张“动态卡片”（时间戳 + 一句话）。钩子：02:13 发出 → 08:00 被揉掉；共情：两张卡片一夜一早；值班：卡片变成值班牌；刹车 / 杏仁 / 表盘：卡片上的时间戳一直在走（22:40 → 01:30 → 03:00）；安静：卡片倒扣在被子上；草稿：卡片滑进“草稿箱”抽屉；结尾：早上从抽屉里抽出来，“发送 / 删除”两个按钮。
- 招牌镜头：第 13–19 秒“刹车没电”：地板上两个大踏板（左“杏仁核”油门、右“前额叶”刹车，有厚度、有投影），刹车上一节电池随时间戳 18:00 → 02:00 一格格掉电，最后一格变红、刹车软塌下去，油门自己踩到底，镜头一震（Remotion）。
- 第0帧：深夜卧室 + 被窝里的人 + 手机光 + 大字时间戳「02:13」的动态卡片（负的入场时间，第 0 帧就完整）。
- 高潮停留：“是累了”——灯泡熄掉、换成 3% 电量的电池后停 1.5 秒；片尾最后一句说完 0.6 秒结束（2026-10-27 按 抖音技巧.md §三 改，原来片尾停 2 秒）。
- 和上一支不同：最近三支 vibe-opus-video-tutorial（教程录屏）、kimi-k3-1-pro（官方演示录屏递进）、agent-compute-hijack-v3（机器人 + 论文数字）。结构（情绪曲线 + 闭环，不是能力递进 / 论文复述）、开场（第二人称的生活场景，不是录屏或机器人台词）、招牌镜头（踏板 + 掉电电池，不是扫描线或点阵翻色）、镜头路线（同一间卧室里推近 / 拉开，一次俯视表盘，不在窗口之间甩）、配乐形状（夜里极简的低频铺底，早上一个亮的和弦进来）、结尾（回到开头那张卡片，留一个选择）——六项都不同。

## 声音

- 夜里：很轻的低频铺底 + 偶尔一声秒针（`fs-watch-tick`）；安静一场去掉铺底，只剩极轻的呼吸感。
