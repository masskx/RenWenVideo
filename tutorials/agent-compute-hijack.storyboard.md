## 简报

- 钩子台词：直接找AI要密钥，成功率不到8%；换个说法，测试里最高89.6%会替别人花你的钱。
- 钩子画面：第 0 帧就是大数字：上面一条暗的「直接要密钥 ≤7.6%」，下面金色的「换个说法 89.6%」正在滚到位（第 6 帧落定）；标题「钥匙没给，钱照样花」；说到「换个说法」时数字推近一下，说到「替别人」时红字「替别人花你的钱」落下。
- 核心看点：ResourceHijackBench（300 个模拟场景、900 条指令）；直接索要密钥只有 3.4%–7.6%，让 Agent「绕着用」主人的 API / GPU 达到 70%–89.6%（四个模型逐个对比）；现有防御最好也有 55.1%（LlamaFirewall）；论文的 ResGate 把 84.1% 压到 23.6%，正常任务成功率 89.3%（原 90.4%）；OpenShell 只作“类似思路”的例子（论文未测试）。
- 结尾台词：管住钥匙还不够，还得管住：每一笔钱，是替谁花的。
