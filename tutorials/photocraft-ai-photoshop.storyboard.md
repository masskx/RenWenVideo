## 导演

- 模板：lemo/blueprint（晒图纸工程图）。为什么是它：这条新闻的本质是“一张图纸画全了，造出来的只有一半”——蓝图的语言（尺寸线、编号气球、图签、剖切线、零件表）天生就是“量出来的进度”；选用指南 §〇 表里“产品 / 系统拆开看”的备选就是 blueprint，首选 teardown 要 3D 实拍质感，违背“知识片 2D 优先”。照搬了：§1 全片在一张晒图纸上、镜头像眼睛读图、白线 + 蓝底、设计物就是角色（这里是软件窗口本身）；§2 纸的颗粒、涂层不匀、折痕、四种线宽、虚线 = 没做出来的部分（隐藏线）；§3 只有蓝和白，**一种非蓝色只用一次**（图签上的章）；§4 字幕是图纸注释（NOTE / n 的小框，双白线，逐字写出），整片的口播最后都抄进“总说明”栏；§5 画线顺序（中心线 → 轮廓 → 细节 → 尺寸 → 气球 → 字）、一层一拍；§6 镜头语法：局部推近、剖切线扫过看内部、锁定停一拍；§8 原生招式：实时标注（尺寸线量东西、数字会变）、图签当故事（状态栏 = 判决）、FIG. 编号改写当转场。
- 模板改造：配色：模板的示例蓝 #18336B → 这支素材自己的普鲁士蓝（北斋《神奈川冲浪里》本来就是普鲁士蓝印的：#14233B / #1C3762 / #25649E，取自官方截图），白线 → 浪里的纸色米白 #EEE8D1（同一张画的两种颜色，蓝图和实物是一个世界）；借 opuscar98/70「蓝图显影成实景」：做好的部分从线稿“显影”成真截图的像素，没做好的留在线稿——招牌镜头就是显影边从 100% 退回 45%（模板的“一个真实物件只出现一次”换成“真实像素只占做好的那部分”）；章的颜色：经典红 → PhotoCraft README 里「early alpha」徽章的琥珀 #D69E2E（判决就是 alpha）；字体：手写英文 → 霞鹜文楷（中文手写注释）+ JetBrains Mono（图签字段、尺寸数字）；声音：大键琴赋格 → 我们合成的 wonder 配乐 + 针管笔划纸、盖章拟音，显影那一下抽空 0.4 秒。
- 点子：观众以为“AI 写出了一个 Photoshop”，其实它自己量过：外表 100%，能干活的只有 45%——剩下那一半才是软件。
- 对标：lemo/blueprint 样片（学：画线顺序、尺寸线和气球的规格、图签当判决、注释式字幕；不拿：机械齿轮的故事、羽管键琴配乐、横版构图）；opuscar98/70（学：从线稿往外显影成实景、显影边带一点暖光；不拿：3D、一镜到底的环绕）。我们的 mistral-large4-open-weights（学：在别人的原图上画、官方数字永远标「自评 / 估算」；不拿：体育转播的包装和比分条）。
- 结构候选：① 一张总装图：先全显影（外表齐了）→ 显影退回 45%（转折）→ 拆开量哪些没做（菜单 / 工具 / 面板）→ 剖切线看底下（性能、PSD、问题数）→ 图签填工时 → 回到总装图盖章；② 时间顺序：上线 → 星数 → 媒体 → 路线图（像念新闻）；③ 先给 45% 再倒推它怎么算出来的（谜底式，和 llm-same-prompt 撞结构）。选 ①：第 0 帧就是最“炸”的真截图，转折在 8 秒内落地，后半段每一句都是图纸上“量”一个东西，一直有新东西。
- 风格：lemo/blueprint 的系统 + 素材自己的颜色。纸：#14233B → #1C3762 → #25649E 的不匀涂层 + 纤维 + 一道折痕 + 边缘褪色；线：米白 #EEE8D1 四种线宽（4 / 2.5 / 1.6 / 1 px），隐藏线短虚线；窗口线稿是从官方截图算出来的（`demo-lines.png`，Sobel 边缘），所以“图纸”和“实物”像素对齐；字：霞鹜文楷（注释、页眉、气球字）、JetBrains Mono（图签、尺寸）。
- 底色：全片同一张晒图纸（冷、安静、像在读规格书）；情绪靠“显影”的多少：开头满屏彩色（外表齐了），转折后彩色只剩 45%，剖切看到的底层全是线（还没造出来），结尾回到总装图、琥珀章是全片唯一的暖色。
- 贯穿物件：图签（右下的标题栏）——第 0 帧「项目 PHOTOCRAFT · 版本 0.6 · 状态 ____」；转折时状态栏写上「能干活 ≈45%」；中段零件表一行行填上（菜单 / 工具 / 面板 / 性能）；工时栏写上「1,100–1,800 h（AI）」；结尾琥珀章盖在状态栏上。
- 招牌镜头：第 6–9 秒“真能干活，只有45%”：安静 0.4 秒，然后显影边从窗口右边往左退，彩色像素一列列褪回米白线稿，停在 45% 处；一条尺寸线从左边量到显影边，写上「≈45%」，右边 55% 的线稿变成隐藏线（虚线）；配乐高潮落在尺寸线写完那一拍。
- 第0帧：完全显影的 PhotoCraft 窗口（真截图）钉在晒图纸上 + 页眉大字「628 / 628」+ 菜单栏上的尺寸线和气球 + 图签 + 角落「@ArtCraft｜案例展示」。
- 高潮停留：45% 的显影边和尺寸线停 2 秒（下一句开头才动）；结尾章落下后 0.5 秒结束。
- 配乐：wonder（92 BPM，亮、慢），climax = turn（climaxAt 落在尺寸线写完）；lifts = hidden、hours；两次安静：turn 场开头 0.4 秒、end 场开头 0.3 秒。
- 和上一支不同：最近三支 mistral-large4-open-weights（telestrator）、huashu-motion-1d95（swiss-motion）、llm-same-prompt-diff-output（whiteboard）。结构（一张图纸从全显影退到 45% 再逐项测量，不是“一个时刻三个机位” / 账单网格 / 谜底式）、开场（真截图在蓝图上全显影，不是定格柱图 / 价格 / 白板）、招牌镜头（显影边倒退到 45%）、镜头路线（读图：局部推近 + 剖切线下扫 + 拉回总图，不是定格倒带 / 网格推进 / 白板平移）、配乐形状（wonder，亮→抽空→高潮在测量完）、结尾（盖琥珀章 + 一个动作）——六项都不同。
