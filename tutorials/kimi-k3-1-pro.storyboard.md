## 导演

- 点子：观众以为 AI 做出的画面都是“生成视频”，其实 K3.1 Pro 是写代码去开 Blender、CAD、虚幻引擎，一个构件一个构件把东西搭出来——所以它能拆、能转、能打印、能修模拟器。
- 对标：lemo `living-screencast`（学：窗口浮在底上带软投影、推近到发生的地方、“N×”快进标签、关键处推近 + 暗角定格；不拿：像素吉祥物、重画 UI——我们放的是官方真实录屏）；Xian 梵高集（学：一句一画、数字代替形容词、底色随情绪、高潮停留；不拿：宋体、金画框）。
- 结构候选：① 参数表——参数 → 价格 → 跑分 → 开源（最常见的发布解读，像 PPT，不选）；② 一条龙倒放——从成片一路倒回线框和代码（只有一条素材撑得住，30 秒太单）；③ 能力递进的展示片——钩子用最震撼的成品（龙），再按“越来越难”排：搭场景（教堂）→ 能拆能转（发动机）→ 走进现实（打印台灯）→ 自己修 bug（肌肉人）→ 一个分数 → 开源。选 ③：用户要“讲能力 + 视频素材”，每一句都有一段真演示撑着；递进让每 3–4 秒都有新东西。
- 风格：lemo living-screencast 的“窗口 + 推近 + 快进标签”语法，放进 v3 的 2D 纵深套件（`Ground horizon/grain` 当 3D 软件的地面网格、`ContactShadow`、`camAt`、视差 `Layer`）。颜色全部取自素材：Blender 视口炭灰 `#2C2C2C` / `#3D3D3D`（`cologne-interior-4.png`），FreeCAD 白底 `#F7F7F7` / 金属灰 `#ABAFB1`（`turbofan-4.png`），台灯亮起的琥珀 `#F3A019`（`modular-lamp-trimesh-23.png`，也是 Blender 选中线框的橙）当唯一强调色 = “被点亮 / 做出来了”，天宫的深赭 `#100402` 和金 `#E5C997`（`celestial-palace-35.png`）只在头尾。字体思源黑体 900（数字）+ 霞鹜文楷批注（账号层）。
- 底色：钩子和结尾——天宫深赭（成品的世界）；片名、Blender——视口炭灰（“软件里”）；发动机、跑分——FreeCAD 白（讲事实、透气）；台灯——从白翻到深底被台灯照亮（全片第一次“走进现实”）；肌肉人——近黑（演示片自己的黑底，全片最硬核的一段）。
- 贯穿物件：一条琥珀色“扫描线”：钩子里把龙扫成白模；Blender 一场从白模扫回打光；发动机一场沿零件扫过、零件逐个点名；台灯一场扫过之后灯亮；肌肉人一场扫过一次就从摔倒换成走路；跑分一场变成两根柱子之间那 0.7 的缝；结尾扫回彩色的天宫。
- 招牌镜头：第 8–13 秒，Blender 视口窗口里教堂从一块地板长成白模（官方录屏 2.5× 快进，带「2.5×」标签），扫描线落下的一刻切到打光成片，镜头同时推进窗口；`330万 三角面` 计数从 0 滚到位（Remotion）。
- 第0帧：巨龙张嘴的画面已经在（负的入场时间）+ 大字「这条龙」+ 左上「据 Kimi 官方演示」。
- 高潮停留：跑分一场两根柱子落定、“只差 0.7”手写批注出来后停 1.5 秒；结尾天宫 +「11.4 前开源」停 1.5 秒（`tailMs`）。
- 和上一支不同：最近三支是 agent-compute-hijack-v3 / v2（手绘机器人 + 论文数字）和 vibe-knowledge-douyin（cinema 字卡）。结构（能力递进的展示片，不是情绪曲线）、开场（真实 3D 成片画面，不是画出来的角色）、招牌镜头（录屏快进 + 扫描线换态，不是点阵翻色）、镜头路线（每场推进一个窗口、在窗口之间甩，不是在一张画布上平移）、结尾（回到开场世界 + 一个日期章，不是回到开场台词）——五项不同；配乐形状（递进、结尾收）也换掉旧的平铺底乐。
