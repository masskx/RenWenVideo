- 结尾台词：机器负责发现，出门处理的，还是人。（抖音技巧.md §三 第 3 种：一句翻转的判断；画面是“已知 / 没定论”两栏）

- 模板：lemo/visual-investigation（视觉调查）。为什么是它：选用指南 §〇 把“调查 / 争议 / 谁说了什么”给到它；这支片就是几个来源对不上：媒体、两家厂商、一个物业负责人。照搬了：§3 近黑底、面板 1 px 细框、来源一律灰度一个调色、唯一强调色只用来“指”（圆圈、划线、对上的那一处、没定论的虚线框）、转录用纸卡 #E4E0D4 / #1D1D1B；§4 每一帧字少、每件证据上方一个等宽来源标签（6×12 色块 + 类型 · 来源）、关键一句用强调色从左到右划出、一帧一个结论当标题；§5 元素白闪切入、只有“画出来的”东西是渐进的（圆圈 0.5 秒顺时针画完）、照片里慢推 ≤ 1.06、不弹不飞、硬切；§1 不确定性画出来（虚线框「未找到」、虚线圆点 = 四到五里的“五”）；§8 原生招式：Then vs. record（说法下面排厂商的数）、Dots for people（一个圆点一个保安：5 / 3 / 4–5，晚班 2 → 1）、Freeze, circle（热成像里圈出热源）、Known / unresolved（结尾两栏）。不照搬：它的灾难题材、双语字幕、Kokoro 配音。
