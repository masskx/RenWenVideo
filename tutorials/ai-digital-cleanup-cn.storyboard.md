# 用 AI 清掉你在网上留下的痕迹（中国版）· 分镜

## 简报

- 钩子台词：你的手机号，可能绑着你早就忘了的二十几个账号。（脚本原句）
- 钩子画面：第 0 帧就是一部手机，屏幕上的计数从 0 往上跳，连线一根根射向周围的 App 方块（通用图形，不用商标），多数方块变暗、打问号；念到“二十几个”时落在「25?」。标题「你的手机号 / 绑了多少个账号？」
- 核心看点：四步全程合法、只查自己——①一证通查（工信微报 › 服务 › 政务服务 › 一证通查，选互联网账号）+ 云闪付「一键查卡」②把结果丢给 AI 分三类、按绑卡 / 实名排风险 ③注销前先问 AI 余额 / 支付 / 授权 / 续费；没有注销按钮就用个保法第 47 条删除权写申请 ④还不理就 12321 投诉选「账号注销难」
- 结尾台词：花一个下午，把自己从网上收拾干净。
- 标题·视频号：你的手机号绑了多少个账号？4步用AI清理个人信息
- 标题·抖音：你的手机号，绑了多少个你忘了的账号？
- 标题·小红书：个人信息清理｜一证通查+AI注销旧账号4步教程

## 封面卡

- 模板：数字型（锚点是一个数：手机屏幕上的「25?」）
- 封面标题：你的手机号，绑了多少个账号？
- 锚点：手机 + 25 个 App 方块的连线环，问号方块变暗；占画面高约 35%
- 辅助句：「4步用AI清理 · 只查自己」
- 标签：左上「个人信息大扫除 · AI」
- 颜色：字 #e8f0fa / 底 #0c1a2c，强调 #ffab40（琥珀）；连线和方块用全片的 B 青
- 冒充检查：方块是通用图形，没有平台商标；「25?」是问句（一证通查覆盖 25 款 App），不是某个人的真实数据

## 素材和出处

- 方法来源：海外博主帖（土耳其语，2026-10-19），链接只在 `inputs/ai-digital-cleanup-cn/script.md`；不上作者名、头像、链接。「6 小时 / 47 条 / 12 个」是作者自述，屏幕标「据海外博主自述」。
- 渠道和路径：脚本 §2 核实表（2026-10-21）。一证通查（互联网账号）：覆盖 25 款 App、只给数量、48 小时短信回复；云闪付一键查卡：只在云闪付 App 内；微信 / 抖音 / QQ / 微博注销路径；个保法第 47、50 条；12321 投诉类型。
- 个保法条文：屏幕上的第四十七条原文已对照中国人大网（npc.gov.cn）原文；申请函写「请在合理期限内」，不写“法定 30 天”。
- 不讲：码号助手 / 一号通查（未核实）、海外数据中介、haveibeenpwned、SEO 压制。
- 图标：`materials/icons/`（各自商标，仅用于指名识别）。素材片：Pexels 07（门锁，Jakub Bukowski，Pexels License），右下角「Pexels 素材」。
- 屏幕上的手机界面都是自绘示意，标「界面示意」；个人信息全部是打码条。

## 其他

- 风格：蓝图深底 + 顶部章节条（查 / 排 / 删 / 投诉），全屏 9:16；A 琥珀 = 本步要点，B 青 = 安全做法，红 = 风险 / 骗局 / 失败。
- 合规（脚本 §4 Compliance）：画面和口播都不出现 黑产 / 开盒 / 人肉 / 社工库 / 泄露库 / 查他人 / 买数据 / 爬虫；大字不出现「泄露」；每一步都是“本人”。
- **不引流（用户 2026-10-21）**：抖音不允许站外引流，脚本原结尾「五条提示词我整理好了，评论区扣「清理」，我把资料包放在主页」整句删掉，画面上也不出现资料包、评论区关键词、主页；结尾只留「花一个下午，把自己从网上收拾干净」。
- 口播和脚本逐字一致；为了切场景，“一证通查”那句没拆，“分三类，再按……”改成句号断开，读音一样。数字用 `[6|六]` 这种写法：字幕显示阿拉伯数字，读音不变。

## 静帧判断

- 第一轮静帧：「25?」压到手机边框 → 手机加宽到 250、字号 112；云闪付的警示章压住下面的骗子行 → 骗子行下移；风险表的「10 分钟 · 一张清单」章出了聊天框右边 → 移进框内居中；微信图标的白色字标在白底上看不见 → 只裁气泡图标、放深色底；12321 标题条字只有约 35 px → 放大到 740 宽（约 40 px）；申请函第一行折行 → 拆成两行；12321 下拉框选中后收起的动画看着乱、印章落在镜头最后几帧 → 下拉保持展开、印章提前；law 镜头换页时旧标题残影 → 旧页 8 帧内淡出上移。
- 丰富度第一版不过（4 个“几乎没变”窗口：37.5、45、50、57.5 秒，都是口播在列举、画面在等下一个卡点）→ sort 的 App 小块跟着句子一个个进；risk 加一条跟着卡点平移的琥珀列高亮、绑卡 + 实名的行变红；paths 的路径一步一步点亮（当前一步琥珀底）；precheck 念到“要先清哪些东西？”时 AI 先回一句「先处理这 4 样：」和四个空格子，再逐个填。
- 封面十条打分（`cover-thumbs.png`）：80 px 认得出标题 1；看得出讲什么 0.5（第一版辅助句“4步 · 全程合法 · 只查自己”没说用 AI 清理 → 改成「4步用AI清理 · 只查自己」）；唯一锚点 1；数字型对路 1；13 字、按意思断行 1；三层字 1；对比够 1；强调色：琥珀之外连线是青 0.5；三个比例各排一次 1；没有假 logo，「25?」是问句不是数据 0.5 → 8.5 分。
