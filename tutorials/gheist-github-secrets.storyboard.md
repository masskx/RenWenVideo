## 简报

- 钩子台词：你仓库里的密钥，可能正被你自己的CI，一行行打印进日志。（hooks：第二人称 + 反常识——偷密钥的不是外人的服务器，是你自己的 CI）
- 钩子画面：第 0 帧就是一个 CI 日志窗口（GitHub 式的近黑底），`Run sync-check` 下面一行行打出红色的 base32 乱码（随机字符，示意）；说到“打印进日志”时一枚红章「你的密钥」砸在乱码上，左下「示意画面·随机字符」。
- 核心看点：Gheist 用被盗 token 往每个能碰到的仓库种分支，让你的 CI 把密钥用 base32 打印出来绕过遮蔽，经 GitHub 自己的 API 下走、几秒后删掉运行；超过 850 个账号、超过 13,500 个分支（据 Wiz Research）；删分支不等于没事，要轮换全部密钥、吊销 token。
- 结尾台词：以后能用短期的细粒度token，就别再用长期的个人token。
- 标题·视频号：你的 CI 正在打印你的密钥：Gheist 攻击 850+ GitHub 账号
- 标题·抖音：850多个GitHub账号中招，你的CI可能正在打印你的密钥
- 标题·小红书：GitHub token被盗怎么自查｜Gheist攻击 ci-sync 分支 密钥泄露 处理办法

## 导演

- 点子：观众以为密钥被偷得靠外人的服务器把东西传出去，其实 Gheist 让你自己的 CI 把密钥打印进你自己的日志，再走 GitHub 自己的 API 拿走——没有可疑域名可拦，删掉分支也晚了，只能换钥匙。
- 对标：lemo `living-screencast`（学：窗口浮在底上带软投影、推近到发生的地方、关键一行聚光；不拿：像素吉祥物）；lemo `halftone-dossier` / mg15 `19-paperclip` 的“截图贴纸化”（学：原文截图做成有白边和投影的贴纸，关键一句高亮抬出；不拿：牛皮纸档案的复古质感）；我们自己的 agent-compute-hijack-v3（2D 纵深套件 + 一个会演的角色）。
- 结构候选：① 新闻快讯——数字 → 原理 → 防护 → 建议（最常见，开头只有数字，不戳人）；② 倒叙破案——从“日志里一串乱码”倒查回被盗 token（悬念好，60 秒装不下自查和处理）；③ 一把钥匙的旅程——钩子先让“你的密钥”在你自己的日志里被打印出来，再给规模，然后跟着这把钥匙走完：被种分支 → 被打印 → 骗过遮蔽 → 经 API 被下走、现场被抹掉 → GitHub 的闸门为什么只拦一半 → 你怎么查 → 怎么换钥匙。选 ③：每一步都是同一把钥匙发生了一件新事，观众一直知道“现在钥匙在哪”；结尾“换钥匙”正好回答钩子。
- 风格：living-screencast 的“窗口 + 推近 + 聚光”放进 v3 的 2D 纵深（`Ground grain`、`ContactShadow`、`camAt`、视差 `Layer`）；截图贴纸化；一个会演的角色——“Gheist”画成一只粉色描边的小幽灵（名字就是德语的“幽灵”，我们自己画，不用 Wiz 的插画）。颜色从素材取：底用 Wiz 头图的近黑 `#1D1C25` 和 GitHub changelog 的 `#010409`；攻击者 = Wiz 头图的粉 `#F07CF0`（描边）/ `#FAC8FB`（高光）；GitHub 的防护 = changelog 的蓝 `#2354D7` / `#0B1B46`；泄露的密钥 = 红 `#FF4D4D`（只表示“危险 / 已泄露”）；自查一场翻成 GitHub docs 的白底 `#FAFAFA`。字：思源黑体 900 + 等宽（日志、分支名）+ 霞鹜文楷批注。
- 底色：钩子到“想拦都没处拦”——近黑（攻击在暗处进行）；GitHub 的闸门——changelog 的深蓝（防护的世界）；自查、换钥匙、结尾——白底（你能做的事，亮起来）。翻底卡在“GitHub 七月起”和“自查”两个词上。
- 贯穿物件：一把钥匙（“你的密钥”）：钩子里变成日志里的红色乱码；规模一场是 850 个账号上的钥匙一齐亮；种分支一场挂在仓库保险柜里；遮蔽一场原样被黑条遮住、base32 后黑条对不上；下走一场被幽灵装进信封顺着“GitHub API”管道飞走；换钥匙一场旧钥匙碎掉、新钥匙插进三把锁；结尾钥匙上挂一个有到期日的吊牌（短期 token）。
- 招牌镜头：第 19–25 秒“遮蔽对不上”：上一行原样密钥被一条黑色遮罩条“啪”地盖成 `***`；下一行同一把钥匙先被幽灵翻成 base32，遮罩条落下却和字形对不上，弹开，整串红字露出、聚光推近（Remotion）。
- 第0帧：CI 日志窗口已在，`Run sync-check` + 第一行红色乱码已打出，大字「你的 CI 日志」，左下「示意画面」。
- 高潮停留：“想拦都没处拦”——防火墙前空空的拦截名单停 1.5 秒；结尾细粒度 token 的到期吊牌停 2 秒（`tailMs` 2000）。
- 和上一支不同：最近三支 late-night-emo（卧室插画 + 情绪曲线）、kimi-k3-1-pro（官方录屏递进）、vibe-opus-video-tutorial（教程录屏）。结构（一把钥匙的旅程）、开场（日志窗口里正在打印的乱码 + 盖章）、招牌镜头（遮罩条对不上）、镜头路线（在一条“管道”上从左到右跟着钥匙走，最后翻进白底）、结尾（一个具体的动作建议 + 到期吊牌）——五项不同；配乐（低频脉冲，到白底换成干净的一个音）也不同。
