## 简报

- 钩子台词：视频里是你妈，开口就要五万，你转不转？（脚本原句）
- 钩子画面：第 0 帧就是一部自绘的视频通话手机：来电人「妈妈」是灰色剪影，画面带红色警示底色、每 0.5 秒撕裂闪一下；红色气泡「急！先转我5万，别告诉爸」弹出；大标题「视频里是妈妈，开口就要5万」；念到“你转不转”时琥珀色「转不转？」落下。
- 核心看点：三招识破实时换脸——①让对方在脸前挥手 / 转侧脸（画面容易扭曲、卡顿）②让他按一下鼻子（真人会变形，AI 经常露馅）③最管用：挂断，用手机里存的号码打回去 + 家里约个暗号；只凭一个视频要钱先别转，拿不准打 110 / 96110。
- 结尾台词：眼见不一定为实。转钱之前，多打一个电话。

## 其他

- 风格：蓝图深底 + 顶部章节条（01 挥手侧脸 / 02 按鼻子 / 03 挂断回拨），全屏 9:16。红 = 骗局和破绽，A 琥珀 = 这一招，B 青 = 安全做法。
