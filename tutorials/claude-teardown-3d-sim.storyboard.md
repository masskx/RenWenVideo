## 简报

- 钩子台词：你对AI说一句话，它就造出一台能一层层拆开的V8。（hooks.md §一 第 3 种：“这不是你以为的”——拆开的发动机不是建模师做的）
- 钩子画面：第 0 帧——作者的 V8 模拟器已经拆开：活塞连着连杆从曲轴上拔出来，红色箭头指着拆开的方向；顶部大字「一句话 → 能拆开的 V8」（红底白字）。
- 核心看点：国外开发者 Elvar 做了一个免费开源（MIT）的 Claude 技能：用大白话描述一台机器，就生成一个离线网页里的 3D 模拟器，每个部件一个按钮，能拆开、剖开、透视；秘诀是“先写模型再画图”，整台机器只由一个数字驱动；起落架用真实数字（据作者：201 mm 齿条，32 齿转 180°）；作者说 2 天做了 7 个，连虚构的沙虫也能造。原帖浏览超过 120 万（6 秒时说出）。
- 收藏点：不需要（案例快讯）
- 结尾台词：以后想看懂一台机器，也许不用真把它拆开。（抖音技巧.md §三 第 3 种：一句翻转的判断；最后一帧回到第 0 帧拆开的 V8，能接回开头）
- 标题·视频号：你对 AI 说一句话，它就造出一台能拆开的 V8
- 标题·抖音：一句话，AI 造出一台能一层层拆开的V8

## 导演

- 模板：lemo/teardown（拆解展示）。为什么是它：选用指南 §〇 把“产品 / 硬件 / 系统架构拆开看”给到 teardown，这支片讲的东西本身就叫 teardown、画面本身就是一台台被拆开的机器。照搬了：§3 深石墨底、机器永远是画面里最亮的东西、只有一个强调色并且只给“量出来的东西”；§4 标签结构固定（锚点圆点 → 细引线 → 底板：两位数编号用强调色、名字、一行等宽规格），一个标签最多带一个口播没说的事实，规格写单位；字幕是底部居中、带软阴影、没有底框的一条；§5 标签画出来（圆点、引线生长、文字滑入 10 px），在机器动之前收掉；§6 镜头永远在走（每个画面都慢推）、关键时刻主体占画面 1/3 以上；§8 原生招式：Dimensions drawn on the thing（起落架齿条上画尺寸线 201 mm，招牌）、The leader that lands on the part（每场一个标签落在零件上）；§7 干净的木琴 / 滴答拟音，每个标签一声 tick。不照搬：three.js PBR 实时渲染和 CAD 管线（我们没有作者的模型文件）、它的键盘样片故事。
- 模板改造：物件：自己用 CAD 渲的 PBR 模型 → 作者自己的实时渲染录屏（静音，只裁中间的机器视窗，竖屏放满上 2/3）（会改性格：不再是“拍出来的产品”，是“别人做的模拟器”，但“数字长在物件上”不变）；强调色：样片橙 #ff6b3d → 作者 V8 模拟器自己的红 #D2142A（取色自 x-v01）；版式：顶部加一条信息带（钩子大字、计数、转述条）；借 lemo/news-package 的下三分之一条做「转述 · 国外开发者 Elvar」，每句第一人称都挂着（审稿要求）；声音：木琴 → 合成 wonder 配乐，高潮落在尺寸线画完那一拍
- 点子：观众以为能拆开看的 3D 机器得找建模师做几周，其实是一个人用大白话让 AI 写出来的——因为它先写模型、再画图。
- 对标：teardown 样片（`code/lemomo-ai__lemo-opuscar/3961ddb/styles/teardown/demo`；学：标签结构、尺寸线、深底亮物、镜头不停；不拿：键盘、PBR 管线、它的配乐）；我们的 kimi-k3-1-pro（10-24，同样是“别人用 AI 做出来的成品”展示片；学：钩子用最震撼的成品；不拿：窗口只占上半屏、底下空的问题）。
- 结构候选：① 成品递进：V8 → 谁做的 → 他怎么说 → 按钮拆解 → 秘诀 → 真数字 → 7 个 → 回到 V8；② 一台机器讲透：只用起落架，从放下到收起，把方法讲完；③ 前后对比：传统建模几周 vs 一句话——没有“传统做法”的可靠数字，不成立。选 ①：素材最强的是“很多台都能拆”，每 4 秒换一台机器正好留人；② 的“真数字”留作招牌。
- 风格：teardown 的系统 + 作者模拟器的颜色。底 #26282D → #0E0F11 径向；字暖白 #F1EFE9（规格 62 %）；唯一强调色 V8 红 #D2142A，只给编号、尺寸线、按钮亮起和钩子大字的底块；标签底板 #0E0F11 86 %。字：思源黑体（名字、字幕）、JetBrains Mono（编号、规格）、Inter Display（大数字）。
- 底色：全片同一个深石墨舞台（模板就是深底），录屏是全片最亮的东西；情绪靠录屏本身的颜色：V8 冷灰、水母浅灰、起落架暖沙、沙虫沙黄，结尾回到 V8 的冷灰。
- 贯穿物件：那台被拆开的 V8——第 0 帧拆着，结尾回来还拆着（接回开头）；中间每台机器都带一个落在零件上的红色标签（01 活塞 → 02 水母 → 03 六足 → 04 齿轮 → 05 沙虫），编号一路数上去。
- 招牌镜头：第 21–23 秒：起落架放下锁住的正面，红色尺寸线从齿条左端画到右端（两端竖线 + 箭头），上面底板升起「201 mm · 齿条 · 据作者」；接着一根引线落到中间那颗黄铜齿轮上「32 齿 · 转 180°」。配乐高潮落在尺寸线画完那一拍。
- 第0帧：拆开的 V8（活塞连杆从曲轴拔出、红箭头）+ 顶部「一句话 → 能拆开的 V8」+ 右下「Elvar｜案例展示」。
- 高潮停留：尺寸线画完后，201 mm 和 32 齿两张标签一起停到第 24 秒（约 2 秒）；最后一句说完 0.3 秒内结束。
- 配乐：wonder，climax = gear（climaxAt 落在尺寸线画完），lifts = model；model 场开头安静 0.3 秒（第二钩子“秘诀是”）。
- 和上一支不同：最近三支 net-six-protocols（iso-infographic）、huashu-motion-1d95（swiss-motion）、mistral-large4-open-weights（telestrator）。结构（成品递进，不是一条路的旅程 / 账单 / 一个时刻三个机位）、开场（真录屏里拆开的发动机，不是代码画的小岛 / 1.95 / 官方柱图）、招牌镜头（录屏上画尺寸线，不是剖开的包 / 小数点 / 画斜纹）、镜头路线（每个录屏慢推 + 硬切，不是等距相机跟拍）、配乐形状（wonder，高潮在尺寸线）、结尾（回到拆开的 V8）——六项都不同。另：账号主持人（IP 形象）只在“我们在说”的三场出现（钩子、介绍、结尾），作者第一人称的几场不出现，免得像是我们做的。
