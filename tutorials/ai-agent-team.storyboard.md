# 一个人带 AI 团队：4 个 agent 自己交接 · 分镜（第二版：导演层重做）

- 来源：Rahul（X @sairahul1）长文《How To Automate Your Work With a Team of AI Agents (Full Setup + Prompts)》 https://x.com/sairahul1/status/2108247331833585700 （2026-10-08）。原文末尾标注 **Paid Partnership**（Teamily AI 合作推广），结尾口播和署名都说明。旁白沿用第一版（CosyVoice 已合成，时间轴不变），画面全部重做。
- 片长 228 秒；配音：百炼 CosyVoice `longsanshu_v3`，语速 1.22；流水线：操作教程（代码绘制）；风格：哑光纸面（`look.theme: "paper"`）。
- 参考：awesome-ai-motion 画廊里 twoclipping《一个形状串起整套 UI》和 stephanlivera《15 秒动态设计自由发挥》。拆出来的关系：**一个形状贯穿、从不切断**（这里是那张任务卡）；暖灰纸面、墨色 + 至多一个强调色；弹簧到处都是、只有一点点过冲；大字、大量留白、一次只发生一件事；快速运动有模糊；没有发光、没有渐变。
- A/B 固定色：A =「交接」（赤陶 `#bf4b2c`：任务卡本身和所有交接弧线）、B =「拍板」（墨绿 `#2d6a4d`：只给“人”）。其余全部是墨色和纸色。agent 不再用 4 种颜色区分，靠图形（放大镜、笔尖、括号、勾）和名字区分。
- 只画口播里说了的东西；Teamily 的界面没见过真图，画面是比喻和示意，不仿它的品牌界面。
- 第一版的问题（用户评价“很差、AI 味很重”）和逐项原因见 `docs/video-craft/导演层.md` 第零节、`踩坑清单.md` 二·五。

## 导演 Brief

1. 目标：给在抖音上用 AI、但还在几个对话框之间复制粘贴的人看。看完记住一句：**agent 做完就交接，人只拍板**。
2. 分镜与主次：起势 = hook、idea、task（0–40 秒，“你是胶水” → “换成一个群”）；发展 = roles 到 ship（建群、群规、接力、审核拦下、人拍板）；收束 = loop、lessons、outro。贯穿全片的主体是**一张赤陶色任务卡**：它被抛来抛去，就是“交接”；它最后落到绿色的人身上，就是“拍板”。次主体是接住它的那个 agent（被砸中下沉、回弹）；背景是慢慢漂的纸纤维。
3. 轨迹与相机：任务卡走重力抛物线（`toss`），从发出者头顶到接收者头顶，接触在关键词上；agent 从上方落到地线上（`drop`，弹一两下）。相机不动——画面变化来自主体自己的过程；舞台不做每句推拉（`look.tour: false`）。末镜定住。
4. 运动与物理：任务卡飞行时沿速度拉长（`squash`）、拖残影（`Smear`）；接触帧接收者压扁 2–4 帧再回弹（`impulse`），影子随离地高度变小变淡、最后恢复。被拒绝时任务卡撞上落下的闸板后反弹回去（碰撞：落点速度反向）。发布按钮在两人之间滑动时，前后两条边用不同弹簧（`twoEdge`），滑动中自然拉长。
5. 材质与光：哑光纸面和黏土质感（`matte`），主光固定左上；每个落地的东西都有接触影（`ContactShadow`）；没有任何发光、彩色渐变、外描边。字只有一个家族（Noto Sans CJK 用粗细分层级，数字用 Inter Display）。
6. 节拍与声音：口播卡点就是重拍；底乐沿用第一版。音效从物理长出来：抛出 whoosh（提前 2–3 帧）、接触 tap（接触帧）、重物落地 thud、闸板 block、纸张 paper、打勾 tick、通过 chime；全部比人声低 12 dB 以上，一秒最多 2–3 个。
7. 禁止项：导演层第九节全部；本片补充——agent 不用 4 种颜色；画面上不写整句口播；不用印章框（结论用大字 + 物体受力表达）；不用聊天气泡堆叠当画面主体。
8. 验收标准：导演层第十一节全部 + 原有门槛；补充——每次交接都看得出“抛出 → 接触 → 接收者下沉 → 影子恢复”；逐帧看 hook 的最后一次交接（拍板）和 block 的碰撞。

## 自查

- 每个镜头都有受力起点和接触帧，卡在关键词上；一句里连着念的项目每项前都有卡点（沿用第一版的卡点，时间轴没变）。
- 同一时刻只有一个主事件；名字、数字、大字都晚主事件 6–8 帧。
- 任务卡贯穿 hook、idea、pushback、chain、block、fix、ship、loop、outro。
- 强调色只有 A（赤陶，交接）和 B（墨绿，人）；agent 不分颜色。
- 转场：大转场用翻页和圆形遮罩，小转场用推移和上推（纸面上不用故障效果）。
- A「交接」字幕出现在 hook、rules、outro；B「拍板」出现在 hook、human、loop、outro。

## 静帧判断

没人可问，按流程自审：16 个镜头各一张收尾静帧 → 修版式 → 开场、中段、结尾 3 张关键词后静帧（164、3771、6607 帧）+ 360 宽 → 用 `frames.mjs` 逐帧看 hook 的“拍板”接触、block 的碰撞、ship 的按钮滑动。

- 观感：纸面 + 墨色 + 两个强调色，一屏一个主体；agent 不分颜色；任务卡贯穿；没有发光、渐变标签、光点粒子、整幅震屏。和参考（twoclipping、stephanlivera）的共同点对上了：大字、大量留白、一次一件事、运动有原因。
