## 简报

- 钩子台词：群里没人@它，它自己发现了一个bug，还提了修复PR。（hooks.md §一 第 3 种：“这不是你以为的”——没人叫它，它自己干了）

- 核心看点：DeepSeek Harness 团队发的《Super-agent 设计探索》是架构思路、不是新产品；人只能同时盯 3 到 5 个会话，所以分两层：Router 只沟通派活、自己不干活，Worker 各开隔离会话干活、向 Router 汇报；官方自测中位数 12.4 分钟 vs 单会话 20.4 分钟，但读缓存 token 2323 万，约 3.8 倍；原型开源，官方写着不是正式产品。“3 到 5 个会话”在第 11 秒。

- 模板：lemo/living-screencast（活的录屏）。为什么是它：选用指南 §〇 把“编程 agent / 开发者工具”给到 ascii-crt / living-screencast；这条新闻的核心画面就是一个产品界面（群聊里 agent 自己回复、提 PR），living-screencast 的“界面全部用代码重画 + 一个像素小精灵代表软件的能动性”正好能把“没人 @ 它也在干活”和 Router / Worker 演出来。照搬了：§1 真实界面重画（群聊逐句转录自官方演示图，不编内容）、窗口浮在柔和壁纸上、像素精灵 = 软件（Router），光标 = 人；§2 像素网格硬边、精灵站在界面元素的上沿；§4 章节胶囊 01–09、字幕放在底部磨砂胶囊里；§5 精灵跳跃有预备和落地压扁、眼睛看向重点；§6 推近 + 暗角聚光（Spotlight freeze）给“那句承诺”、拉远看全窗口；§8 原生招式：Match-cut origin（精灵从 Super-agent 头像位置冒出来）、Cell division（新会话分屏，Worker 精灵分裂出来）、Spotlight freeze（原文第一句、README 第一句）；声音 8-bit 小音效 + 高保真底乐。不照搬：它的样片产品、吉祥物形象。
