## 素材和出处

- `demo-full.mp4`：用户自录的公开 demo（https://adampog.github.io/literal-web-crawler/），静音；工作副本由 `scripts/clips/literal-web-crawler.sh` 生成（30 fps 全片 + 两段补帧慢放 + 封面静帧）。每个镜头右下角「网页演示录屏」。
- 项目：adampog/literal-web-crawler（MIT），链接只写在发布包 README 的出处里，不上屏、不口播（不引流）。
- 事实（脚本 Fact check）：交替四足步态（四条走、四条抓）、撕下的碎片有物理效果、核心是无依赖的纯脚本；demo 控件 Roam / Follow cursor、Rip、Size（0.6–2）、Repair page、Use your own page 都在录屏里；Omarchy（Linux）插件可替换屏保。灵感来源是 YouTube Shorts，口播只说“一位海外创作者的短片”。

## 其他

- 风格：蓝图深底、无顶部章节条，一屏一个录屏框；A 琥珀 = 口播点名的东西，B 青 = 链接 / 修复；demo 自己的霓虹色保持原样。
- 口播改动：结尾“短片——这才叫”的破折号换成逗号（读音停顿一样，避免 TTS 把破折号读成长停顿），其余逐字不变。
- 录屏里贴进去的文字带 `https://example.com`、`https://douyin.com` 字样（示例地址，不是引流链接），画面上能看到，字很小。
- 合规：不说去 GitHub 搜 / 下载，没有资料包 / 评论区 / 主页 / 公众号；没有“最 / 第一”。发布时勾选「内容由AI生成」。
