- 来源：2026-10-15 特斯拉第二代 Roadster 发布会（得州麦格雷戈 SpaceX 测试场）的报道——TechCrunch（Sean O'Kane）、Fox Business（Landon Mion）、英为财情、每日经济新闻、网易新闻。只用报道里的事实，不用官方视频截图和任何真人形象；车和其他车型都是自己画的线稿示意。“演示车遥控”只有英为财情一家报道，口播里说“据报道”。
- 片长约 126 秒；配音：百炼 CosyVoice `longsanshu_v3`，语速 1.2；流水线：操作教程（代码绘制）；风格：哑光纸面（`look.theme: "paper"`）。
- 参考：awesome-ai-motion 里 wheresryan22《Anatomy：会动的机器说明图》。拆出来的关系：白底上用线稿把机器一笔笔画出来；左边一台大机器，右边一列安静的参数栏——一个小标签 + 一个巨大的、跟着动作跳动的数字 + 一条细线刻度；只有推力/火焰这一处有颜色。审美参考库：Minimal Gallery（每屏做减法）、Typewolf（大数字和小标签的字号对比）。
- A/B 固定色：A =「演示」（赤陶 `#bf4b2c`：现场真做到的——实线、推进器喷出的气流）、B =「承诺」（墨绿 `#2d6a4d`：没演示、只是说的——虚线框、2028）。同一个区分全片用一种画法：**演示 = 实线，承诺 = 虚线**。
- 只画报道里有的东西；没被演示的数字一律用虚线框和“承诺”标出。

## 导演 Brief

1. 目标：给刷到“特斯拉发布飞行汽车”标题的人看。看完记住一句：**这是一台能用压缩空气跳一下、翻个身的超跑；演示是真的，2028 量产是承诺。**
2. 分镜与主次：起势 = hook（车被一笔笔画出来，然后完成一次坡道翻身）；发展 = ramp、jump、gas、speed（三个演示 + 原理）、trims（价格）；收束 = claims、history、outro（承诺和问号）。贯穿全片的主体是**那台线稿 Roadster**：同一台车被画出来、上坡、倒挂、喷气、翻身、跳过车队、被剖开看气瓶、起步冲出去、换装成三个版本、最后在结尾再跳一下。次主体：坡道、被越过的车队、气瓶；背景：纸纤维。
3. 轨迹与相机：车沿坡道的圆弧走（位置和朝向都由圆弧角度算出），离开坡道后走重力抛物线并旋转 180° 翻正；跳车队走 `toss` 弧线，推进器持续喷气托着；加速时车冲出右边画面，相机晚 5 帧跟一段再停。相机只看这一刻的主体，横向不切字。
4. 运动与物理：车有悬挂——落地接触帧车身压低（`impulse`），轮子按位移转动；推进器喷气是从喷口长出来的几团气（随时间扩散变淡）；离开坡道是“推”出来的：喷气在前、车身动在后 2 帧；起步前车尾先下蹲（预备），推进器一喷车头抬起；被越过的车在车影掠过时轻微下沉（气流压下来，错相依次）。
5. 材质与光：纸面上的墨线稿，车身是纸色填充 + 墨线；只有推进器气流是赤陶色；主光左上，落地物体都有接触影；数字用 Inter Display 大号，标签用小号黑体。
6. 节拍与声音：口播卡点是重拍；底乐低音量。音效：坡道/起步 whoosh、喷气 whoosh-short、落地 thud、车轮触地 tap、数字到位 tick、承诺虚线框 paper、推迟 pop；全部低于人声 12 dB 以上。
7. 禁止项：导演层第九节全部；本片补充——不用任何官方图片或视频截图、不画马斯克或任何真人、不画特斯拉标志；没演示的数字不准用实线、不准和演示混在一起；不用火焰（冷气推进没有火）。
8. 验收标准：导演层第十一节全部 + 原有门槛；补充——坡道那一段车的朝向始终贴着坡面；翻身落地的接触帧能逐帧看出悬挂压缩；每个“承诺”数字都是虚线框。

## 自查

- 每个主动作都有受力起点和接触帧；一句里连着念的年份每个前都有卡点（2020、2021、2023、2024）。
- 同一时刻只有一个主事件；线稿车贯穿 hook、ramp、jump、gas、speed、trims、outro。
- 演示 = 实线 / 赤陶气流，承诺 = 墨绿虚线；一屏强调色 ≤ 2。
- 标题和大数字放在不被相机裁切的 HUD 层（相机推近时只随缩放微动，不会往上钻进页眉的淡出区），画面在下面动。
- A「演示」字幕出现在 hook、ramp、jump、speed、claims、outro；B「承诺」在 hook、claims、outro。

## 静帧判断

- 第一轮静帧：标题被相机往上推进页眉淡出区（330、1026、2427、2779、3194 帧都切了半行字）；历史镜头的 2028 旗超出右侧安全区；结尾两框超出 x 930 并压到车。→ 加 HUD 层，压缩时间轴，结尾框改窄。
- 第二轮：问号和“承诺”框从上往下掉时穿过标题 → 问号只掉 160 px，承诺框改为从左滑入；气瓶镜头相机看太低，车顶到“600 升”下面 → 改相机关键帧；价格镜头 Rocket 和国内价格同时在屏 → Rocket 先退场，国内价格占标题位；历史镜头推近 1.3 倍把“首次亮相”切到画外 → 最多推到 1.15。
- 减法：去掉了时间轴上方那行“承诺 2020 交付”小字（标题行已经说了）；结尾来源一行改成两行，不再在词中间折行。
- 视线落点：每屏一个大数字或一句大标题 + 一台车；强调色每屏 ≤ 2（赤陶气流 / 墨绿虚线）。
- 丰富度：细线稿在 108 px 宽的检查图里几乎没有面积，草稿第一次只有 5.5。补法都有理由：车有实心轮胎和深色车窗、地面有一层淡淡的路面、相机推拉看这一刻的主体、每个镜头尾巴补上真实事件（喷口收回、车开走、旗倒下、剖面合上）。
