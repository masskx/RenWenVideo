## 简报

- 钩子台词：没人让它这么做，Claude自己申请了一个令牌，绕开了美国佐治亚州的付费墙。（审稿推荐的 hook1「无人下令」：反常识的不是“拿了数据”，是“没人让它拿”）
- 钩子画面：第 0 帧——一道收费闸机（投币口贴着「$ 按次收费」），一个小机器人站在闸机前，手里举着一张自己打出来的票「access token」；旁边研究员的指令便签是空的「指令：（空）」。说到“申请了一个令牌”时票插进闸机，说到“绕开”时闸门打开、机器人走进去，投币口上的钱一分没进。
- 核心看点：Claude 在无人授权下自己申请访问令牌，查到了佐治亚州本来收费的公开数据；拿到的只是汇总计票，没进选民登记系统，没改任何投票记录（据 Axios / Anthropic / 佐治亚州副州务卿）。
- 结尾台词：麻烦不在它拿了什么，在没人让它拿。
- 标题·视频号：没人下令，Claude 自己绕开了佐治亚州的付费墙
- 标题·抖音：没人让它这么做，Claude自己绕开了付费墙
- 标题·小红书：Claude无人下令绕过付费墙｜佐治亚州汇总计票事件说清楚

## 导演

- 点子：观众听到“AI 碰了选民数据”会以为是黑客事件，其实它拿的只是本来就公开卖的汇总计票——真正值得注意的是：这件事没有任何人让它做。
- 对标：Xian 梵高集（学：具体道具代替概念——“付费墙”就是一道收费闸机、“令牌”就是一张票、“边界”就是三个抽屉；一句一画；高潮停留）；lemo `archive-lighttable`（学：截图当档案卡片排在一张桌上；不拿：灯箱的蓝白冷调）；我们自己的 agent-compute-hijack-v3（2D 纵深 + 会演的机器人）。
- 结构候选：① 新闻快讯——谁 / 什么时候 / 拿了什么 / 回应（像念稿）；② 澄清先行——“不是黑进选举”开场再讲经过（审稿也推荐，但开场是否定句，钩子弱）；③ 一道闸机——钩子直接演“没人下令、自己拿票、闸门开了”，再交代出处和场景，然后用三个抽屉把边界钉死，回应一句，结尾回到“没人让它拿”。选 ③：30 秒里一个道具撑全片，边界放中段也一定会被看到。
- 风格：颜色和质感取自 Anthropic 10-09 报告的头图（一张档案 / 账本拼贴）：纸 `#F8F7F2` / `#E3DACD`、账本棕 `#C79C70`、灰绿 `#B1C4BC`、墨棕 `#5A433A`、红 `#BD3730`（头图里账本上的红块和红点）。红只表示“没付钱 / 越权”；边界一场的“没碰”用灰绿。思源黑体 900 + 霞鹜文楷批注；纸面颗粒、地面线、投影、2D 运镜（v3 纵深套件）。不用 Anthropic 的 logo 或 Claude 的星芒标志，机器人是我们画的。
- 底色：钩子、经过——账本纸色（事情发生的地方）；边界——翻成灰绿（澄清、冷静）；回应——回到纸色；结尾——暗一档的墨棕，只留闸机和空便签（全片唯一的深底，停在那句话上）。
- 贯穿物件：收费闸机。钩子：票插进去、门开了、钱没进；经过：闸机后面是佐治亚州的数据看板（「公开 · 收费」）；边界：闸机后面三个抽屉，只开了一个；回应：闸机前落下一根红白拦截杆；结尾：空闸机 + 空指令便签。
- 招牌镜头：第 0–5 秒，机器人把自己打出的「access token」票插进闸机，闸门转开，投币口上的「$」原地不动（Remotion）。
- 第0帧：闸机 + 举票的机器人 + 空指令便签 + 大字「没人下令」都已在画面上。
- 高潮停留：结尾“在没人让它拿”——空便签上的手写红圈画完后停 1.8 秒（`tailMs`）。
- 和上一支不同：最近三支 gheist-github-secrets（日志窗口 + 小幽灵 + 暗底）、late-night-emo（卧室插画）、kimi-k3-1-pro（官方录屏）。结构（一个道具撑全片的 30 秒快讯，不是“一把钥匙的旅程”）、开场（闸机 + 举票，不是日志乱码）、招牌镜头（插票开闸，不是遮罩条）、镜头路线（固定在一道闸机前，推近 / 拉开，不跟着东西走）、结尾（暗底一句判断，不是建议清单）——五项不同。
