# AI为什么敢说你有大问题 · 分镜

> 目录名 / id 只是内部标识；片中、封面、发布文案都不出现任何 AI 产品名，一律写「AI助手」。

## 简报

- 钩子台词：检查说你没事，AI助手却说你可能有大问题。你信谁？（脚本原句）
- 钩子画面：第 0 帧就是左右分屏——左边一张自绘报告单 + 绿色对勾「检查：没事」，右边自绘机器人「AI助手」+ 红色闪烁气泡「可能有大问题」，中间一道闪电裂缝；念到“你信谁”时琥珀色大字「你信谁？」落下。
- 核心看点：约七成医生遇到过拿着 AI 答案来看病的人（复旦大学老龄研究院调研）。AI 敢这么说有两个原因：① 幻觉——按概率往下说，通顺不代表对；② 只看到你打的几句话，81.33% 的医生认为最大问题是缺乏个体化。AI助手用来整理情况、列问题、看懂术语；诊断和用药交给医生。
- 结尾台词：AI帮你把问题问清楚，判断，留给医生。
- 标题·视频号：检查说没事，AI说有大问题？AI为什么敢这么说
- 标题·抖音：AI为什么敢说你有大问题？
- 标题·小红书：AI看病靠谱吗｜AI助手为什么会说你有大问题？2个原因

## 其他

- 规则（脚本 Hard rules）：不出现任何 AI 产品名；不给医疗建议、不举症状、不评价医生；只讲幻觉和缺乏个体化两个原理。画面全是自绘扁平动画：没有医院 / 医生照片、没有 CT / X 光、没有 App 界面和任何 logo、没有红十字（白大褂上没有任何标志）。门诊告示恶搞图不用。
- 数字出处（中新网 2026-10-21 报道的复旦大学老龄研究院申琦团队调研：75 位医生 + 143 位居民）：约七成医生遇到过用 AI 查健康信息的患者；81.33% 认为 AI 健康建议最大的问题是缺乏个体化。屏幕上的出处行写「复旦大学老龄研究院调研 / 75位医生」。
- 幻觉场景里的那句话（「你说的 情况 可能 是 大问题」）和候选词是示意，不是任何真实 AI 的输出；长短条不带数字。
- 配色：绿 = 检查结果，红 = 吓人的回答 / 看不到的信息，青 = 用好 AI助手，琥珀 = 交给医生。
