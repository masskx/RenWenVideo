## 简报

- 钩子台词：几百篇论文共用的一个前提，OpenAI说，被它的AI推翻了。（hooks.md §一 第 1 种：反常的事实 + 数字；“几百篇”是 OpenAI 原话 "hundreds of papers"）

- 核心看点：OpenAI 声称它的模型给出了一个 3-SAT 的次指数算法（2^{n/(log n)^{1/2+o(1)}}），推翻 ETH，并用 Lean 做了机器验证（验证的是稍弱的界）；它仍比多项式慢得多，不等于 P=NP，也没有实用加速的结论；ETH 的提出者本人带头核查，但公开信写明“参与不等于认证”。

## 导演

- 点子：观众以为“AI 推翻了一个计算机大难题”就等于“破解一切加密、软件全变快”，其实它只是证明 3-SAT 能比指数时间快一点——仍比多项式慢得多，而且连提出者本人都说：我们在核查，不是背书。
- 对标：3Blue1Brown 式的“一张图讲清楚”（huashu `math-3b1b` 的语法：一条曲线变形成下一条、关键点标出；不拿：黑板配色）；Xian 梵高集（具体道具：“前提”就是一块基石、“几百篇论文”就是一座纸塔、“核查”就是三张名片）；agent-compute-hijack-v3 的 2D 纵深。
- 结构候选：① 新闻快讯——谁、发现了什么、专家怎么说（平）；② 从“ETH 不是以太坊”的梗开场（好笑，但第一句没有事实和数字，hooks.md 判不过）；③ 一块基石：钩子里基石裂开 → 讲清它是什么（一条指数曲线）→ 新算法把曲线压下来（招牌）→ 二次钩子“先别激动”把三条曲线摆一起 → 核查的人和公开信 → 回到基石：裂了但塔没倒，结论待定。选 ③：一张图讲清“快了多少、没快多少”，避免误读。
- 风格：图表世界 + 纸塔道具。颜色从素材取：OpenAI 官方题图的暖渐变（黄 #FBC137 → 桃 #FAA675 → 粉 #FCA29A）= “OpenAI 的说法”；论文 PDF 的纸白 #FFFFFF / 墨黑 #111111 = “论文 / 事实”；GitHub 的链接蓝 #0969DA = Lean 验证；深底 #14161C 用在钩子和结尾。红只给“指数爆炸”那条曲线。字：思源黑体 900 + 等宽（公式、代码）+ 霞鹜文楷批注。
