# Claude Duet：AI 凭什么能主动找你 · 分镜

## 简报

- 钩子台词：你还没开口，AI先来找你了。（脚本原句）
- 钩子画面：第 0 帧就有一张正在滑下来的通知卡（铃铛图标 +「AI 助理」+「早上好，今天有 3 件事需要你处理」），第 10 帧抖一下；背景是模糊、压暗的刷手机素材；标题「你还没开口，/ AI 先来找你了」。
- 核心看点：Claude Duet 能主动干活靠三个机制——① 记忆（沿用 Claude 里的记忆、技能、已连接的应用）② 定时任务（每隔几个小时检查一次，云端虚拟机，关了手机也能干）③ 关键步骤等你确认（发消息、付款、签文件、删除前先给你看）；难的是把它们拼成一个靠得住的系统。
- 结尾台词：AI可以主动，但最后那一下，还得你来按。
- 标题·视频号：AI开始主动找你干活了：Claude Duet背后的三个机制
- 标题·抖音：你还没开口，AI先来找你了
- 标题·小红书：Claude Duet是什么｜主动型AI助理的3个关键机制
