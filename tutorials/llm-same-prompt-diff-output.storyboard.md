## 简报

- 钩子台词：同一句话问AI一千遍，随机性关到0，还是出了80种答案。（hooks.md §一 第 1 种：荒唐的事实 + 数字）
- 钩子画面：第 0 帧——白板上已经写好一张提示词卡「Tell me about Richard Feynman」（磁铁压着）和「温度 = 0」，大字「×1000」正写到最后一笔；1.2 秒起卡片右边一条条回答线扇形散开，2.4 秒橙色笔写下「80 种」并画圈（圈过头、没闭合）。
- 核心看点：Thinking Machines 拿 Qwen3-235B，温度 0、同一句提示词跑 1000 次，得到 80 种不同的回答；前 102 个 token 都一样，第 103 个分岔（992 次 “Queens, New York”，8 次 “New York City”）；主因不是“GPU 并行谁先算完”，而是服务器把同一时刻很多人的请求拼成一批，批的大小一变，加法的顺序就变；电脑里的小数换个顺序加结果会差一点点（(0.1 + 1e20) − 1e20 = 0，0.1 + (1e20 − 1e20) = 0.1）；改成“批多大都按同一顺序算”以后，1000 次一模一样，但更慢（另测 Qwen-3-8B：26 秒 → 42 秒）。
- 收藏点：不需要（原理快讯）
- 结尾台词：所以答案变了，可能不怪你问的，怪那一秒，还有谁在问。（抖音技巧.md §三 第 3 种：一句翻转的判断；最后一帧回到提示词卡，接回第 0 帧）

## 导演

- 模板：lemo/whiteboard（白板讲解）。为什么是它：这是一条“原理讲解”（选用指南 §〇 的表：原理 / 论文 / 概念讲解 → whiteboard），而且原理本身就是一步一步“写出来”的：一句提示词 → 一千条回答 → 一个分岔 → 一批请求 → 一道加法。照搬了：§1 一块有光泽的白板，所有东西当着观众用白板笔按笔顺写出来；白板是一张地图，每个想法占一块地方，镜头在区域之间走（板上的距离 = 论证里的距离），没有手、笔自己飘、有投影；磁铁是唯一能动的东西；§2 暖白底、浅灰的旧字残影、一道比镜头慢的斜向反光（“光泽感”就靠它）、墨水正片叠底、笔画有手抖、起笔有墨点、圆画过头不闭合；§3 最多三种笔色、每种意思全片不变；§4 字幕是板上的米白圆角标签 + 一小段强调色笔划（look.captions "label"）、术语在口播说到的那一刻写完；§5 每一笔慢-快-慢、按时间窗口写完；§6 一块大白板 + 2D 镜头：跟着笔走、横移、回到前面的区域、最后拉远看全板；§7 每一笔都有声音（笔划沙沙声）、磁铁吸上去的咔哒、“两份同一段旋律在两个速度上”的思路表示分岔；§8 原生招式：按笔顺写、笔带镜头、磁铁、橡皮擦倒带、全板一览。不照搬：它的爱因斯坦 / GPS 故事、它的单线英文字体、它的配乐。
- 模板改造：配色：模板示例三色 → 原文图自己的颜色：墨黑 #23262C 画结构、TM 图里的蓝 #009DE4 画“请求和批”（过程）、TM 图里的橙 #F78427 只画“分岔 / 不一样”（要紧的那一个），外加原文两种底色的荧光笔块（#F8F8D1 = 不确定、#E3EEB0 = 确定）铺在对应区域下面；材质：只有手写 → 板上用磁铁压着原文的打印件（TM 的“别人的请求”图、vLLM #17166 的提问截图），借 `lemo/archive-lighttable` 的“证据钉在板上”，每张带出处；招牌：两支笔二重奏 → 在第 103 个词那里一支笔分成两支，两条线按次数画粗细（992 粗、8 细，借 `lemo/dataviz` 的“粗细就是数量”）；节奏：模板是 111 秒的慢课 → 45 秒的快课，写字速度约模板的 2 倍，镜头多用“跟笔”少用“停”；声音：模板的配器 → 我们的合成配乐 playful（拨弦 + 拍手，接近模板的“发条极简”），高潮在橡皮擦掉细枝、1000 次合成一条线的那一拍
- 点子：观众以为 AI 同一个问题答案不同是因为“它在随机发挥”，其实把随机关掉也会变——因为同一时刻别人也在问，你的请求和别人的被拼成一批，批一变，加法顺序就变，小数换个顺序加就差一点点。
- 对标：whiteboard 样片《Einstein in Your Pocket》（学：按笔顺写的公式、笔带镜头、磁铁当主角、全板一览收尾、每一笔的声音；不拿：GPS 故事、单线英文字体、111 秒的长度、配乐）；我们的 openai-eth-false（学：一张示意图讲清一个反直觉的数学点，15 秒左右的第二个钩子；不拿：纸塔道具）。
- 结构候选：① 一个谜底：80 种答案 → 分岔在哪 → 常见解释被划掉 → 真凶（别人的请求）→ 加法顺序 → 修好 → 回到提示词卡；② 一次拆解：一条回答沿着推理流水线往回走（采样 → 模型 → 批 → 加法）；③ 前后对比：左半板“温度 0 但不确定”，右半板“批不变以后确定”，两支笔同时画。选 ①：它天然有“常见解释被划掉”的反转（第二个钩子），模板 §11 的“橡皮擦倒带”正好落在“修好”那一步；③ 的左右对比用在修好那一场的局部。
- 风格：whiteboard 的系统 + 原文图的颜色。板：暖白 #F7F6F1 → #EFEDE6 渐变、20 多个浅灰残影（旧公式、箭头、圈）、一道斜向反光以 0.35 倍镜头速度漂；墨：黑 #23262C（结构、普通字）、蓝 #009DE4（请求、批、流程箭头）、橙 #F78427（分岔、不一样的那个词、“80 种”）；荧光笔块：#F8F8D1（不确定区）、#E3EEB0（确定区，修好那一场）。字：霞鹜文楷（板上的中文、字幕）、原文里的英文用 TM 的衬线感（Georgia / 思源宋体）写在提示词卡和 token 上、数字用霞鹜文楷。

- 招牌镜头：第 6–13 秒的分岔：镜头跟着一支蓝笔沿一排 102 个小方格横移（格子一个个被画出来，计数器滚到 102），到第 103 格笔分成两支橙笔：上面一条粗线写「Queens, New York」+「992」，下面一条细线写「New York City」+「8」。修好那一场（约 33 秒）橡皮擦把细的那条倒着擦掉，只剩残影，「1000 / 1000」写在粗线上——配乐高潮落在擦完的那一拍。
