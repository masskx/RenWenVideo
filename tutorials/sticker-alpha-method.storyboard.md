# 一个角色 → 一整套透明表情包 · 分镜

## 简报

- 钩子台词：一张角色图，变成一整套能直接发的表情包，还是透明底的。这套方法，任何一个生图模型都能用。（脚本自带钩子 A，没换）
- 钩子画面：第 0 帧就是「一张图 → 一整套表情包」+ 示范聊天（工作群（示范对话））里已经发出的「我马上看」表情，0.5 秒内再弹出「辛苦了」「下班快乐」；「还是透明底」时聊天底色连换深 / 浅 / 橙 / 蓝，表情没有白框；「任何生图模型」时 V05 欢呼动图弹出
- 核心看点：4 步：定角色（不带字的定稿、缩小看）→ 换动作（每次用同一张定稿当参考，只换最后一句动作）→ 做透明底（Alpha 通道；说了透明 ≠ 真透明；棋盘格画进图里是假透明）→ 验收（深 / 浅 / 彩色底、别一键删白、缩到 1/4）
- 结尾台词：先做四张，发进聊天里试试。
- 标题·视频号：AI做专属表情包，4步搞定透明底
- 标题·抖音：一张角色图，做出一整套透明表情包
- 标题·小红书：AI做表情包｜角色不跑偏+真透明底

## 计划

时长按脚本放宽（`maxSeconds` 100；脚本目标约 90 秒）。顶部章节条：01 定角色 · 02 换动作 · 03 透明底 · 04 验收 · 05 用起来。

## 素材和出处

- 全部角色图、动图都是素材包里按这套方法用 AI 现做的示例，片中标「AI 生成示例」；没有真人、品牌、真实联系人。
- 示范聊天按 E02 的样子在片子里重搭（用真透明表情 C0x_sticker_alpha），为了让表情逐个弹出、并避开右侧按钮区；标题仍是「工作群（示范对话）」。
- 链式参考的「跑偏」和像素格里的 Alpha 数值是示意图，不是真实生成结果；quarter 里「字太小」那张是用 A03 现场拼的示意。
- 「有的模型能直接出透明 PNG」只说到这一层，不点名任何模型（脚本 §6 / 素材 README §七）。
- A00 反例只在缩小对比里出现，宽度不超过一半。
