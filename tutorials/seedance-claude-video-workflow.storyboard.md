## 简报

- 钩子台词：AI视频里，杯子会自己慢慢变大，问题常常出在生成之前。（hooks.md §一 第 2 种：一个反常的画面 + 原因悬念；例子取自原作者长文）
- 钩子画面：第 0 帧——白板上一格“生成的视频（示意）”，杯子正在长大、时间码在走；0.9 秒红笔圈住杯子，写「自己变大？」。
- 核心看点：原作者让三个 AI 分工（Claude 导演写分镜和所有提示词、Codex 画首尾帧、Seedance 把首尾帧变成几秒视频，人负责选方向、批准花钱、看动态、听声音）；首尾帧里不一样的东西，视频里会慢慢变（原话：杯子大了一点，视频里杯子就会慢慢变大；墙的颜色不一样，墙就会慢慢变色）；提交前把首尾帧叠起来看；导演侧四个 agent，审核只挑错、写“通过”才提交；生成后每镜取多张全分辨率帧、切点前后各取 3 帧，动态和声音交给人。
- 收藏点：结尾整面白板（四步：分工 → 叠首尾帧 → 审核“通过” → 复核），停 1 秒可截图。

## 导演

- 模板：lemo/briefing-board（工程简报板：一面白板、磁贴标签、三色马克笔、印章、最后拉回整面墙）。为什么是它：这条讲的是一套生产流程——谁负责什么、哪一步要检查、什么时候盖“通过”，正是简报板“把计划钉在墙上、一条条核”的语法；选用指南 §〇 没有“工作流方法”一行，按 `find.mjs` 和题目最近的“系统拆开看 / 原理讲解”挑了它。照搬了：§1 一面实体白板（搪瓷、擦掉的旧字残影、滑动反光、铝框和笔槽）、真东西做照片、三色墨水各有含义（石墨 = 名字和规则，蓝 = 测量 / 被检查的东西，红 = 判定）、一面连续的墙、最后才看全墙；§2 磁贴落下摆动、马克字逐字写出、印章砸下回弹、手持呼吸 ≤ 3 px、颗粒；§4 字幕 = 底部磨砂亚克力条 + 蓝色笔记号；§5 运镜重叠缓动、每 1–2 拍落一个东西；§6 沿线滑行、判定镜头、长拉回；§8 原生招式：投影线（首帧 → 尾帧）、印章、整墙揭示；§9 文字停在镜头停的地方。不照搬：抠图照片（这条没有可用的实物照片，按 §10 “没有可授权照片就用马克笔画草图”——首尾帧和预览画成草图并标「示意」）、24 fps（我们 30 fps）、空调底噪。
- 模板改造：蓝墨水取即梦示例水母片的蓝 #1F6FD0（被检查 / 测量的东西：首尾帧 → 视频、每镜帧），红只给判定（圈差别、通过、交给人）；原生招式“投影线”换成“叠帧”——尾帧那张从右滑到首帧上、半透明叠住，三处差别（杯子大小、墙色、把手左右）当场圈出（招牌）；照片层 = 唯一一段真实素材（网友照此思路做的咖啡广告 4 秒，静音、标「@kuibenge｜案例展示」），像打印照片一样钉在“Seedance”旁边；结构用模板 §11 的“清单一项项盖章”；配乐 news 104 BPM（模板要小编制、有节奏，不要钢琴铺底），高潮落在叠帧
- 点子：AI 视频里莫名其妙的变化（杯子变大、墙变色），很多是首尾帧本身就不一样——模型只是把差别“补”成了动作；所以检查要放在生成之前：叠首尾帧、让审核 agent 挑错盖“通过”，生成后再按切点抽帧、动态和声音交给人。
- 对标：briefing-board 样片（`code/lemomo-ai__lemo-opuscar/…/styles/briefing-board/demo`；学：磁贴、三色墨水、印章、整墙拉回；不拿：照片抠图、建筑尺寸线）；我们的 nrta-ai-duanju-regulate（上一支；学：一个世界一个机位、读的东西停在镜头停的地方；不拿：灯台、放大镜、原件截图）。
- 结构候选：① 反常画面（杯子变大）→ 分工 → 机制（模型补中间）→ 叠帧（招牌）→ 审核盖章 → 复核 → 动作；② 按长文的 8 步顺序讲——36 秒讲不完、像念目录；③ 只讲四个 agent——丢了最有用的“首尾帧差别 → 动作”机制。选 ①。
- 风格：briefing-board 系统。白板 #F5F6F3，墙 #8F8B85，石墨 #2B2D31，蓝 #1F6FD0，红 #D2342B，灰 #9A9DA2；字：霞鹜文楷（马克字）、思源黑体（磁贴、字幕）、IBM Plex Mono（时间码）。
- 底色：全片一面白板，灰墙在外；情绪靠墨水颜色：红只出现在判定上。
- 贯穿物件：那只杯子——钩子里自己变大，首尾帧里大小不同，叠帧时被红圈圈住，结尾整面墙上被大红圈框住。
- 招牌镜头：第 15–21 秒（overlay 场）：尾帧整张从右滑到首帧上叠住（半透明、红框），三处差别依次红圈：杯子大小、墙色、把手左右，最后砸下印章「不该变的必须一样」——配乐高潮落在这一拍。
- 第0帧：近景“生成的视频（示意）”一格：杯子正在变大、时间码 00:00、红色进度线。
- 高潮停留：印章落下后停约 1.5 秒（overlay 场尾）；最后一句说完 0.3 秒内结束。
- 配乐：news（104 BPM），climax = overlay，lifts = roles、review。
- 和上一支不同：最近三支 nrta-ai-duanju-regulate（archive-lighttable）、us-ai-datacenter-pause（dataviz）、openssh-musl-auth-bypass-ai（ascii-crt）。结构（反常 → 机制 → 检查清单，不是误读 → 对出处 / 规模 → 三州 / 原帖 → 推演）、开场（一格示意视频里杯子变大，不是放大镜压原文 / 点阵 / 终端）、招牌（叠帧圈差别，不是 0 处 / 兆瓦变房子 / 电路命中）、镜头路线（一面白板上下滑行 + 判定镜头，不是灯台俯拍 / 纸面推拉 / 字号推近）、配乐形状（news 有节奏，高潮在叠帧）、结尾（整墙揭示 + 红圈，不是灯台熄灭 / 回到点阵 / 自查）——六项都不同。
