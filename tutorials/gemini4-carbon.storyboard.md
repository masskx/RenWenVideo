## 导演

- 模板：lemo/dark-keynote（暗场科技发布会）。为什么是它：这是一条“新模型发布”（选用指南 §〇 的表：新模型 / 新版本 / 发布会 → dark-keynote），而且这条新闻的戏剧性正是发布会式的：一个巨大的数字、一个按钮、一道光。照搬了：§2 舞台（近黑底、上中部径向提亮、一团偏离中心的冷光、50 % 角部暗角、48 px 发丝网格，白 3 %、每第 4 根 6 %，不加颗粒）、UI 全部代码画（圆角窗口只有小图标和标题，没有红绿灯、菜单栏；通知卡、徽章、列表行），三级抬起的暗面 + 1 px 边 + 1 px 顶部内高光；§3 一个强调色只给“产品是什么 / 做什么”（59、亮起的那一行、确认），问题色只在问题存在时出现；§4 Inter Display 600 巨大数字（字距 −4.5 %）、JetBrains Mono 标签和状态字、**字幕是一个 UI 组件**（底部居中的暗色半透明药丸 + 1 px 亮边 + 强调色“说话中”小圆点，0.16 秒上浮淡入）、大数字单独一屏且不压字幕；§5 一切落在网格和节拍上，快出 + 一次小过冲（back 1.3）立刻停稳，生成元素 0.2–0.3 秒落下 / 弹出，消失是“设计过的”（一拍收一件、CRT 关机压成一点）；§6 转场 = UI 展开 / 收拢（没有淡入淡出、没有空帧），推近穿过定格、回到前面的构图做前后对比；§7 调音的打击乐 + 垫子、两种声音家族（乱 = 散、产品 = 同一个调里）、静音是工具；§8 原生招式：数字从乱码里落定、光扫揭示、定格 + 数字静音。不照搬：它的 Tidy 故事、光标主角、桌面图标堆积、片尾卡。
- 模板改造：配色：模板示例强调色（青柠 / 电紫 / 信号橙）→ Carbon 官方主视觉的天蓝 #4EABEB（水晶和 Google 竖版主图里最亮的那层蓝，取色见下），舞台的近黑往 Google 主图最深的海军蓝 #03245B 偏一点（模板要“偏蓝的中性”，这里干脆用素材的深蓝）；材质：模板“没有实物、只有界面”→ 官方水晶主视觉当“产品”，只出现一次，被光扫亮（会改性格：多了一个实物，丢了“纯界面”的冷，换来片子和 Google 自己的发布物是同一个东西）；证据窗口：模板“全部原创 UI、不放真软件”→ AA 榜单图和 Google 官方跑分表裁成局部，装进模板的圆角窗口里当证据，每个窗口带来源标签（借 `lemo/caption-news` 的“每张别人的画面都带出处”）；原生招式换一个：生成的堆积（Generated accumulation）→ “权限清单”：四行用户类型按网格打出来，只有「网安防御方」一行亮成强调色，其余三行停在暗处、状态字「尽快 · 无日期」（这条新闻的核心不是“东西多”，是“谁能用”）；声音：模板的马林巴相位 → 我们的合成配乐 wonder（利底亚、十六分琶音、钟琴感的拨弦，接近模板的调音打击乐），高潮落在权限清单那一行亮起的一拍
- 点子：观众以为“榜单第一 = 我马上能用到最强的 AI”，其实这个第一名这周只先给一部分网安防御方，开发者和普通人要等，没给日期——因为它最强的一项恰好是网络安全。
- 对标：dark-keynote 样片《Room to Think》（学：数字单独一屏从乱码落定、光扫揭示、UI 展开 / 收拢当转场、字幕药丸、每个元素落在拍子上；不拿：Tidy 的故事、光标主角、桌面堆积、片尾卡、配乐）；我们的 openai-eth-false（学：15 秒左右“先别激动”式的第二个钩子；不拿：纸塔基石的道具）。
