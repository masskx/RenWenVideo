## 简报

- 钩子台词：你现在看的这条视频，没开过剪辑软件，每一帧都是 AI 写代码画出来的。
- 钩子画面：第 0 帧就是一面 2×3 的“片墙”——六种风格的代码成片（mg-styles-15 的扁平、线条、形变、包豪斯、回形针、像素）同时在播，顶上一个帧计数器 `f 0000` 在跳；说到“每一帧都是代码”时，一条蓝色扫描线从上往下扫过片墙，扫过的格子翻成它背后的代码（深灰代码块），计数器旁弹出 `renderAt(t)`。

- 结尾台词：最后一个建议：先挑一种风格，只做十秒，让另一个 AI 挑毛病，改两轮，再去做长片。

## 导演

- 点子：观众以为 #Vibe知识大赏 里那些好看的动画是“AI 生成视频”，其实是模型在写代码——写一个网页、一帧一帧截图、拼成视频；所以它能学、能改、能复制，四步就能上手，难的只是提示词和返工。
- 对标：① mg-styles-15 作者自己的 15 种风格合集（`x_vincent_15styles`）——学：每段“左边作品、右边一行风格名”的展柜式节奏、作品永远是主角、片尾一面作品墙；不拿：横屏版式、它的字体和深棕底。② 库里 lemo `living-screencast`——学：窗口浮在底上、软投影、推近到发生的地方；不拿：吉祥物、重画 UI。③ Xian 梵高集——一句一画、数字代替形容词、底色随情绪、高潮停留。
- 结构候选：① 新闻解读（发布 → 参数 → 案例 → 结论）：最常见，像念 PPT，不选；② 一支片从成片倒放回代码：好看，但讲不了教程和经验，3 分钟撑不住；③ Hook → Why → Process → Essence → Tips（meng shao 知识区结构）放大成五章：钩子（这条片本身就是代码）→ 为什么现在（话题 + Opus 5.5 + 15 种风格 + 官方下场）→ 本质（网页 → 截图 → 拼片）→ 四步上手 → 提示词三块 → 翻车和评委 → 我自己的四招 → 别的模型也行 → 一个建议。选 ③：用户要“教程 + 经验 + 委婉提别的模型”，这个结构每一章都有一段真素材或一个具体物件撑着，3 分钟里每 2–4 秒有新东西。
- 风格：mg15 `19-paperclip`（贴纸式拆解：东西被拆开、贴上标签）+ lemo `living-screencast` 的窗口语法，叠 v3 的 2D 纵深（光照地面、`ContactShadow`、`camAt` 推拉）。颜色全部取自素材（`node scripts/qa/palette.mjs`）：Remotion 文档的白 `#FFFFFF`、代码块深灰 `#22242D`、链接蓝 `#2B93F2`（全片唯一强调色 = “一条命令 / 一个步骤 / 代码”）、灰 `#B4BCC5`；Anthropic 页面的象牙白 `#F9F8F4`、墨 `#141313`、Claude 星芒的陶土橙 `#DE7356`（只在讲 Anthropic / 官方时出现）；mg-styles-15 流程图的近黑 `#09090B` / `#141217`、沙色 `#D8D5C7`、赤陶 `#C26C4A`（只在讲 15 种风格时出现）；DeepSeek 品牌蓝 `#4D6BFE`（只在对比一场）。红 `#E5484D` 只表示翻车 / 错误。账号层：思源黑体 900 数字、霞鹜文楷批注、底部逐字字幕。
- 底色：钩子、本质、提示词、我自己的四招、结尾——代码深灰 `#22242D`（“代码的世界”）；话题和 15 种风格——流程图近黑 `#09090B`（“作品的世界”，让作品的颜色跳出来）；Opus 发布、Claude Motion——象牙白（官方的世界）；四步上手、翻车与评委、别的模型——文档白（讲事实、教程，透气）。章与章之间翻底，是观众看得见的分章。
- 贯穿物件：一张“帧卡”——一帧画面和它背后的代码是同一张卡的两面，蓝色扫描线一扫就翻面：钩子里把片墙翻成代码；本质一场里网页被一帧帧“拍”成帧卡、排成胶片、拼成 mp4；提示词一场里提示词文件被扫成三块；我自己的四招里，我们自己的片被扫回分镜表；结尾帧卡翻回来，计数器停在这支片的总帧数。
- 招牌镜头：本质一场（约 44–51 秒）：深灰底上一个浏览器窗口在播一支代码片，相机快门一闪一张，每闪一下一张帧卡（`f 030` `f 072` `f 108`…）飞出排进一条胶片，胶片卷进一个 `.mp4` 文件图标——“网页 → 截图 → 拼片”三步一个连续动作（Remotion）。
- 第0帧：片墙六格已经在播（负的入场时间），顶部帧计数器 `f 0000`，片墙下方大字「0 个视频模型」+ 左上小签「#Vibe知识大赏」。
- 高潮停留：评分一场“5.4 → 7.0”的刻度尺落定、“6 = 剪映模板 / 8 = 广告公司”两个标记出来后停约 1.5 秒（`tailMs` 900）；结尾帧计数器停在总帧数 + 「0 个视频模型」停约 1.8 秒。
- 和上一支不同：最近三支是 kimi-k3-1-pro（官方录屏能力递进）、agent-compute-hijack-v3 / v2（手绘机器人 + 论文数字）。结构（五章教程 + 经验，不是递进展示 / 情绪曲线）、开场（作品墙 + 翻成代码，不是单个成品或角色）、招牌镜头（网页被拍成胶片，不是扫描线换态 / 点阵翻色）、镜头路线（每章换底、章内在窗口和文件之间推拉，不是推进一个窗口）、结尾（帧计数器停在本片总帧数的自证，不是日期章 / 回到开场台词）——五项不同；配乐形状照旧不加底乐（只有拟音），这一项相同。
