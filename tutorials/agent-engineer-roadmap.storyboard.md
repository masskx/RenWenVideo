## 导演 Brief

1. 目标：给想转 Agent 开发、或者刚学完提示词就以为会做 Agent 的人看。看完记住一句：**Agent 工程师 = 看懂模型调用 + 把它做成能跑、能测、能恢复的系统；按五个项目一步步交付，每个都有验收标准。**
2. 分镜与主次：起势 = hook（面试结论 → 指南展开成五段）、route（一块请求沿五站走一遍）；发展 = llm、api、prompt、rag、loop、guard（同一台“上下文机器”一层层加东西）；收束 = backend（机器被装进服务箱）、projects（四个方向）、outro（五个问题 + 一正一异两个用例）。贯穿全片的主体是**上下文机器**：一排有容量的槽位（上下文窗口）+ 右边的模型芯片 + 上方轨道上的龙门吊。次主体：每镜进来的块（Token、消息、资料片段、工具结果）；背景：网格纸。
3. 轨迹与相机：龙门吊沿轨道走（弹簧，到位略过冲），块挂在吊钩下，降下时按重力加速，落进槽位是接触帧；被拒的块撞到槽位边缘弹开；请求块在 route 里沿电路走线逐站停靠。相机只推向这一刻在动的部件（槽位、芯片、闸门），横向不切字；标题和读数在 HUD 层。
4. 运动与物理：块落槽位有压缩和回弹（`impulse`），相邻槽位晚 2–3 帧轻微下沉；吊钩先上提（预备）再横移；塞不下的块撞边弹回，再被“压缩”成一半宽；流式输出是小块一块块从芯片吐出，间隔不均匀；循环里工具箱接到块时先下沉再回弹；数据库只吐出两行进槽位，其余留在库里。
5. 材质与光：蓝图深底 + 细网格，零件是平涂面 + 浅色工程线，带尺寸线和引线标注；唯一会“亮”的是模型芯片的指示灯（有光源：芯片工作时亮）；不用辉光、不用渐变字；等宽字的读数（tokens、step、ms）跟着动作跳。
6. 节拍与声音：口播卡点是重拍；底乐低音量。音效：块落槽位 tap、龙门吊横移 whoosh-short、被拒弹开 block、指南落桌 thud、印章/否决 stamp、读数到位 tick、卡片 paper、流式输出 tick（稀疏）；全部低于人声 12 dB 以上。
7. 禁止项：导演层第九节全部；本片补充——不出现作者头像或任何真人形象、不放原文截图和原配图（项目表按内容重画）；不写原文没有的数字（测试通过数、模型名都不编）；不用霓虹、不发光描边、不用粒子；一屏强调色 ≤ 2（琥珀 + 青）。
8. 验收标准：导演层第十一节全部 + 原有门槛；补充——**所有要紧内容都在 y 330–1590**（6:7 裁切后完整，3:4 封面完整）；块落槽位的接触帧能逐帧看出压缩；每个项目卡都写清“验证什么 / 交付什么”。

## 自查

- 每个主动作都有受力起点和接触帧；同一时刻只有一个主事件。
- 上下文机器从 llm 到 guard 一直在，backend 里被装进服务箱；route 的请求块落进第一站的机器。
- 模型 = 琥珀，系统 / 工程 = 青，一屏强调色 ≤ 2；没有发光和渐变字。
- 所有标题、读数、字幕都在 y 330–1590。

## 静帧判断

- 第一轮静帧（按 6:7 裁切看）：蓝图底 + 一台机器 + 琥珀 / 青两色，科技感成立；所有要紧内容都在 6:7 带里。问题：route 标题太长撞上右侧“05/05”→ 缩成“做成服务”；hook 第四栏的项目块无故用了琥珀 → 统一；backend 里缩小的机器没对准服务箱、右侧组件超出 x 930 → 重新对位；块、仓库名、卡片字太小 → 普遍加大。
- 第二轮：api 镜头推到 1.14 倍时，相机为了不越界只能居中，左侧“system”块被切 → 本片相机上限 1.1 倍。
- 丰富度：第一稿看似 10.1，其实是一次“sweep”转场整屏刷成青色（单格 93）撑起来的，去掉后只有 7 左右，还有 8 格几乎不变。原因：中性块是深藏青填色，在深底上几乎没有面积。改法：中性块改浅钢色（不算第三个强调色），仓库名用实心青底，补几处有理由的相机（跟龙门吊、推到正在发生的卡片）；转场改成深色面板。最后 10.3、没有不变格。
- 减法：hook 的“不太行”标签和“未通过”章各留一个位置，不再叠字；rag 的项目卡只在开头 3 秒出现，让出画面给链路。
- 扫片：相机看得太低时，舞台顶部的清单 / 卡片滑进 HUD 标题下面 → 相机看向的 y 按缩放限位；hook 的项目块从高处落下时穿过栏目标题 → 下落高度降到 70。限位后丰富度掉到 9.7，再补两处真实事件（route 走过的节点实心填色、结尾五站依次点亮）和后端组件改成浅钢实体块，回到 10 以上。
- 封面：3:4 封面上最大的字是底部两行，改成钩子“面试没过，拿到一份 / Agent 工程师路线图”，中间是五栏指南图。
