## 简报

- 钩子台词：只改0.016%的权重，小模型做数学题的正确率，从7.9%跳到48.1%。（hooks.md §一 第 1 种：荒唐的事实 + 数字）
- 钩子画面：第 0 帧——博客自己的 IMPROVE 卡（base 7.9% 灰条、Astra's edit 48.1% 绿条）+ 右侧标签「只改 0.016% · 131,072 WEIGHTS · 作者自报」+ 顶部比分条「MATH-500 正确率 % ｜改前 7.9｜改后 ––」，说到 48.1% 时定格、比分翻牌。
- 核心看点：MIT CSAIL 的博客说，让 GPT-6 Astra 直接改 Qwen3.5-0.8B 的 0.016% 权重（不训练），MATH-500 从 7.9% 到 48.1%——但它修的是“想到停不下来”的循环：原来 96 道练习里 85 道撞上 token 上限，减掉第 15、19 层的一个方向后，撞上限从 93% 降到 33%；同样的办法用在很少打转的 Gemma 上几乎没涨（6.8 → 最高 7.7）。全部作者自报、未同行评审。
- 收藏点：不需要（研究新闻）
- 结尾台词：数字是作者自报，博客没经过评审；它修的是循环，不是数学。（抖音技巧.md §三 第 3 种：一句翻转的判断；画面回到第 0 帧的 IMPROVE 卡）
