## 导演

- 模板：lemo/game-show（节奏游戏综艺：扁平矢量、粗墨线、硬投影、糖果色布景、每个动作卡在节拍网格上、每回合以一个“判定字”收尾）。为什么是它：选用指南 §〇.1 的“盘点 / 合集（N 个工具）”给到 game-show；“从夯到拉”本身就是判定字——每个 skill 一回合，落档就是判定。照搬了：§1 一切在网格上（120 BPM，落地 / 盖章 / 弹出都在拍上，也是音效）；§2 只有矢量、8 px 墨线、硬投影、无渐变无模糊；§3 一个布景一个色、角色自带颜色；§4 判定字和标牌就是字幕（字幕做成描边标牌）；§5 落地从天而降、出现用回弹、命中挤压、拍上蹦跳；§6 正面舞台、拍上微推、小节线硬切 + 短白闪、“竖向滚动布景”= 排行榜；§8 回合卡、判定字、成绩单、“数据当游戏 UI”（星数记分牌）、群体掉落。
- 模板改造：配色——糖果八色 → 原帖封面的五档色块（夯爆了 #E5494D / 顶级 #F76C17 / 人上人 #D7A520 / NPC #6F7F98 / 拉完了 #787878，墨 #111820），回合布景按文件类型配色（PPT 砖红、Word 蓝、Excel 绿、会议紫），红在这里是“夯”不是危险（梗本身的配色）；版式——16:9 正面舞台 → 9:16 五层档位架当舞台（豆子站在层板上，掉穿 = 往下滚动布景）；原生招式换一个——“下一关彩蛋（孵蛋）”换成“会骗人的记分牌”（五个官方豆子头顶同一个 195,868，一张「整仓」贴纸把五块牌子拉成一块）；声音——只有喊声、没有旁白 → 用户的 MiniMax 口播 + 描边标牌字幕（新加 `CaptionTelop`），配乐用我们合成的 playful 120 BPM 而不是 150 BPM 的 J-pop 循环；字体——Fredoka 圆体 → 仓库的思源黑体 900 + Barlow Condensed 数字（仓库字体，语言要求不算处数）
- 点子：观众以为星数越多越好用，其实排进夯爆了的是“交出来就能用的文件”——0 星的进了顶级、848 星的拉完了、官方 19 万星是整个仓库的。
- 对标：lemo/game-show 样片（学：回合卡 + 判定字、豆子角色和名牌、群体掉落、成绩单收尾、硬投影和粗墨线的质感；不拿：AI 进化史的故事、角色造型细节、150 BPM 的歌、英文喊声）；本仓库 workbuddy-15-skills（同类“盘点 skill”题；学：一项一个画面；不拿：它的结构和画法）。
- 结构候选：① 按类目逐个过 10 回合（太长、像清单）；② 一个反常 → 三个代表回合（PPT / Word / Excel）→ 会骗人的记分牌（第二钩子）→ 0 星和 848 星揭底 → 一条规则 → 成绩单 + 安装命令；③ 淘汰赛对阵（两两 PK，信息量不够 39 个）。选 ②：钩子和第二钩子都是“星数 ≠ 排位”，中间三回合给“夯爆了长什么样”的具体画面，结尾给动作。
- 风格：lemo/game-show STYLE §2–§8（硬投影卡片 + 豆子角色 + 判定字 + 条纹布景）+ 账号层（简体中文、口播字幕、出处小字）；从题材长出来：“从夯到拉”的档位表本来就是彩色色块排行，game-show 的“判定字”正好是档位名。

- 贯穿物件：五层档位架——钩子里空着两层，三个回合各往里落人，第二钩子时被拉远成整架，规则那一拍全架豆子一起蹦（混音板的高潮），结尾缩成成绩单的一角。

- 第0帧：深藏青布景 + 五层档位架（左侧五个色块：夯爆了 / 顶级 / 人上人 / NPC / 拉完了）+「0★」豆子已经在顶级层、「848★」豆子在半空往下掉 + 顶部大字「0★ 进顶级 · 848★ 拉完了」。

- 和上一支不同：最近三支 xupt-half-radio（halftone-dossier）、nvidia-huang-resigns（caption-news）、nvidia-board-oust-huang（news-package）。结构（反常 → 三回合 → 记分牌揭底 → 规则 → 成绩单，不是公告 → 反转 / 物件履历）、开场（豆子落档的结果先行，不是新闻稿标题卡 / 年份网点）、招牌（记分牌被「整仓」贴纸合并，不是旧口径划掉 / 席位图 / 电码）、镜头路线（正面舞台 + 拍上微推 + 竖向滚动，不是字幕卡硬切 / 拼贴视差）、配乐形状（playful 120 BPM 拍点驱动，高潮在规则，不是 tension 高潮在反转）、结尾（可截图的安装命令成绩单，不是日期卡 / 补完电台）——六项都不同。
