## 简报

- 钩子台词：AI说好让他少干活，结果今年8月，他在GitHub上留下了427次贡献。（hooks.md §一 第 1 种：反常的事 + 数字）

- 核心看点：据作者 Orestis Ioannou 自己的 GitHub 数据，2026 年 8 月 427 次贡献，是他 2019 年以来的单月新高（此前最高 319）；他现在是技术副总裁，按理写得最少；他说累不是因为哪件事更难，而是同时开着好几个 agent，每个都“有时”需要他；写代码便宜了，他给自己接了多得多的活；一轮轮爆发、倦怠，今年已经三轮。（“427”在第 4 秒说出，画面第 0 帧就有）
- 收藏点：不需要（知识快讯）
- 结尾台词：他不反对AI，只是发现：能做的更多，总会变成做得更多。（抖音技巧.md §三 第 3 种：一句翻转的判断；画面是他的原话 "being able to do more keeps turning into doing more. And I am tired."）

## 导演

- 模板：lemo/caption-news（字幕新闻）。为什么是它：一条 AI 新闻、一个大数字开场、一个转折（技术副总裁本该写得最少），素材是真录屏 + 原文 + 原图——正是 STYLE.md §1 的“静音也看得懂、字幕就是画面、证据上屏”。照搬了：§2 版式（台标 + 来源标签 + 素材署名角标，竖屏按 §2 另排：画面 y 300–1150、字幕卡两行压在画面下）；§4 字幕卡（思源黑体 900、左对齐、一句两块依次砸进、一个关键词进琥珀色块；`look.captions: "card"`）；§5 图形（账本底的数据卡、标题 ≤ 6 字左上、关键点大点 + 扩散圈 + 色块标签；原文重排成纸 + 荧光笔扫过；亮格四宫；冻结帧 = 白闪 + 推近 + 降饱和 + 角标括号 + 时间码；局部推近 + 画圈）；§6 统一调色 + 颗粒在合成时加（`look.grain: 2`）；§3 剪辑语法（硬切、转折白闪、120 BPM 网格、两次真正的安静）；§8 原生招式 1（第 4 帧数字钩子）、4（文件自己说）、5（冻结 + 安静）、7（亮格）、8（推近画圈）。不照搬：它的样片故事、英文字幕行（换成等宽小字的出处 / 原话）、片尾卡（我们片尾 ≤ 1 秒）。
- 模板改造：配色：蜜黄 #FFC21A + 墨 #0E0E0C → 他原图 VP 色带的琥珀 #FBBF24 + 原图底 #111827（颜色从素材取，账本纸的双边线也换成琥珀）；版式：16:9 单行中英字幕卡 → 竖屏画面在上、两行中文字幕卡压在画面下（模板 §2 的竖屏说明）；字幕第二行：英文口播行 → 等宽小字的出处 / 原话（观众只看中文）；原生招式：地图长出照片 → 录屏里的键帽推近画圈（“切换”这件事本身在录屏里）；收尾：5 秒片尾卡 → 原话引语卡压在褪色录屏上、最后一句说完 0.5 秒结束（抖音完播）
- 点子：观众以为 AI 会让人少干活；其实它让“开工”变得太便宜——一个本该写代码最少的技术副总裁，同时开着好几个 agent，每个都“有时”要他回话，于是活越接越多，一轮轮干到累。
- 对标：caption-news 样片《蜜蜂账本》（学：数字先出、账本数据卡、文件高亮、冻结帧的节奏；不拿：蜜蜂、它的配乐和片尾）；news-package 样片《本周 AI 四件事》的包装密度（学：每一帧都有台标和来源；不拿：滚动条目和片头）。
- 结构候选：① 倒金字塔 + 中途转折（坏数字 → “按理说不该这样” → 原文怎么说 → 为什么 → 一句判断）；② 三件事清单（数据、原因、建议），第三件翻转；③ 倒数数字（427 → 319 → 7 → 3 轮）。选 ①：模板 §12 的第一种结构，正好对上“427 → 技术副总裁本该最少”的转折。

- 底色：全片同一个深底（模板的“账本”和他原图的夜色）；情绪靠素材 ↔ 数据卡 ↔ 纸的切换、冻结帧降饱和和结尾整体压暗表达，不翻底。
