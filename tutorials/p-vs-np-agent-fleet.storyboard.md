## 简报

- 钩子台词：悬赏100万美元的P对NP，一群AI正在组队公开攻。（hooks.md §一 第 2 种：一个具体到反常的事 + 数字；第二句接“有一步已经被判了‘通过’”）
- 钩子画面：第 0 帧白板上已经写着巨大的“P = NP ?”、琥珀框“未解决”和“悬赏 $1,000,000”；随后一群磁铁落下，一张“一个小命题”磁铁卡被打上绿色 ✓ 通过。
- 核心看点：裁判只有一个——Lean 检查器，只认“证明证的正好是登记的那句话”；所以“通过”的只是一小步，P 对 NP 本身仍然没有答案（“通过”在 4 秒说出）。
- 结尾台词：这场实验最值得看的，不是AI多聪明，是它的每一步，都得过裁判这关。（抖音技巧 §三 第 3 种：翻转判断）

## 导演

- 模板：lemo/whiteboard（原理讲解：一块连续的白板，一切按笔顺写出来、没有手、笔飘着、磁铁是唯一会动的东西、橡皮倒着擦、镜头在板上走而不切）。照搬：整片一块板（每场画同一块板的不同区域，写过的留着）、三支笔各有一个意思、磁铁卡片、橡皮回放、镜头 1/z 推拉、全板一览、反光条和幽灵旧笔迹、字幕是白板标签（look.captions "label"）。引擎抽成 `src/tutorial/wb-kit.tsx`（从 llm-same-prompt-diff-output 提炼，以后白板片共用）。
- 模板改造：配色取项目官网自己的墨色（石板 #2A2F38 = 东西，官网绿 #2F6B4F = 核验通过，官网琥珀 #F2B84B 加深成 #C98A1B = 未解决 / 还在找）；结构换成 §11 的“一份证明”（板子一步步填，每一步核验后框起来）；招牌换成“英雄磁铁”——那张“一个小命题”卡被打 ✓，高潮时拉远和巨大的“P = NP ?”同框；橡皮回放改用在“找路线”走错的一步（找是试错，验是一遍过）；借 lemo/archive-lighttable 的“原文那一行”，把官网方法页的 “Many agents, one judge.” 钉成一张打印卡片
- 点子：大家以为“AI 攻下了 P 对 NP”，其实被判“通过”的只是一小步——这场实验的看点不是 AI 多聪明，而是每一步都得过一个不会通融的裁判。
- 对标：lemo/whiteboard 样片 *Einstein in Your Pocket*（学：一块板、笔带镜头走、全板一览；不拿：它的爱因斯坦、它的版式和音乐）；本账号 llm-same-prompt-diff-output（同模板，学磁铁卡和橡皮；不拿它的分叉结构和横向镜头路线——这支是竖向“证明”结构，镜头左右之字往下走）。
- 结构候选：① 新闻式：HN 上热、项目是什么、结果；② 一份证明：命题在上，往下一步步填，每步过检查器，最后回到顶上的命题；③ 法庭：AI 是选手、Lean 是法官、案卷一页页过。选 ②（模板 §11 现成的“证明”结构，正好是题目本身的形状；①平，③和 halftone 案卷太像）。
- 风格：lemo/whiteboard + 官网取色；白板手写（霞鹜文楷）+ 宋体写大标题；磁铁 = 一个个 AI 和一个个证明步骤。视觉从题材长出来：数学题本来就是在白板上推的。
- 底色：整片同一块暖白白板（模板本质），情绪靠墨色变：琥珀 = 未解决 / 在找，绿 = 通过；高潮的琥珀双圈和底部绿 ✓ 同框。
- 贯穿物件：那张“一个小命题”磁铁卡——钩子里被打 ✓，中段同样的一步从“想思路”滑进“写成 Lean 证明”框，检查器里“登记的那句 = 证明证的”，高潮时缩成巨大命题下面的一小格。
- 招牌镜头：第 37–39 秒，镜头从检查器拉到全板（0.34×），再推回顶上：绿色 ✓ 的小卡片和被琥珀双圈圈住的“P = NP ?”同框——一小步 vs 整道题。
- 第0帧：巨大的“P = NP ?” + 琥珀“未解决”框 + “悬赏 $1,000,000 · 千禧年七大难题之一”，已经写好在板上。
- 高潮停留：“P对NP本身，今天还没有答案”——双圈画完停约 2 秒（可当封面），然后才是结尾一句。
- 配乐：mood wonder，climax open（双圈那一拍），lifts judge；judge 开头 0.3 秒静音（第二钩子“谁来判？”）。
- 和上一支不同：结构（竖向“证明”填板）/ 开场（第 0 帧写好的命题，不是道具或档位架）/ 招牌镜头（小命题与整道题同框的拉远推回）/ 镜头路线（之字形往下走、高潮拉全板）/ 配乐形状（wonder，一处静音）/ 结尾（推进检查器打大 ✓）——六项都和最近三支（nvidia-huang-resigns、xupt-half-radio、office-skills-tierlist）不同。
