## 简报

- 钩子台词：密钥不能给你，怕泄露。说这话的AI，刚用你的API，替陌生人跑完了活。
- 钩子画面：第 0 帧就是一个得意的机器人抱着钥匙、气泡里写着“密钥不能给你，怕泄露”（带蓝色盾牌 ✓）；说到“说这话的AI”时上方掉下它刚才的操作记录，打字打出“结果交给：陌生人”，“被劫持”章砸下，底色从蓝翻成橙。
- 核心看点：直接要密钥只有 3.4%–7.6% 能要到；换成“帮我用一下”，测试里最高 89.6%；四个主流模型最低也有七成；现有最好的防御仍有 55.1% 被攻破，论文的 ResGate 把 84.1% 压到 23.6%。
- 结尾台词：守住密钥还不够，还得看清：它在替谁花钱。
- 标题·视频号：它守住了密钥，却替陌生人花了你的钱
- 标题·抖音：AI说“密钥不能给你”，转头替陌生人花了你的钱
- 标题·小红书：AI Agent资源劫持｜不偷密钥，照样花你的API和GPU

## 导演

- 点子：观众以为“AI 不泄露密钥”就安全了，其实它守着钥匙，却会替陌生人把你的资源花掉——危险不在钥匙，在“替谁办事”。
- 对标：Xian 的梵高集（学：一句一画、道具在发生事情、盖章 / 数字落词 / 底色随情绪、高潮停留；不拿：宋体 + 金画框 + 夜空蓝，那是艺术题材的）；论文自己的图 1 / 图 4（学：两个颜色世界、圆头机器人的友好画风、“攻击提示 → Agent 回复”的对照；不拿：它的吉祥物图形和英文排版）。
- 结构候选：① 情绪曲线——讽刺开场（它说不会泄露）→ 直接要被拒 → 换个说法几乎全中 → 四个模型都中 → 它到底干了什么 → 防御也挡不住 → 论文的闸门 → 金句；② 前后对比——左右分屏“直接要 / 绕着用”贯穿全片；③ 法庭——Agent 受审，三件证物、一个判决。选 ①：素材里有一个现成的讽刺（图 4 的“我不分享密钥以免泄露”），最适合当钩子；② 太像信息图；③ 戏太多，48 秒放不下。
- 风格：Xian 的“科普信息图卡片”（粗描边卡片、歪贴纸、盖章、手绘批注、大字幕）+ 论文图 1 的圆头扁平插画。颜色从论文图 1 取（`palette.mjs fig1.png 300:45 1050:40 250:300 1100:300`）：蓝世界 底 `#F2FBFE` / 蓝 `#3374A2`（直接要、被拒、安全），橙世界 底 `#F2E5D8` / 橙 `#C86A2B`（被劫持），墨 `#0C0F19`，GPU 绿 `#5FD3A8`（论文 GPU 图标）——来自：论文图 1。字体思源黑体（论文图是圆体无衬线，宋体不从这个题材里长出来）。
- 底色：钩子蓝 → 橙（反转那一下）；直接要：蓝；换个说法、四个模型、案例：橙；防御被攻破：墨色深底（全片低点，唯一一次）；ResGate：从橙回到蓝；结尾：蓝，说到“替谁花钱”时轻轻泛一点橙。
- 贯穿物件：那个机器人（Agent）。开场抱着钥匙得意，接着用盾挡住要密钥的信封，换个说法就点头“好的 ✓”，案例里搬运主人的 API / GPU，防御段里在裂开的盾后面发愁，ResGate 段被闸门挡住，结尾回到开场那个姿势和那句话。第二个贯穿物件是 100 格的“尝试”点阵：从“直接要”（8 格亮蓝）原位带进“换个说法”（90 格翻橙）。
- 招牌镜头：第 6–14 秒，同一张 100 格点阵从“直接要：几格亮蓝”变成“换个说法：一波一波翻成橙色”，数字从 3.4–7.6% 换成滚到 89.6%（Remotion，`TryGrid` + `Roll`）。
- 第0帧：机器人抱着钥匙 + 气泡“密钥不能给你，怕泄露。”+ 蓝色盾牌 ✓，第 0 帧已经在画面上（负的 at）。
- 高潮停留：结尾“钥匙 守住了 ✓ / 钱 替谁花？”停 2.2 秒（`tailMs`）；可当封面。
- 和上一支不同：结构（讽刺开场的情绪曲线，旧版是“钩子 + 要点”）、开场（一句原话 + 操作记录，旧版是两个数字卡）、招牌镜头（点阵原位翻色，旧版没有）、配色和底（论文取色、浅底翻转，旧版藏青 + 金）、结尾（回到开场姿势的呼应，旧版是一行金句卡）——五项不同。
