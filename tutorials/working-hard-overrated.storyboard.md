## 简报

- 钩子台词：幸福感每高1分，干活效率高12%。（hooks.md §一 第 1 种：反常的事实 + 数字）
- 钩子画面：第 0 帧——暖白纸上一根墨线刚画出 0–10 的刻度尺，笔影在纸上；0.9 秒内刻度爬上一格、右边的曲线往上一甩成箭头，手写「效率 +12%」。
- 核心看点：努力不是护城河——原文说 10% 的时间要硬推、90% 应该被“拉”着走；转发的人说：所以要用 agent，别在一堆 sessions 里当苦行僧（10 秒内说出 12% 和“努力工作被高估了”、转发者的 agent）。
- 收藏点：结尾三步清单（列出硬推的事 / 重复、等待、整理交给 agent / 省下的时间做想做的），约 51–56 秒，停 ≥ 2 秒。
- 结尾台词：今天试一件：挑一件你天天硬推的重复活，交给agent跑一遍。（抖音技巧.md §三 第 1 种：一个马上能做的动作）

## 导演

- 模板：lemo/one-line（一根墨线从不离开纸面：所有东西都是这根线画出来的，场景不切、只变形；线的“性格”随情绪变，笔影是唯一的“真实世界”）。为什么是它：这篇讲的就是“费力 vs 不费力”——一根线本身就能演“推”（抖、粗、发干）和“拉”（细、快、一气呵成），比任何图表都直接。照搬了：§1 一根线、暖白纸、只有笔影；§2 纸纹、按速度变粗细的墨、飞白和颤抖、晕染；§3 墨 + 纸，强调色只用一次；§4 手写字幕逐字写出、纸色光晕；§5 时间 = 章节窗口 + 曲率；§6 跟笔的连续镜头、不切；§8 “线就是时间”（推的线颤抖发干）、“交接”（agent 的手接过笔）、引擎原样改写（MIT）。
- 模板改造：配色——唯一的强调色从“爱 / 危险的红”换成 Claude Code 的陶土色 #D97757，只给 agent 打勾那一段（交接）；结构——一张最终大图的“倒推揭示”换成一条往下走的线，十一个小画面一句一个（9:16 竖着往下走，镜头跟笔下行）；线的性格——年龄（童年 → 老年）换成情绪（push 颤抖发干 / flow 细快 / plain）；字幕——Caveat 英文手写换成霞鹜文楷中文手写（新加 `CaptionScript`），标签用页面导出的逐帧相机钉在纸上；声音——大提琴独奏 + 合成笔声换成仓库合成的 warm 配乐 + 用户口播
- 点子：观众以为“越拼越好”，原文说最顶尖的人看起来都毫不费力——10% 硬推、90% 被拉；对用 AI 的人来说，那 10% 里重复的推可以交给 agent。
- 对标：lemo/one-line 样片 *The Line That Never Lifted*（学：一根线、笔影、颤抖和飞白讲情绪、交接时换一只手；不拿：老人脸的倒推大图、风筝和自行车的具体画法、英文配音和大提琴）；本仓库 llm-same-prompt-diff-output（白板手写；学：写字的节奏；不拿：白板和磁铁）。
- 结构候选：① 按原文顺序讲名人故事（太散，个人信息多）；② 数字钩子 → 原文标题 + 转发者的 agent（开环）→ 三个“毫不费力”的例子 → 推 vs 拉 → 10% / 90%（第二钩子）→ sessions 里的苦行僧 → agent 接过笔 → 三步清单；③ 只讲 10/90 一张图（太短、没有 agent）。选 ②。
- 风格：lemo/one-line STYLE §2–§8 + 账号层（简体中文手写字幕、出处小字）；从题材长出来：“努力 / 不费力”就是一根线的两种写法。
- 底色：全片暖白纸（模板只有纸和墨）；情绪靠线的性格变——推的段落线粗、抖、断墨（钩子后的推石头、推箱子、10% 的斜线、苦行僧），拉的段落线细而快（圈圈、网球弧线、音符、风筝、90% 的小圈）。
- 贯穿物件：这根墨线本身——从刻度尺开始，一路往下画到最后一个勾，然后跑出纸面；中途被 agent 的手接过一次（变成陶土色），再交回来。
- 招牌镜头：约 45.8–47.5 秒（handoff 场）：笔影换成从左上伸进来的另一只手的影子，线变成陶土色，飞快地给六个 sessions 窗口逐个打勾；交回墨色后，线一口气往下拉出一只风筝。
- 第0帧：暖白纸 + 墨线刻度尺正在画出来 + 笔影（纸、线、笔影三样都在动）；手写「幸福感 0–10」已经在。
- 高潮停留：handoff 场“你的手，留给被拉着的那部分”之后风筝画完多停约 1 秒；结尾清单停 ≥ 2 秒，最后一句说完 0.7 秒内结束（线跑出纸面）。
- 配乐：warm（84 BPM），climax = handoff，lifts = ratio。
- 和上一支不同：最近三支 office-skills-tierlist（game-show）、xupt-half-radio（halftone-dossier）、nvidia-huang-resigns（caption-news）。结构（一根线往下走，十一个小画面，不是回合 / 履历 / 反转）、开场（线正在画刻度尺，不是档位架 / 新闻稿）、招牌（另一只手接过笔、陶土色打勾，不是「整仓」记分牌）、镜头路线（不切、跟笔下行，不是硬切舞台）、配乐形状（warm 84 BPM，高潮在交接）、结尾（清单 + 线跑出纸面）——六项都不同。
