Title: OpenAI 推出 Images 2.6 模型，ChatGPT 支持直接生成和编辑 GIF 动画

URL Source: https://www.ithome.com/1/022/486.htm

Markdown Content:
感谢IT之家网友 [华南吴彦祖](https://m.ithome.com/html/app/open.html?url=ithome%3A%2F%2Fuserpage%3Fid%3D2029428)、[补药吖](https://m.ithome.com/html/app/open.html?url=ithome%3A%2F%2Fuserpage%3Fid%3D1980397) 的线索投递！

[IT之家](https://www.ithome.com/) 11 月 5 日消息，据 The Verge 今日报道，ChatGPT 现在可以通过提示词或上传到人工智能聊天机器人的照片来创建 GIF。此次更新与 OpenAI 的新 Images 2.6 模型同步推出，允许用户调整 GIF 的动画速度，编辑单个帧，并与他人分享。

在此之前，ChatGPT 无法单步原生生成 GIF。公司分享的一个示例展示了 ChatGPT 如何根据“你能制作一只猫跳舞的 GIF 吗？”的提示生成 GIF，同时还提供切换播放速度和逐帧观看的选项。

![Image 1](https://img.ithome.com/newsuploadfiles/2026/11/18cb8bb4-ce0a-4b12-ae79-ae598c2e74e9.jpg?x-bce-process=image/format,f_auto)

OpenAI 表示，除了支持 GIF 制作外，Images 2.6 更新还使 ChatGPT 能够更快地生成图像。公司表示，**用户目前每周通过 ChatGPT 及其 API 生成超过 40 亿张图片**，较其 9 月份报告的每周 30 亿张大幅增长。

IT之家从报道中获悉，Images 2.6 正在向所有 ChatGPT 和 Codex 用户推送，涵盖网页、桌面和移动应用。OpenAI 还在其 API 中推出了 GPT-Image-2.6 Flare 和 Sunburst 模型，以实现更快、更高质量的图像生成。
