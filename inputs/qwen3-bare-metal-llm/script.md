# 参考口播与分镜

| 时间 | 画面 | 上屏文字 | 参考口播 |
|---|---|---|---|
| 0–3 秒 | M1 或 M2：第 0 帧出现虚拟电源键，按下后跳到大片黑底终端和 asm-llm 提示符，再打出两项数据。示意版写「示意」。 | 内核约 24 KB / 权重 614 MiB | 这台机器一开机，就进千问聊天。 |
| 3–14 秒 | M2：一张细长的内核卡和一块明显更大的权重卡分开出现。 | 24,252 字节是内核 | 作者用汇编写了一个专用内核。内核二十四 KB 左右，模型权重另外加载，这个版本要六百一十四 MiB。 |
| 14–27 秒 | M1：作者路径对应虚拟机内的真实提示符，打一条短英文例句。如果没有实机，用 M2 演示「引导→内核→权重→聊天」。 | 直接进本地聊天 | 你可以把它想成一台开机就跑同一个任务的机器。少走通用系统那段路，换模型、接工具就没那么方便。 |
| 27–38 秒 | M2：左边画「专用聊天终端」，右边画「通用电脑」。镜头停在旧主机上。 | 你的旧电脑专门跑什么？ | 你有没有一台只干一件事的旧电脑？它跑的是什么，会愿意为它换一个启动方式吗？ |
