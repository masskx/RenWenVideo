# 参考口播与分镜

| 时间 | 画面 | 参考口播 |
|---|---|---|
| 0–3 秒 | 三格同步停在手握杯柄的一帧，先只标 A/B/C；同一处杯柄准星打在三格上。尚未实测时改用原创手杯示意与三张起价卡，明确标示意。 | 同一只杯子，三档 AI 视频，你愿意为哪个镜头付钱？ |
| 3–11 秒 | 自绘国内起价卡依次弹出，底部大字「每秒起价」。 | MiniMax 公布了 H3 系列。国内视频三档，起价每秒一毛六、两毛六和五毛。 |
| 11–26 秒 | 同一张图送进三格，放大手、杯柄和放回桌面的瞬间。 | 比的时候统一五秒和七六八 P。只看三件事：手穿不穿杯，杯柄会不会变形，动作有没有做完。 |
| 26–41 秒 | 先显示盲评，再翻开真实扣费和可用条数；没有结果则用空表示范怎么算。 | 真正影响预算的是一条能用的镜头花多少。把这一档的实付总额，除以最后留下的条数。 |
| 41–47 秒 | 白杯回到桌面，字幕出现评论问题。 | 你上一次做产品镜头，最后是便宜档跑得多，还是贵档一次过？ |
