# 参考口播与分镜

| 时间 | 画面 | 参考口播 |
|---|---|---|
| 0–3 秒 | 等号被删掉，99 元购物车的运费从免运跳到待付，审查气泡问「为什么删？」。角落标「模拟审查」。 | AI 只删了一个等号。正好买九十九块的人，突然要付运费了。 |
| 3–13 秒 | 自绘规则卡随口播放出获得许可、披露、逐行解释。 | LibreOffice 刚收紧开发规则。用大模型辅助要先获准，提交要披露，每一处改动都得用自己的话讲清。 |
| 13–28 秒 | 100 元测试先通过，复制一份改成 99 元，红框锁定失败。 | 比如这个改动，一百块的用例还会通过。你得知道九十九块会发生什么，也得把这个用例补上。 |
| 28–40 秒 | 切到样板代码与支付规则两张卡。 | 有些代码重复，交给 AI 能省时间。有些代码只差一个符号，客户收到的账单就变了。 |
| 40–46 秒 | 审查气泡移到大字提问。 | 你们团队允许 AI 写哪类补丁？哪类你会要求当场讲清楚？ |
