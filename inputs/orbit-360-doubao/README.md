## 三、补充资料（给你看，不上屏）

- 人像可选补充指令（原文）：身体定格，只有眼神轻微追踪。仅允许眼球与瞳孔非常轻微、自然地移动。摄影机在人物视野范围内时，眼神缓慢追踪镜头；摄影机进入背后时，不要求眼睛继续追踪。摄影机重新进入视野后，眼神自然重新连接。头部绝对静止，不眨眼，不改变嘴型和表情。
- 原文 ComfyUI 步骤（方法02）：ComfyUI 模板库加载 “MiniMax H3 I2V” → 按提示下载 FL2VA 模型、文本编码器与 VAE → 下载 360° Orbit LoRA 放进 `ComfyUI/models/loras/` → 同一张图接首帧和尾帧 → 用 LoRA 作者给的原始提示词，先按推荐配置复现 → 检查成片。LoRA 模型卡推荐：768×768、73 帧（约 3 秒 24fps）、28 步、无 CFG、LoRA 强度 1.0、关音频。
