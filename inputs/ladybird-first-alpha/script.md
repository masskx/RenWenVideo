# 参考口播与分镜

| 时间 | 画面 | 参考口播 |
|---|---|---|
| 0–3 秒 | 三个竖排测试标签，光标点击「播放」，随后出真实测试画面；未实测则用自绘播放器标「测试方案」。 | 换一个从零写的浏览器，你最常用的网页还能打开吗？ |
| 3–11 秒 | 自绘浏览器外壳与引擎两层，镜头推向下层。 | Ladybird 放出了首个阿尔法版。它背后那套负责排版、执行网页脚本的引擎，是自己写的。 |
| 11–28 秒 | 主力浏览器和 Ladybird 同机分屏。依次切文章、视频、按钮。 | 我们用三关看够不够用：文章能不能完整显示，视频能不能播，点下按钮有没有反应。 |
| 28–39 秒 | 放上三项实际结果或未测试的空白检查单，角落标系统与版本。 | 官方现在只提供苹果电脑和 Linux 的 Alpha 下载，也预告了有些网站会坏。三关的结果只代表手上这台机器。 |
| 39–45 秒 | 三张标签收起，只留一张空白网页卡。 | 你会拿哪个网站考它？哪项功能一坏，你就会换回去？ |
