# 素材清单

| 镜头 | 可直接制作或取景 | 作者和许可 |
|---|---|---|
| 1、3 | 在可用的 macOS 或 Linux 上，同机用 Ladybird 和现有主力浏览器打开三页。建议选公开文章（首屏能否完整渲染）、自有无版权负担的 HTML5 视频（能否播放）、自制按钮交互页（点击能否更新状态）。每一项录下两边画面、版本号和结论。 | 自录，自制页面和片段由摄制者控制。外站内容只用获准画面，避免账号、弹窗和网址上屏。 |
| 2 | [Andreas Kling 项目公告](https://ladybird.org/posts/alpha/)第一段和 [GitHub 发布页](https://github.com/LadybirdBrowser/ladybird/releases/tag/2026.47.7)首段。取「自研引擎」和「Alpha」重画结构卡。 | 署名 Andreas Kling / Ladybird Browser Initiative。项目代码标 BSD-2-Clause；网页、标志与转录画面的授权另行确认，优先手绘卡。 |
| 4 | 自绘三项结果板：首屏 / 播放 / 交互。无录制环境时改成三项空白测项和开源发布说明。 | 摄制者原创。未测留空并标「测试方案」。 |

若官网下载页无法列出安装包，核对项目发布页和下载入口后再排录制，不使用来历不明的镜像。
