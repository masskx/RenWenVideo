# ai-more-work-burnout — 抖音素材包（给视频作者）

选题：「AI说好让我少干活，结果我从没这么累过」（Orestis Ioannou 个人 GitHub 数据）。只是素材，不含脚本和成片，不要加 full.mp4。

## 成片要求
- 抖音 30–40 秒成片。
- 人声和画面整体加速约 1.2–1.25x。
- 纯内容，结尾不要引流、不要“评论区告诉我/关注领取”之类的诱导。

## 口径红线（来自 REVIEW-DOUYIN.md）
- 说 **contributions（贡献）**，不要说 commits/提交量。
- 不要说“他史上最忙的一年”：2020 年同期是 2,371 次，2026 截至 10-27 为 2,102 次。可以说 8 月 427 次是单月新高（此前最高 2020 年 4 月 319 次）。
- 作者不反对 AI，原话："I am not complaining about the tools"。
- 这是一个人的数据，不要推广成“所有程序员都这样”。
- 不要提知乎「约58万」这个数字（未核实）。
- 使用 Parallel Code 演示素材和 Cursor 截图时须在画面注明来源。
