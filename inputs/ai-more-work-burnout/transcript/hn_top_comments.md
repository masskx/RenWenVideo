## ak39 (id 50261749, replies 4) https://news.ycombinator.com/item?id=50261749

This resonates 100% with me. I am tired too.

This is what I think is the solution - I've tried it a few times with good results.

1. We need our own project or task plan. A simple forward-thinking TODO list is good enough. This needs to be prepared before the day begins. Daily.

2. Focus and limit scope. Focusing on doing ONLY what's on the list is the discipline I (we) lack and which we need badly.

3. Side quests are killing us. Allowing ourselves to veer off the planned daily tasks should require a complete away-from-the-keyboard planning session with pen and paper. Print it out but plan it away from the LLM. Use the LLM to summarise the problem, by all means, but do the thinking away from the LLM. The current TODO list needs to be the main input of such a deliberation. The output is the new TODO list. The objective of this away-from-keyboard exercise is simply to maintain control of the next steps.

On days where I worked with my TODO lists, I clocked out and joined the family for activities, slept sooner and better. On days I lost control of that list, the exhaustion mounted almost on the same day.

Make a finite list for the day, tick it off and go spend time with the missus, the kids or the dog. 2c.

## bemtevi (id 50258391, replies 1) https://news.ycombinator.com/item?id=50258391

For decades tech companies have promised that devices save time....but to do what? The pitch was that they would save time for us to do more 'creative stuff'...but I think that pitch and idea is fundamentally flawed. From doing creative stuff for a couple decades, I can make a few observations:

(1) More tech doesn't save time if it's developed in the direction/dimension of more information flow. Because it seems that the best environment for creativity is a somewhat restricted environment of information. And if one needs to engage with information to take advantage of this new tech, it actually impedes creativity.

(2) A lot of the grunt work that we seem to be automating also encourages creativity. From what I've observed from many artists and programmers (I hang out with both), it seems that creativity strikes best when it's not forced, and the "downtime" doing grunt work actually accelerates it.

So I think that AI breaks these two principles (minimal information and the removal of the crucial grunt work), and actually makes us work more for less.

The only gains seem to be those short-term kinds (a program can be made faster, rewards can be reaped by senior people who have thought about stuff for a while), rather than encouraging a healthy environment of creativity....

## maerF0x0 (id 50260419, replies 0) https://news.ycombinator.com/item?id=50260419

From a higher level view, and not just about the article I note that:

- Automation seems to make specific individuals work more, the leverage makes the individual more valuable in the short run (eg if I can produce 10x the engineering, for a little while I'm 10x more valuable, I dont mean LoC but engineering value). But in the long run its deflationary on the value of what I do, I might have to work harder just to stay in place.

- Automation/industrialization spins the hedonic treadmill. Economists ~100 years ago thought we'd all work like 5 hours a week or something because, for example, 95% of the farmers would be replaced with machines etc. However what they didn't/couldnt account for was us increasing our consumption as fast as the productivity improvements. Before today I had use for approximately 1 GPU (gaming), now I'm probably using dozens or hundreds. George Monboit also notes this with "green" technologies, that we end up consuming more such that we approximately end up with the same pollution (co2, plastic, whatever).

- Software has long been a negotiation between Manager/Executive class and the maker class about what an appropriate amount of software per week/40 hours was. They think because claude writes code 95% faster we should ship 20x the software. But they miss that coding was only 10-25% of the job.
