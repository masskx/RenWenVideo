## 口径对照（选题摘要 vs 原文）

| 选题/转述常用说法 | 原文要点 | 口播建议 |
|---|---|---|
| 「适配列表要公示」 | 设置页 **和** 分发页两处公示；列机型+OS | 说清两个公示位置 |
| 「预装 AI 助手的手机要过进网关」 | 预置智能体的手机/平板/可穿戴，进网检测须适配验证+涉诈/反诈评测 | 可说；对象含平板、穿戴 |
| 「智能体配唯一身份码」 | 「应参考…国家标准配备」 | 勿说成「已经按强制国标打码完毕」 |
| 「OTA 要先报备评估」 | 提交升级方案 → 升级结束交报告 → **评估后才可正式向用户提供服务** | 勿说成「没评估完绝对不能推任何包」；跟原文语序 |
| 「应用商店没声明就不能被强制调用」 | 「应用分发平台」+电子签名声明；未经声明同意不得强制调用 | 「应用商店」可口语化，正式应用「分发平台」 |
| 「工信部今天发文」 | 成文 10-24，**上网发布** 11-06 | 「今天官网发布」OK；勿把成文日说成今天 |
