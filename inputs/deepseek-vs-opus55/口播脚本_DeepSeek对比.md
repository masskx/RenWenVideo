## 02｜先说清楚今天发生了什么，约 0:12—0:35

[白底信息卡，逐条弹出：发布日期 / 模型名 / 开源 MIT / API 可用。再接一张流程卡：提示词 → 代码 → 渲染 → MP4。]

10 月 17 号，DeepSeek 发布了 V4.1 Flash 1017。网页、App、API 都能用，模型权重也开源了，协议是 MIT。

有一点先说清楚：它跟 Opus 5.5 一样，是写代码的语言模型，不是视频生成模型。

这些视频，是模型写出动画代码，再交给 Remotion、HyperFrames 这类工具渲染成 MP4。所以比的其实是：谁写的动画代码更好、更快、更便宜。
