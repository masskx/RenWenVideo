# Obsidian 官方连接器：换个 AI，同一本笔记还能接着写吗？

## 想法

- 标题：换了 AI，昨天的笔记还能接着写吗？
- 观众记住一件事：两个获得文件权限的助手可以接力读写同一套笔记，换的是助手，交接的是笔记文件。
- 为什么现在拍：Obsidian 于 11 月 26 日 05:19（台北）宣布官方连接器，现有技能有了更多官方安装入口。原帖现场查看约 77.8 万次 X 浏览（11 月 26 日 18:02 左右，查阅快照；统计时点略晚于 18:00 截止，属于 X 浏览量）。[Obsidian 原帖](https://x.com/obsdmd/status/2125700941156651151)
- 谁会讨论：已经用 AI 整理工作或创作笔记的人。只共享可交接的项目笔记，换工具就能继续；允许助手看到更多历史背景，能少补上下文，但需要给更多文件访问权限。

## 事实和出处

- 官方 GitHub 的安装说明列出了 Claude、ChatGPT 等插件入口，ChatGPT 插件也适用于 Codex；其他支持技能的助手可按说明装技能。旧技能的公开发布早于此次公告，视频讲这次官方接入，不说 Markdown 支持是今天新增的。[官方项目与安装说明](https://github.com/obsidianmd/obsidian-skills) · [官方连接器帮助](https://obsidian.md/help/connectors)
- 官方技能覆盖 Obsidian Markdown、Bases 和 JSON Canvas 等。演示只验证一份本地测试笔记，助手需要对同一个目录有读写权限；接力不等于迁移聊天记录。文件本地保存并不保证 AI 推理在本地，给云端助手读取前应确认敏感内容与权限范围。[官方技能列表](https://github.com/obsidianmd/obsidian-skills#skills)
