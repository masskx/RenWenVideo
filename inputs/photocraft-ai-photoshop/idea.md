# photocraft-ai-photoshop：AI 写的免费 Photoshop，菜单齐了，能干活的只有 45%

> 2026-10-30 选题（数据复盘-2026-10-30.md §四，用户同日让开工）。素材情况 A（只有图片：官方截图 + 官方路线图原文）。

## 想法

- 想让观众记住的一件事：AI 把一个软件的“样子”抄全很快（628 个菜单一个不少），能真干活的部分，它自己量出来只有 45%。
- 为什么现在讲：PhotoCraft 上线约一个月 75.1k 星（GitHub 页面，2026-10-30），中外媒体都在问“Adobe 完了吗”。
- 最反常识的地方：这个项目自己的路线图写得比谁都克制——“能干活 ~45%”“性能 25 项只达标 3 项”“剩下的按 Opus 5.5 agent 工时算还要 1,100–1,800 小时”。
- 想要的感觉：冷静、像读工程图纸；不唱衰也不吹。

## 事实和出处（全部见 sources.md）

- PhotoCraft：Photoshop 的开源“净室”重写，纯 Rust，MIT / Apache-2.0，early alpha，免费。（README）
- 路线图（2026-10-17，v0.6.0，对照 Photoshop 2026）：菜单 628 / 628、工具 56 / 68、面板 30 / 35；“能干活” ~45%（估算 40–50%）；性能预算 25 项达标 3 项；953 个未关 issue（10-13）；它写出的 PSD 还不能稳定被 Photoshop 接受；到 beta 还要约 1,100–1,800 小时（Opus 5.5 agent 工时，按仓库 1,004 个已合并 PR 校准）。（ROADMAP.md）
- 存 PSD：重新保存 psd-tools 测试集 309 个文件里 307 个渲染不变。（README）
- 75.1k 星 / 13.3k fork（GitHub 页面，2026-10-30 读）；同系列 FilmCraft 16.9k、LightCraft 15.1k。
- 「用 Claude Opus 5.5 写的」「发起人 Brandon Thomas」：**媒体报道**，官网和 README 没写 → 口播说“据报道”。
