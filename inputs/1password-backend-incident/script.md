# 参考口播与分镜

| 时间 | 画面 | 上屏文字 | 参考口播 |
|---|---|---|---|
| 0–3 秒 | M1：第 0 帧左侧保险柜锁住，右侧出现一张自己没发起的恢复请求卡，红色停在卡边。 | 密码库没受影响 / 恢复邮件要核实 | 密码库没被打开，但这封邮件先别点。 |
| 3–15 秒 | M1：拉近三张无实值的数据卡，姓名、邮箱、部分邮件令牌；第三张加「单独无法登录」。 | 部分账户资料受影响 | 1Password 说，部分用户的姓名、邮箱和某些邮件链接里的令牌被复制。按官方说法，单靠这种令牌，无法登录账户。 |
| 15–26 秒 | M1：转回保险柜和钥匙，二者保持原位。 | 密码库和保护密钥未受影响 | 你的密码库和保护它的密钥，官方都列在未受影响的一栏。 |
| 26–39 秒 | M2：通知卡收起，切到手机上手动打开熟悉的官方入口，用抽象图标表示。 | 自己打开官方入口核实 | 如果收到一封你没发起的恢复邮件，先别沿着它的链接走。自己打开平时用的官方应用再确认。你会先去哪儿核实？ |
