# 1Password 后台安全事件素材包

| 编号 | 内容和取景 | 作者、许可与使用限制 |
|---|---|---|
| M1 | 自画金库、钥匙、邮件通知和三张账户资料卡。第 0 帧金库已经上锁；邮件卡只写「意外的恢复请求」，不画发件地址、链接、验证码或密码。事实取自公告的 What information was affected / What was not affected 两节。 | 原创示意道具，画面标「示意」。事实来源及署名为 [1Password 官方公告](https://1password.com/blog/update-on-nov-2026-security-incident)。 |
