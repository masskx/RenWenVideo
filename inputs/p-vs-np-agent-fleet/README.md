# p-vs-np-agent-fleet 素材包

抖音竖屏选题。先读 [选题与核实记录](idea.md)，再用 [参考口播与分镜](script.md) 对照素材。配图均为原创示意，1080 × 1920 PNG，可直接导入剪辑软件。

| 文件 | 内容 | 来源和使用 |
| --- | --- | --- |
| [01-hook.png](materials/01-hook.png) | 小命题核验通过，主问题仍未解决 | 按 [项目首页](https://pequalnp.com/) 和 [实时看板](https://pequalnp.com/live) 原创绘制。00–03 秒、33–41 秒使用。两块状态卡可分别裁切，做拉远和盖章节奏。 |
| [02-route.png](materials/02-route.png) | 找路线与验路线的站点类比，蓝线从起点经过七个站点 | 自制假想地图，图内保留「类比示意」。08–17 秒使用。验路线阶段沿蓝线逐站点亮。数学背景见 [Clay](https://www.claymath.org/millennium/p-vs-np/)。 |
| [02a-route-blank.png](materials/02a-route-blank.png) | 同构图的找路线画面，适合先演一次走岔路 | 和 02 共用站点位置，切换时保持机位。 |
| [03-workflow.png](materials/03-workflow.png) | 找思路、查反例、写证明、Lean 核验 | 根据 [项目流程](https://pequalnp.com/how) 原创绘制，17–33 秒使用。先露出审核框，再倒回两个分支。通过状态只贴在单个命题上。 |

## 可补录的官方画面

| 来源 | 取景 | 画面口径 |
| --- | --- | --- |
| [项目首页](https://pequalnp.com/) | 首屏的题目与开放状态。进图例时只对准核验状态，避开赞助入口和动态数字。 | 可作为事实核对页。需要上屏可按授权情况自行录制，右下角标「Brilliant｜案例展示」。 |
| [实时看板](https://pequalnp.com/live) | 找到 Lean 核验区，取小命题被接受的一行。页面是实时的，录制时可选当天仍显示的条目。 | 读「项目看板显示」，保留命题编号，放大局部。 |
| [项目方法页](https://pequalnp.com/how) | 用作核对分工与检查条件的文字出处。 | 中段优先用随包示意图。 |

外部网页的画面和录屏复用许可未核实，随包提供链接和取景点。成片可全程使用 4 张原创示意素材。
