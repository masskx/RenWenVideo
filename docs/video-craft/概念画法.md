# 抽象概念怎么画

> 讲解视频里最难的是把一个抽象概念变成**看得见、会动**的东西。先把口播里的概念归到下面某一类，再挑一个画法，关键动作卡在说这个词的那一刻。同一个概念全片只用一个画法，中途不换比喻。
> 改编自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的 `knowledge/从11套里学到的.md` 第七节（MIT，© 2026 Dashi AI Lab）。

## 通用类别

| 概念类别 | 可以这样画 | 动作卡在 |
| --- | --- | --- |
| 范围、上限、容量 | 框或容器（框住多少、装满溢出）、量杯刻度、会缩放的取景框 | 说到“范围 / 上限”时框画出来 |
| 太多、太贵、负担 | 东西越堆越高后歪倒（硬币、纸堆），秤的一边压下去 | “太多”时开始堆，“撑不住”时歪倒 |
| 分类、种类、组成 | 几张不同的小卡 + 大括号 + 一个总名字（盖章） | 每念一类出一张卡，总名字盖章 |
| 能力齐全、条件都满足 | 清单逐项打勾（成绩单） | 念到哪项勾哪项，全勾后盖章 |
| 对比、只有 A 没有 B | 左右两栏 + 中间虚线，同一个主体两种状态 | 念到哪边亮哪边 |
| 步骤、流程、因果 | 编号①②③ + 箭头，一站一站走 | 每一站在念到时亮起 |
| 增长、变多、规模 | 柱子一根根长高、东西一层层铺开、数字滚动 | 数字被念到时滚到位 |
| 遗忘、丢失、过时 | 东西掉出框、变灰、淡出，或被划掉 | “忘了”时掉出去 |
| 输入 → 处理 → 输出 | 东西进入机器（盒子、漏斗、机器人），另一头出来变了样 | 进机器、出机器各卡一次 |
| 连接、断点 | 两端之间断开的桥或线，接上后有东西流过去 | “连起来”时接上 |
| 视野、格局 | 小鱼缸 → 窗外的大海；镜头从小处拉远到大处 | “全世界 / 全球”时拉远 |

## 想不出来时

1. 先问：这个概念在现实里像什么东西？那个东西会怎么动？
2. 优先挑“会动”的比喻：会堆、会掉、会接上、会变灰、会长高，而不是一张静态图标。
3. 一个镜头只演一件事。比喻太复杂就拆成两个镜头。
4. 实在想不出画法，就用“编号 + 关键词卡 + 印章”这个保底版式，再靠转场和节拍推拉保证画面丰富。
