# 配音（TTS）：只用本人的复刻音色（豆包语音）

> 2026-10-18 改写：配音只有一条路——用户在火山引擎“豆包语音”上做的**个人声音复刻（2.0）**。阿里云百炼（DashScope / CosyVoice / Qwen-Audio）和 edge-tts 的代码、配置和文档都已删除。复刻音色调用失败时**不要换别的声音顶上**，直接报错并告诉用户。

脚本：`scripts/generate-tutorial-voice.py`（教程：`npm run tutorial:voice -- <id>`；长文讲解的 `build-explainer.mjs --voice` 也调用它的 `--say` 模式）。

## 一、凭据和配置

环境变量（只从环境或本地 `.env` 读，**不要写进仓库、不要在对话里完整打印**；模板见 `.env.example`）：

| 变量 | 用途 |
|---|---|
| `DOUBAO_API_KEY` | API Key 鉴权（请求头 `X-Api-Key`） |
| `DOUBAO_APP_ID` + `DOUBAO_ACCESS_TOKEN` | 另一种鉴权：训练音色所在应用的 APP ID + Access Token（`X-Api-App-Id` + `X-Api-Access-Key`），设置了就优先用 |
| `DOUBAO_VOICE_ZH` | 中文复刻音色 id（`S_` 开头），默认音色 |
| `DOUBAO_VOICE_EN` | 英文复刻音色 id；英文片子写 `"voiceEnv": "DOUBAO_VOICE_EN"` |
| `DOUBAO_VOICE_ZH_ENERGY` | 可选：第二份“高能量”复刻（见 §四），场景上写 `"voiceEnv": "DOUBAO_VOICE_ZH_ENERGY"` |
| `DOUBAO_TTS_ENDPOINT` | 可选，默认 `https://openspeech.bytedance.com/api/v3/tts/unidirectional` |

缺鉴权或缺音色 id 时脚本直接退出并说明缺哪个变量。

配置（`tutorials/<id>.json`）：

```json
"tts": {"provider": "doubao"}
```

- 不写 `voice` 就用 `DOUBAO_VOICE_ZH`。`provider` 只能是 `doubao`（不写也按 doubao），写别的会直接报错。
- 每个场景写 `"pace"`（§三）；可选 `"mood"`、`"voiceEnv"`。
- 可选覆盖：`"paces": {...}`（档位表）、`"pauses": false`（关掉剪气口）、`"model": null`（不发 expressive 模型）、`"audio": {...}` / `"params": {...}`（直接并进请求）。
- 长文讲解（`explainers/<id>.json`）：`"voice": {"provider": "doubao", "rate": 1.16, "gapSeconds": 0.12}`，逐行合成（每行一条字幕）。

## 二、接口、时间戳和字幕

- 接口：`POST https://openspeech.bytedance.com/api/v3/tts/unidirectional`，请求头加 `X-Api-Resource-Id: seed-icl-2.0`、`X-Api-Request-Id`（每次一个新 uuid）。请求体 `req_params.text / speaker / audio_params`（`format: mp3`、`enable_subtitle: true`、`speech_rate`）。返回是一行一个 JSON 的流：`data` 是 base64 音频片段，最后一条 `code: 20000000` 表示成功。
- **请求里不要带 `"model": "seed-icl-2.0"`**（官方示例里有），服务端会报 `InvalidModel`；资源头已经选好了模型。脚本默认发 `model: seed-tts-2.0-expressive`（§四）。
- 计费按字符的资源是 `seed-icl-2.0`；`seed-icl-2.0-concurr`（按并发）没买会报 “quota exceeded for types: concurrency”。报 “not granted” 说明这个 key 没开通声音复刻 2.0，去火山控制台开通。
- 语速：豆包的 `speech_rate` 是 -50…100（100 = 2 倍速）；配置里的 `rate`（1.0 = 正常）换算过去，`rate: 1.16` → `speech_rate: 16`。

**一个场景整段只发一次请求**——语气能跨句连贯；以前按逗号切句、逐句合成再拼接，听起来“一个词一个词往外蹦”，那条代码已删除。

**时间戳怎么变成字幕和卡点**：

1. `enable_subtitle: true` 时，服务端每句返回一次 `sentence.words`（`word`、`startTime`、`endTime`，单位秒，整段连续的绝对时间）。
2. `map_timestamps` 把返回的字按顺序对齐到我们的口播文本：相同的字一起前进；服务端改写了读法的地方（“3” 读成“三”、英文拆分不同）文本指针照样一个字一个字往前走，几个字内遇到完全相同的字就重新对齐。结果是口播里每个非空白字符都有一个时间。
3. 剪气口（§四）会删掉一部分静音，被删段落之后的时间戳同步前移，卡点和字幕不会错位。
4. 口播按标点切成字幕块（每块 ≤ 15 个汉字宽，太短的并到下一块，显示不到 0.7 秒的和下一块合并）；每块的开始时间 = 它第一个字的时间戳，结束 = 下一块开始。`{a}` 卡点的时间 = 标记后第一个字的时间戳。都写进 `tutorials/<id>.timeline.json`，画面和字幕直接读它。
5. 每个场景的逐字时间缓存在 `public/audio/tutorials/<id>/<nn>-<scene>.words.json`；文本、音色、语速、情绪指令或剪气口参数一变，缓存就失效，重跑会重新合成该场景。

## 三、语速随内容和情绪变化

用的是用户自己的声音，**节奏要和画面对上**，所以语速不是全片一个数。写口播时就定语速：分镜的镜头表加一列“语速”。

| 档位 | rate | 用在哪里 |
|---|---|---|
| `slow` | 1.04 | 关键结论、转折、需要观众停一下的一句；结尾的提问 |
| `calm` | 1.1 | 解释原理、讲一个概念的来龙去脉 |
| `normal` | 1.16 | 一般讲解（默认） |
| `brisk` | 1.24 | 开场钩子、过程演示、画面动作密集的段落 |
| `fast` | 1.32 | 列举（工具名、步骤一个接一个）、快速回顾 |

- 场景上写 `"pace": "brisk"`（也可以写数字）。某一句要换节奏时，在**这句开头**写 `{pace:slow}`，从这一句起换档；标记写在句中会自动挪到句首——脚本只在句号处分段合成，不会把一句话切开。分段之间留 180 毫秒换气，时间戳按段平移。
- 档位校准过：用户的复刻音色在 `rate: 1.0` 时比普通 TTS 慢；配合剪气口，normal 约 5 字/秒。
- 档位表可在配置里覆盖：`"tts": {"provider": "doubao", "paces": {"brisk": 1.22}}`。

## 四、复刻音色“平、拖”：原因和办法（2026-10-17 实测）

复刻 2.0 主要复制**录音样本**的说话状态；样本是平稳朗读，合成出来就平。实测（同一句话，测音高起伏）：情绪指令 `context_texts` 几乎没用；`emotion` / `loudness_rate` 参数效果小；**口语化重写 + expressive 模型**起伏最大（+27%）。所以：**情绪靠“写出来”，节奏靠“剪出来”，语气上限靠“录出来”。**

1. **重录复刻样本（效果最大，用户自己做）**：按想要的成片语气录——站着、带笑意、比平时大声一点快一点，像给朋友讲刚发现的事；内容要有反问、惊讶、强调、转折。可以录两份（高能量 / 沉稳讲解），新 id 放进环境变量，场景用 `"voiceEnv"` 选。
2. **口播按“说”来写**（`文案.md` §七）：短句、反问、感叹、转折、直接对“你”说。**不要用省略号**——会读成长停顿。
3. **expressive 模型**：默认发 `model: seed-tts-2.0-expressive`；换回原模型写 `"tts": {"model": null}`。
4. **剪气口（默认开启）**：合成后把超过 170 毫秒的停顿剪到 170 毫秒（句号、问号、感叹号后留 240 毫秒），时间戳同步平移；再过一道轻量人声处理（去低频、3 kHz 提亮、轻压缩）。关掉：`"tts": {"pauses": false}`。
5. **`mood`**：场景上写 `"mood": "像短视频博主讲一个反转"`，作为 `context_texts` 发送；对复刻音色效果很弱，别指望它。
6. **声音以外的劲**：底乐跟着段落起落、音效落在卡点上、画面持续有变化。

## 五、读音和数字

- 口播文本里用 `[显示|朗读]`：字幕显示左边，TTS 读右边。例：`[Web3|Web three]`、`[0.81 秒|零点八一秒]`、`[GPT-4o|GPT 四 o]`、`[9222|九二二二]`。
- 多音字：在“朗读”一侧换同音字。
- 英文缩写、型号、版本号：先听一遍；读得不对就用 `[显示|朗读]`。
- 停顿靠标点：逗号短停，句号长停；要更长的停顿就断成新的一句，不要堆省略号。
