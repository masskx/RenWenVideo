- 一份 X 帖子合集：别人用 Opus 5.5 写代码做出视频后，把提示词（或只是帖子文字）贴出来，仓库收录成 `data/videos.json`。每条字段：`slug`、`author`、`post_url`、`category`（motion 369 / 3d 117 / explainer 116 / interactive 101）、`tech_tags`（canvas 267、svg 183、threejs 131、shader 92、gsap 86……）、`prompt`、`prompt_partial`、`skillry_url`（第三方重制页）。

- **大部分不是“好提示词”而是“好结果的帖子”**：300 条标 ·，原因依次是作者自述 / 作者评价（只说做了什么、花了多久，没提示词）、极短或开放委托（“做个酷视频”）、游戏或纯 3D 场景、“动态 15 秒 showreel / SaaS launch”套话、原文在上游就被截断（23 条，标注里写了「原文在此截断」）。

## 四、可以吸收的做法（按本仓库优先级归位）

**钩子**

- 第 1 秒就要有东西：`jhylee95-452427`“第 1 秒钩子，再分产品证据和 AI 两段”；`twoclipping-000267` 钩子按拍逐字落。
- 一句话能说清的反差就是钩子：`ldataengineer-823010`“10% 坠机率的飞机你会上吗？”把抽象风险换成一个人人能答的问题。
- `tanabe-fragm-322001` 的“延迟揭晓”：前 25 秒让人以为是别的东西，最后几秒才翻面——留到结尾的反转，不要放钩子位。
- `redpersongpt-284430`：每个概念写**前 2 秒钩子**，钩子先列 20 个再挑；`archiveexplorer-560622`：每一拍写 3 个标题选项再选。

**留人**

- **每 1.5–2 秒一个新想法**（`ik-builds-585923`）；`everestchris6-399895` 的量化版：每 30 秒 12–15 个构图，每个 1.4–3.5 秒；每 30 秒冻结 ≤ 1 秒，单次静止 ≤ 0.5 秒。可以直接当 `richness.mjs` 之外的人工核对线。
- **一镜一个想法**（`wani-shola-459278`、`daniel-haida-636937`），景别轮换、不重复布局（`everestchris6-399895`）。
- **物件驱动转场**：卡片变成下一张卡、图标变成下一场的主体（`daniel-haida-636937`、`twoclipping-496100`），比淡入淡出更“有事发生”。
- **变速和喘息**：低能量段给喘息、效果强度按段落 40/70/100%（`pound75423-464968`）；先静后响（`adrianduta96-992248` 前 12 秒无声）。
- **每个动作有可见结果**（`everestchris6-399895`）；**每项技能先证明再打勾**（`koushikde-937635`）——讲功能时先演出效果，再出名字。

**手机上看得清**

- 9:16 安全区写进规格：文字避开平台按钮列和底部文案区（`bilimfili1-459762`、`howdevelop-733090`）；`l3d1c-632524` 用真字体量宽、超出就缩。
- **静音也能看懂**（`howdevelop-733090`）：很多人刷到时是静音的，关键信息必须上屏。
- 每个功能至少停 2.5 秒（`bilimfili1-459762`）；不要直接贴截图，把截图拆成组件和图标来动（`ho-ba-761062`、`elkrispis-872980` 的反馈“用组件不要录屏”）。

**忠于脚本和素材**

- 事实文件（`everestchris6-399895`）、资料表标出处和可信度（`alexalbert-274839`）、尺寸对不上就标出来而不是瞎猜（`aayush4soni-644283`）。

**打磨**

## 六、不要照搬

- **画幅和时长**：绝大多数是 16:9 或方形（只有 `bilimfili1-459762`、`okazaky-084783`、`agioyaz-*`、`x4b47x-034026`、`qianqiongge-246969` 等少数是竖屏）。按 [选用指南.md](选用指南.md) §三 改写。
- **自带 TTS / 代码合成配乐**：ElevenLabs、edge-tts、Web Audio 合成都不用；只用用户的豆包复刻音色和本仓库音效库。
- **CTA 和评论诱导**：`als-link-301108`（“评论 VIDEO 领提示词”）、`iammukeshm-421585`、`archiveexplorer-560622` 第 9 拍（CTA）、`elkrispis-872980`（结尾 CTA）——抖音不允许站外引流，本仓库一律不做“评论领取 / 资料包 / 关注领”（[quick-reference.md](../quick-reference.md) §二）。
- **虚构产品和数据**：`brainextends-606193` 的虚构专辑封面、各种“虚构 app”模板——结构可借，内容换成素材里的真东西。
- **别人的品牌**：“Apple keynote 式”“a16z 式”“Spotify 主题”只学语法，不在画面上出现别人的 logo、字体和界面。
- **作者自述的数字**：“一次提示”“14 分钟”“零修改”“3.7 万行”都是作者说的；讲这些案例时写「据 @作者」，并按 `ac55/prompt-matrix.zh-CN` 区分“一次提示 / 纯代码 / 零素材 / 无人修改”。
- **`prompt_partial` 和截断条**：标注里带「（部分）」或「原文在此截断」的，读到的不是完整提示词，不要当成“照这个就能出这个片”。
- **游戏、可玩、纯 3D 场景**（52 + 61 条）：本仓库基本用不上，除非脚本讲的就是它们。

## 八、怎么查

```bash
node scripts/prompts/find.mjs --fit=盘点 --min=2                 # 某类脚本的 ★★ 全部（按价值排）
node scripts/prompts/find.mjs '数字|number' --fit='发布|对比' --min=1
node scripts/prompts/find.mjs 无限推近                           # 中文摘要和“可借”也会被搜到
node scripts/prompts/find.mjs --show=twoclipping-402193         # 全文 + 研读标注 + 原帖
```

- opus55 条目的标题现在是 `★★ 中文摘要 · 形式 · @作者`；`--show` 多一行“研读”（形式、适合、可借）。
- `--fit` / `--min` 只作用于有标注的条目（目前只有 opus55）；不加这两个参数时，其他来源照常参与搜索。
- 适合的类型：发布 对比 讲解 教程 盘点 新闻 开发者 轻松 中国风 音乐，另有 品牌片 3D 游戏。

## 九、换快照以后
