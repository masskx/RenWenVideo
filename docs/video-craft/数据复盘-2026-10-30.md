1. **选题差出 5 倍，比做工差得多。** 同样 7 分、同样 40 秒、同一天：llm-same-prompt 8,009，gemini4-carbon 3,856。“反常的真事 + 和观众的工作 / 钱 / 前途有关”中位 8.6k；新模型跑分中位 1.7k；“AI 写代码做视频”中位 1.9k。

4. **“AI 写代码做视频”这个题，观众不再觉得新鲜**：huashu-motion 第一版 54 秒自见、第二版 32 秒 393 播放、2 秒跳出 46 %；vibe 教程 2 秒跳出 46 %。“这是 AI 做的”不再是钩子——9 月 Opus 5.5 刚出时是，现在 X 上一天几百条。**但 sweety、vibe 每千播放的收藏和涨粉是新闻片的 2–10 倍**：看完的人是来学的、会关注。
5. **短的看得更全**：27–40 秒的片看了片长的 24–45 %；54–171 秒的 7–21 %。平均观看仍是 9–15 秒。
6. **主页访问转粉丝约 1/9**（222 访问 → 24 粉）：eth 带来 52 次主页访问、2 个粉。进了主页的人没看到“关注了以后会持续得到什么”。

## 三、之后的策略

**一句话：新闻片换播放，工具片换关注；两种都要从“和你有什么关系”开场，不从“AI 做了什么”开场。**

1. **选题先打分，再开工**（见下面的四问；四问里三个“是”才做，两个“是”只做 ≤ 30 秒短版或不做）：
   - 一句话里有没有一个**反常的事实**，外行也听得懂？（“AI 推翻了几百篇论文的前提”✓；“K3.1 Pro 跑分 xx”✗）
   - 跟观众的**工作 / 钱 / 前途 / 安全**有没有关系？（读博规划、机房怕热、Photoshop 免费了 ✓；某个 benchmark ✗）
   - 第 0 帧有没有一张**真东西的画面**（截图、实拍、成品）能撑住？
   - 有没有一个**数字**能在前 10 秒说出？
2. **配比**：每周约 5 条新闻片（选题四问 ≥ 3）、1–2 条工具 / 教程片（Opus 5.5 生态里真正能用的东西，按收藏设计）、可以穿插 1 条非 AI 的情绪片（late-night 的分享率说明观众愿意转）。新模型发布只在“和你有关”的角度成立时做（gemini4 的“你现在用不了”就比 mistral 的“跑分打折”好一倍多）。
3. **工具片的改法**：开场不说“这是 AI 做的”，说**它替你省了什么 / 赚了什么**（钱、时间、一个具体的活）；第 0 帧放成品最炸的一帧；30–45 秒；中间一张能截图的“三步”清单（收藏点）；结尾一句“你可以拿它做什么”。
4. **开放式问题开场 = 评论**：suanli 的问句开场带来全周一半评论。每周至少一支用“一个人人能接的问题”开场，结尾不回答死。
5. **主页转粉**：把最好的三支置顶（suanli、eth、phd）；新闻片和工具片各建一个合集，标题统一（例：「AI 新闻 · 一分钟」「用 AI 做视频」），让进主页的人一眼知道关注了能得到什么。
6. **发布节奏**：一天最多两条，间隔 ≥ 3 小时，下一次导出就能分清是题的问题还是撞车。10-28 起统一用模板 + 改造，继续。
7. **继续保持**：第一句 = 具体事件 + 数字（10-26 定规则以后发的片都做到了）；30–40 秒；高潮对配乐（suanli 的做法）。

## 四、X / GitHub 上 Opus 5.5 相关的开源项目（2026-10-30 查）

> X 的页面拒绝自动抓取（HTTP 402），以下来自 GitHub、Trendshift 和转述 X 帖子的报道；星数是不同日期的快照，只看量级。

**能做成片的选题（四问 ≥ 3）**

- **ArtCraft / PhotoCraft**（Brandon Thomas，github.com/storytold）：一个人用 Opus 5.5 写出 Photoshop、Premiere、Lightroom 等 Adobe 套件的开源 Rust 克隆，MIT / Apache-2.0；PhotoCraft 10-11 约 4.4 万星，之后各家报道 6–7 万星；仍是 alpha，报道说日常专业用途大概能到 50–70 %，专利风险被 Phoronix 等提出。四问：反常 ✓、和钱有关（订阅费）✓、第 0 帧有真界面 ✓、数字 ✓。角度要克制：“免费 Photoshop 来了？”+ 实测能做什么 / 不能做什么，不说“Adobe 完了”。
- **video-shotcraft 作者的说法**（据报道，约 1 万星）：“用 Opus 5.5 的人，可以把所有代码做视频的 skill 卸了”——skill 应该是方向和品味，不是能力封装。这正好是我们仓库的路线（模板 = 品味，代码我们自己写），可以做成一支“AI 做视频，现在拼的是什么”的观点片。

**对流程有用的**（主要来自 zhuyansen/awesome-claude-video-skills 的清单；星数是清单里写的，许可证没逐个核对，用之前打开仓库看 LICENSE）

- **zhuyansen/awesome-claude-video-skills**（约 1.3k 星）：379 个让编码 agent 做视频的开源仓库，按类型分、中英双语。注意它的「SAFE / CAUTION」是 Agent Skills Hub 的模型读 README 和安装步骤给的，**不是代码审计**——只能当初筛。以后找新模板、新招式先查这里，再按 `prompt-library` 的规矩快照（不改 vendor）。
- **和我们最像、值得拆的**：
  - heygen-com/hyperframes（约 75k）：“写 HTML，渲染成视频，给 agent 用”——和我们的 `scripts/page-render.mjs` 是一条路，看它怎么处理时间轴、字体和逐帧截图的速度。
  - remotion-dev/skills（约 5.9k）：Remotion 官方的 agent skill（`npx skills add remotion-dev/skills`），渲染、字幕、音频的官方做法，对照我们的 `踩坑清单.md`。
  - echris6/motion-video-kit（约 1.2k）：独立的“评审 agent”循环 + 质量线——和我们的 `jury.mjs` 同一个想法，可以对照它的评审项。
  - feitangyuan/onetake（约 3.5k）：“一镜到底、不切下一页”的动效片——正好治“PPT 念稿”的老毛病，可当一个新模板候选。
  - Alisa0808/vox-director（约 2.5k）：Vox 式剪纸拼贴讲解——讲解片的另一种画法。
  - Mr-funny/hbg-douyin-code-explainer-video（32）：清单里唯一写明抖音的，中文 9:16 讲解 + 配音 + Whisper 对齐 + 配乐 + 成片视觉 QA——和我们的管线几乎一样，看它的 QA 有没有我们没查的项。
  - calesthio/OpenMontage（约 73k）、ymybxx/SoloMCN（73，从热点到发布抖音 / 小红书 / B 站）：选题和发布环节的参考，我们现在这两头最弱。
