# 踩坑清单（扫片时最常见的问题）

> 前半部分改编自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的 `knowledge/从11套里学到的.md`（MIT，© 2026 Dashi AI Lab）；后半部分是本项目做片时实际踩到的。每次扫片、出静帧都对着这张表看一遍。

## 一、原项目最要紧的几条

1. **画面只由时间决定**：不用 CSS 动画、transition、`Date.now()`、不带种子的随机数（用 `hash(n)`）。逐帧渲染时，不跟着时间走的东西会乱跳。
2. **不写死秒数**：时间一律从时间轴取（教程的 `cue('a')`、长文讲解的 `stamp.at` 和字幕时间）。换一段口播，写死的秒数就错了。
3. **字幕带只放字幕**：好几套都出过部件掉下去、滚动卡片、纸堆穿过字幕区。本项目字幕带是 y 1290–1500，运动路线也不能经过。
4. **换场时最容易叠字**：上一镜的标注还没淡完，下一镜的部件已经进来。扫片时专门看每个镜头交界前后 0.5 秒（`scan.mjs --around=秒`）。
5. **镜头快速移动时，跟着跑的部件会被甩出画面**：按世界坐标让部件比镜头先到，或者逐帧确认不出画。
6. **字号按最长那句量**：打完的长句贴到发送键、溢出边框。改字号或让容器随字数变宽。
7. **页眉和字幕一样当禁区**：部件压住页眉的情况也出过好几次。
8. **改完一处要整段重看**：修一个时刻、没回头看别的时刻，副作用常常出现在别处。每次改动后重出扫片和静帧。
9. **满屏颗粒、渐变会让渲染变慢、文件变大**：纹理只生成一次；本项目里的表现是 mp4 码率上去，要提高 `--crf`。

## 二·五、“AI 味”：检查都过了，片子还是像 AI 做的 PPT

丰富度、卡点、扫片全过的 `ai-agent-team`（2026-10-15），用户的评价是“很差、AI 味很重”。对照观默的导演层逐项拆出来的原因（详见 [导演层.md](archive/导演层.md) 第零节）：

| 现象 | 原因 | 改法 |
|---|---|---|
| 东西都是一起“弹”出来的，像幻灯片动画 | 所有元素用同一个 `usePop` 弹簧、同一个 `Appear` 往上浮 | 每镜只有一个主事件；次主体、影子、标签按 `PHASE` 晚几帧，各用自己的函数 |
| 画面一直在“动”，但动得没有道理 | 丰富度靠 `beatTour` 每句整幅推拉、`shake` 整屏抖、光斑跟着卡点跑 | 关掉 `look.tour`；变化来自主体的过程（抛出、落下、压扁、回稳）和有理由的相机跟随 |
| 一看就是“科技模板” | 深蓝底 + 青紫渐变标签 + 彩色外发光 + 光斑 + 光点粒子 | 禁止无理由发光和渐变；一盏主光、哑光材质、接触影；强调色 ≤ 2 |
| 像 PPT | 一屏十几张圆角卡片、五六十个字，口播的话抄到画面上 | 一屏一个大主体 + 大量留白，画面只放观众要看的那几个字 |
| 没有重量 | 东西出现就出现，没有受力、接触、影子、余波 | 写清受力起点 → 接触帧 → 恢复；`toss`/`drop`/`squash`/`impulse` |
| 声音空 | 只有人声和一条循环底乐 | 接触帧上放音效（从同一个物理函数算出时刻），比人声低 12–18 dB |
| 每个镜头都是新的一页 | 每镜从空白重新弹出所有元素 | 至少一个主体贯穿多镜，变形成下一个状态 |
| 网页渲染时，模板要的 900 字重大标题出来是细体 | 缺字体时回落的是思源黑体可变字体；`new FontFace()` 不带字重描述载入可变字体，只用默认的 Regular | `page-render.mjs` 按文件名里的字重（900 / Black / Bold…）给静态字重实例（`/root/.cache/page-render-fonts/`，fontTools 生成，命令在脚本头部）；serif 字体回落到仓库的思源宋体 | huashu kinetic-type，2026-10-23 |
| 用 `--root` 渲参考仓库的样片，`out/` 写进了固定的快照目录 | 输出默认放在页面旁边 | `--root` 时输出放 `qa/page-render/…`；快照目录（`prompt-library/vendor`、`code`）永远不写 | lemo dataviz，2026-10-23 |
| lemo 的 briefing-board 样片跑不起来（`ship.png` 404，图片解码失败） | 有些样片的图片是它们自己的 `build.sh` 现生成的，仓库里本来就没有 | 先挑不需要构建步骤的样片（dataviz 能直接出帧）；要用有构建步骤的，先读它的 `build.sh` | lemo，2026-10-23 |
| 给道具配的颜色一上来就是“米白纸 + 橙 + 宋体”和“深底 + 橙” | 没有取色这一步，我会默认编出 huashu 点名的 AI 通用配色 | 先从素材取色（`palette.mjs`），写进 `## 导演`「风格」并注明来自哪里；道具零件不带默认风格，颜色和字体都从片子传进去 | PropsLab 校准，2026-10-23 |

## 三、扫片做法

- `node scripts/qa/scan.mjs <video.mp4>`：每秒 3 帧拼成 8×4 的图，一张约 10.7 秒，逐张看截断、叠字、闪烁、空白，字幕是不是跟着换。
- `node scripts/qa/marks.mjs <video.mp4>`：每个卡点前 0.1 秒、后 0.35 秒各一帧，“前”那格还没有动作、“后”那格已经开始出现，就是卡上了。
- `node scripts/qa/scan.mjs <video.mp4> --phone=秒,秒`：缩到 360 宽，要读的字必须读得清。
- 字幕抽几个时刻，和口播核对是不是同一句。
