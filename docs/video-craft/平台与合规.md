# 平台与合规：抖音 / 视频号 / 小红书的风格和隐性要求

> 用户 2026-10-23：“不能忘了我的目标是抖音这种中国的视频平台，要注意这种风格，以及一些隐性要求。”
> 和 [quick-reference.md](quick-reference.md)（观众、平台、硬规则）一起用；做 treatment 时对照 §一，发布前按 §三 逐条查。平台规则会变，标“待核实”的条目在第一次用到时去平台创作者中心 / 官方规则页确认，结果写回这里。

## 一、中文短视频的画面习惯（知识 / 科技区）

借国外代码视频的**方法**，但成片要像中文平台上的好片子，不是像 X 上的英文 motion design。

- **钩子在第一屏就写出来**：第 0 帧有一个大字结论 / 反常识的问题 / 一个数字（“大字报”式），观众不开声音也知道这条讲什么。黄金 3 秒决定划不划走，完播率决定推不推。
- **字幕是主角之一**：大字、粗体、描边、居中偏下；**关键词变色**（一个强调色），逐句出现；很多人静音刷。字幕不能挡主体，也不能和画面上的字重复。
- **信息密度高、口语化**：大约每 2–3 秒一个新信息或新画面；口播像对朋友说话，短句，有反问、有转折、有“你”。
- **花字和表情包是调味，不是主菜**：综艺式花字（`mg15/18-hanazi`）、贴纸、拟声词可以在一两个笑点上用，用多了显得廉价（用户 2026-10-22：“装饰元素堆得乱、显得廉价”）。账号的克制程度见 [账号风格.md](账号风格.md)。
- **知识区的成熟包装**可以对标：回形针 PaperClip（贴纸化实拍 + 扁平图标 + 精确图表 + 大画布运镜，`mg15/19-paperclip`）、林超（板书 + 公式卡片）、星球研究所（图片质感 + 地图 / 数据）。科技 / AI 区还有大量“录屏 + 口播 + 关键词字幕”的片子——那是底线，不是目标。
- **结尾落在一句“金句”或回到钩子**，不做“关注 / 领资料 / 评论区扣 1”。
- **封面**：主页九宫格里封面就是标题，大字 + 一个主体；抖音、视频号、小红书的裁切不同（见 §二）。

## 二、各平台的版面和规格

| | 抖音 | 微信视频号 | 小红书 |
|---|---|---|---|
| 画布 | 1080×1920 全屏 | 竖版信息流约 6:7 显示，点开全屏（[发布与风格偏好.md](发布与风格偏好.md) §一） | 3:4 或 9:16 |
| 遮挡区（按 1080×1920） | 顶部约 0–200（状态栏、搜索 / 标签）；右侧按钮列约 x 900–1080、y 800–1500（头像、赞、评论、收藏、分享）；底部约 y 1500 以下（作者名、标题、音乐） | 信息流里上下会被裁：要紧内容放中间 6:7 带（y 330–1590） | 底部标题区、右侧按钮 |
| 封面 | 主页按 3:4 裁；`cover.jpg`（3:4）+ `cover-9x16.jpg` | 6:7（`cover-6x7.jpg`） | 3:4，标题大字，**标题里放能被搜到的关键词** |
| 文案 | 标题 + 描述 + 3–5 个话题 | 描述可带话题 | 标题（含关键词）+ 正文分行 + 话题 |

这些数字是现有做法（`讲解动画规则.md`、`theme.ts` 的版式）的依据；**待核实**：各平台当前的界面遮挡区以真机截图为准，第一次核实后把截图放进 `docs/video-craft/assets/` 并更新这张表。

## 三、隐性要求（发布前逐条查）

不写在“规则”页面上、但会导致限流、判低质或下架的东西：

1. **原创度 / 搬运**：大段直接用别人的视频、整屏截别的平台、只配个音念一遍原文，容易被判“非原创 / 搬运”。外部素材只作证据、一段只服务一个点、加上我们自己的讲解和画面；标「@作者｜案例展示」。
2. **别的平台的痕迹**：不出现 TikTok / YouTube / X / 小红书等水印和 logo、别的平台的界面皮肤、二维码、外链、“去 xx 搜”“私信 / 加微信 / 主页领”（站外引流）。截图里的平台 UI 要裁掉或打码。
3. **AI 生成内容标识**：用户的复刻音色、生成图、合成画面都属于“AI 生成 / 合成内容”，发布时勾选平台的「内容由AI生成」声明；画面里有生成图的，发布包写明。依据：《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行，**待核实**具体条款对“显式标识”位置的要求）。
4. **广告法极限词**：不说“最、第一、唯一、全网首发、100%、国家级”等，不做绝对化承诺；对比竞品要有出处。
5. **境外 AI 产品**：可以讲新闻和能力，**不讲怎么翻墙、怎么注册 / 购买境外账号、怎么绕过地区限制**（也不出现“梯子、代理、节点”等词）；不引导国内用户使用未备案的服务。
6. **地图**：画中国地图必须用标准地图（自然资源部标准地图服务），边界画不准是严重问题；不需要地图就不画轮廓，用坐标、定位针代替（`tibet-quake-ai-rumor` 的做法）。
7. **灾难、医疗、金融、时政**：不报未核实的伤亡、不做预测、不给投资和医疗建议、不碰时政敏感话题；灾难类语气克制（`tibet-quake-ai-rumor`）。
8. **字体版权**：只用可免费商用的字体：思源黑体 / 思源宋体（Noto Sans / Serif CJK，本仓库默认）、阿里巴巴普惠体、阿里妈妈数黑体、抖音美好体、得意黑、站酷系列、霞鹜文楷、OPPO Sans、HarmonyOS Sans 等；**不用微软雅黑、方正、汉仪等未授权商用字体**。用别的仓库的样片代码时，把它的字体换成这些。
9. **音乐版权**：不用流行歌；用自己合成的底乐（`scripts/generate-tutorial-music.py`）或明确可商用的音效（[音效.md](音效.md)）。
10. **人物肖像和隐私**：真人脸、手机号、账号、住址打码；不拍 / 不用未成年人；不用可识别的普通人肖像做“反面例子”。
11. **低质判定**（**待核实**具体口径）：纯静态图片轮播、PPT 式翻页配音、画面长时间不动，容易被判低质。每 2–3 秒要有真实的画面变化（`richness.mjs` 只是最低线）。
12. **敏感说法软化**（来自 Xian 的发布经验，[学习/xian-梵高做片法.md](学习/xian-梵高做片法.md)）：自残、自杀、精神疾病的直白说法容易被限流，口播和画面上的字都改软：“割伤 / 割下”→“弄伤”，“自杀 / 开枪打中自己”→“离开了这个世界”，“疯子”→“怪人”，“精神病院”→“疗养院”；标题和描述避开“震惊”“最”“第一”这类标题党 / 绝对化用语（同 §三.4）。
