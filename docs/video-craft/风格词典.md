# 风格词典：把一句描述翻成能做的参数

> 用户说不出具体参数，只说得出感觉（“温暖一点”“要高级感”“像黑板报”）时，用这份把描述落成底色、配色、字体、线条质感、动效和转场；给了参考图时，配合 `scripts/qa/palette.mjs` 取色（见文末“照参考图做”）。
> 改编自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的 `knowledge/风格词典.md`（MIT，© 2026 Dashi AI Lab）。原文按 macOS 字体和 HTML Canvas 写，这里换成本项目的 Remotion 写法和渲染机上的字体；色值、适合与翻车点照原文保留。“已实测”指原项目做过样片，本项目尚未逐一做过。

## 一、描述词 → 参数

**热闹还是克制（1–5 分）**：1 分 = 1 个主色 + 1 个强调、一屏一个东西、多数时间静止（但丰富度检查照样要过，靠镜头推拉）；3 分 = 主色 + 2 个强调、一屏 2–3 个东西；5 分 = 4–6 色、装饰铺满、一直有小动作。分数只改颜色个数、装饰密度和运动幅度；字号、安全区、字幕带、一镜一事这些硬规矩不变。

## 二、字体（渲染机上有什么）

- 本项目的组件统一用 `"Noto Sans CJK SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`（黑体），等宽用 `"JetBrains Mono", "DejaVu Sans Mono", Menlo, Consolas`。云端渲染机只装了 Noto Sans CJK；Windows 本机有微软雅黑、宋体、楷体。
- 风格要衬线 / 宋体、楷体、圆体、手写体时：字体栈里先写想要的字体，**最后垫一个渲染机上一定有的**（Noto Sans CJK SC）；渲一张静帧确认真的用上了——族名写错或没装时 Chrome 会悄悄回退，不报错。
- 想用的字体渲染机上没有：放进 `public/fonts/`（本地，不提交；注意授权）并在组件里 `@font-face` 引用，或者换成有的字体。
- 中英混排时英文字体排第一，中文的竖直位置可能偏；标题位置以渲出来的静帧为准，别只信基线。

### 在 Remotion 里怎么做（替代原文的 Canvas 写法）

| 质感 / 动作 | 做法 |
|---|---|
| 纸纹、颗粒、网点 | 一张小贴图放 `public/`，CSS `background-image` 平铺；**不要每帧生成**；满屏颗粒会让文件变大，出片用更高的 `--crf` |
| 线稿一笔笔描出 | SVG `path` + `strokeDasharray` / `strokeDashoffset` 随进度变化（`ui.tsx` 的 `Arrow`、`Check` 就是这样做的） |
| 逐字写出 / 打字 | `typed(text, t, t0, cps)` 或按字切片；光标用 `blink` |
| 由虚到实 | 每个字 `filter: blur(…)` 从大到 0 + 透明度 |
| 辉光 | `textShadow` / `boxShadow` 一层低透明度；只给大字用 |
| 投影 | 错位实色块（硬投影）或一次性 `boxShadow`；别给大量元素加大模糊 |
| 定格一拍二 | `jitter(t, i)` 把时间量化到 12–15 张/秒 |
| 等距 / 3D | CSS `transform: rotateX() rotateZ()`，按 (x + y) 从远到近排层级 |
| 像素风 | 小尺寸画好再放大，`image-rendering: pixelated` |
| 转场 | `CutStage` 自带横扫、翻页、圆形遮罩、推移、故障；风格特有的（擦黑板、撕纸）照 `transitions.tsx` 的写法加一种 `CutKind` |

## 四、照参考图做（原项目“用法二”）

1. 读参考：写下 4–6 条“看到了什么”（底色、主线、字、部件、留白、质感）。是视频就再记动法：东西怎么出现、多快、怎么换场。
2. 取色：`node scripts/qa/palette.mjs <参考图> 16 [x:y …]`，先看按面积排的主色，再逐点取底、主线、标题、强调物。强调色 A/B：参考图里有红有蓝就用它自己的；只有一种，缺的用默认（红 `#d41928` / 蓝 `#2373ce`）；都没有，用色板里最醒目的两种对比色。其余颜色避开 A/B 的色系。算一遍对比度（`讲解动画规则.md` 第二节）。
3. 挑字体：先认参考里的字是哪一类（宋 / 黑 / 圆 / 手写 / 书法 / 等宽），再按第二节在渲染机有的字体里挑，渲静帧并排比。
4. 照 `风格卡模板.md` 写风格卡，存到 `docs/video-craft/styles/<风格名>.md`。
5. 出 3 张静帧（开头、中段、结尾，各取关键词开始后约 0.3 秒），和参考图拼在一起对比：配色、字体、线条质感、版式像不像；缩到 360 宽字还读不读得清；A/B 两个词是不是一眼认得出。一般要 2–4 轮才像。
6. 参考图版权由用户负责：只学画风，成片里不出现原图。

## 五、用一句话描述（原项目“用法三”）

一次问完这 7 个问题（答不上来的用括号里的默认值）：

| # | 问什么 | 决定什么 |
|---|---|---|
| 1 | 讲什么？有没有步骤、数字、对比？ | 版式：流程长卷 / 一屏一个点 / 往下读（按分镜内容定） |
| 2 | 想让观众有什么感觉？挑 1–2 个：温暖、可靠、好玩、高级、怀旧、紧张、安静 | 色温、圆角还是直角、动效弹不弹 |
| 3 | 年代感：现代 / 八九十年代 / 民国 / 未来（无所谓） | 字体、纸纹、网点、褪色 |
| 4 | 像什么材料：纸、黑板、白板、屏幕、玻璃、黏土、水彩、霓虹…… | 底和笔触的质感 |
| 5 | 颜色：偏暖 / 偏冷 / 黑白 / 高饱和 / 低饱和；有没有品牌色 | 底色、主色、A/B |
| 6 | 热闹还是克制，1–5 分（3） | 颜色个数、部件密度、运动幅度 |
| 7 | 给谁看（大众、手机） | 字号、一屏放多少字 |

然后用第一节把答案落成参数表，挑 2–3 个**真的不一样**的方向（不是同一套换个颜色），每个方向出 2 张同时刻的静帧拼成对比图，配一句话说明感觉、适合什么、风险是什么，给用户挑；挑定后写风格卡，再按 `SKILL.md` 的流程出片。没人可问时自己按描述推，把判断写进风格卡的“来源”。
