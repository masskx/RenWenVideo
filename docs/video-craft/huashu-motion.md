# huashu-motion：导演方法怎么用到本仓库

> 用户 2026-10-23：“以后做视频，也参考这个 skill，根据实际情况运用。”来源 [alchaincyf/huashu-motion](https://github.com/alchaincyf/huashu-motion)（花叔，MIT），读的是 v0.3.1、commit `52467f9`（2026-10-22）。可选参考，和 [quick-reference.md](quick-reference.md) 冲突时以速查页为准。

huashu-motion 本身是一套 HTML + GSAP 的做片工具（`om` 命令、studio 指着画面改、自己的配音和配乐）。本仓库用 Remotion + 豆包复刻音色，**工具不搬，只用它的导演方法**。原文最值得读的几份：`skills/huashu-motion/references/rhythm.md`（节奏）、`director.md` 末尾的 Film-wide taste rules、`library/techniques.md`（每个动作“说什么”）、`library/languages/data-story.md`（数字）、`kinetic-type.md`、`mechanism.md`、`system-diagram.md`。

## 一、直接用的

| huashu-motion 说的 | 在本仓库怎么做 |
|---|---|
| **第 0 帧就是海报**：主体已经在画面里，而且已经在动；不要空黑底上一个小东西慢慢亮起来 | 钩子场景的主角（大数字、网格、界面）用负的 `at`，让第 0 帧就有它；数字从第 0 帧前就开始滚，第 6 帧左右落定 |
| **镜头连贯（continuity chain）**：每个转场说得出“是什么东西把眼睛从上一场带到下一场” | 全片挑一个贯穿的物件（一把钥匙、一张点阵、一个数字），在钩子、中段、结尾反复出现；在分镜里写一行“镜头连贯” |
| **节奏是对比**：钩子 3 秒内；中段（30–60 %）有一段“密集段”；不要每场都同一个能量 | 中段挑一场做密集段：几个元素逐个落下、每个落点一声 tick（例：柱状图四根条每 7 帧落一根）；别的场景保持一场一个主动作 |
| **每两小节内必须有新东西**（口播片按口播走） | 和速查页“每 2–3 秒一个新变化”一致；卡点 `{a}{b}` 就是新东西的位置 |
| **数字落在说出它的那个字上**（count-up 落地 = 口播 = 音效） | 滚动数字的结束帧对准卡点；`sfx` 的 tick / chime 放在落定帧 |
| **用压暗其余来强调**，不要到处加箭头和框（data-story） | 强调一条数据时把其余压到 30–45 % 不透明度；这和 cinema 的“不加装饰”一致 |
| **每个动作有含义**（techniques.md）：ease-out 进场 = 有意图地到达；进得慢、出得快；弹簧只给“物理的东西” | cinema 的 `Reveal` / `rise` 就是减速进场；退场用 `leave()`，比进场快；数字和柱子不回弹 |
| **推近落点**：数字落地时 2× 或小幅推近 | 一场最多一次，用 5–8 % 的短推近（`beatZoom` 或单个元素 `scale`），不抖不弹 |
| **真材料**：界面、截图、数字都是真的；没有就用开放授权素材，写清来源 | 和本仓库“外部素材标来源、不编事实”一致；截图太小看不清时，把原句重新排版成大字（标“原文”），不要放一张手机上读不了的截图 |
| **给观众能带走的东西**（清单、原句、参数） | 结论场景尽量落成一张能截图的清单或一句原话 |
| **自己先给三条“挑剔导演”的意见再交片** | 渲染后按 1× 看一遍，写三条：哪里无聊、开头是不是一个强想法、画面是不是太单薄；改完再给用户 |

## 二、不用或要改着用的

- **三个方向选一个**：本仓库已经定了 cinema 风格（用户 2026-10-22），不再每条做三个方向；只有用户要新风格时才用。
- **3D / depth 方向**：只在素材确实需要（界面层次、实物）时用。
- **结尾署名 “Made with huashu-motion”**：只给用它的工具做的片子；我们没用它的运行时，不加。
- **配乐、配音**：本仓库只用用户的复刻音色和自己的底乐 / 音效；它的 `om voice` / `om sound` 不用。“每个重要落点一声音效”照用。
- **蒙太奇快切（一拍一切）**：知识类口播片很少需要；真要用，放在中段密集段，2 秒以内。

## 三、做片时的自查（加在分镜里）

1. 第 0 帧截图能当封面吗？主体在不在、在不在动？
2. 写一行“镜头连贯”：贯穿物件出现在哪几场。
3. 指出密集段在第几秒（应在全片 30–60 %）。
4. 每个滚动数字落定在哪个卡点上。
5. 渲染后自己写的三条意见，以及改了什么。

用过的片子：`agent-compute-hijack`（钥匙贯穿；柱状图是密集段）、`ai-same-take-on-humans`（36 点网格贯穿；6 个不同答案逐个亮是密集段）。
