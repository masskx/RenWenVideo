# 评审表：让一个没做这支片的评委打分，再改一轮

> 来源：mg-styles-15 的评审提示词（[vendor/…/rubric.md](prompt-library/vendor/Vincentwei1021__mg-styles-15/49052d8/rubric.md)，MIT）——原片都是“制作 → 独立评审 → 按评审改 → 再评审”做出来的；ClaudeAnimationBase 的三档放大审片；lemo 的“全速看一遍”；Xian 的“截帧拼总览查重叠、遮挡、空画面”。按我们的平台（抖音 / 视频号 / 小红书知识区，9:16，≤ 60 秒，中文口播）改写了维度。
> 用法：`node scripts/qa/jury.mjs <id>` 生成评审包 `qa/<id>/jury/`（总览图、和对标 / 最近几支的并排图、手机尺寸帧、简报和导演一节、口播全文、复述检查结果、下面这段提示词）。评委是**另一个 agent**（用户允许开子代理时）；不允许时我自己按同样格式评，报告里写“自评，非独立”。分数记进 [经验.md](经验.md)。

## 打分锚点（1–10）

5 = 学生作业；6 = 模板水平（能用，但一看就是套模板）；7 = 专业；8 = 高端商业；9 = 获奖候选；10 = 世界最好。第一版大多是 5–7，不要虚高。

## 评委提示词

```text
你是抖音 / B 站知识区头部账号的视觉总监，也是 Motionographer 级别的动态设计评委。这支片不是你做的，请严格、具体地评，
目标是让它达到知识区头部账号的水准。客气没有用，具体才有用。

材料都在评审包 qa/<id>/jury/ 里：jury.md（简报、导演决定、口播全文、机器检查结果）、sheet.jpg（每 0.5 秒一帧的总览）、
compare.jpg（和对标、和我们最近几支片并排）、phone_*.png（缩到手机宽度的帧）、key_*.png（关键时刻全分辨率帧）、
video.mp4（成片）。

1. 先好好看：总览图看结构；关键动作前后看逐帧；全分辨率帧看字、边缘、锯齿、色带、裁切；手机尺寸帧看能不能读。
2. 按下面每一项打 1–10 分（5 学生作业 / 6 模板 / 7 专业 / 8 高端 / 9 获奖候选），每项一句理由：
   - hook：第 0 帧能不能当海报、前 2 秒有没有真东西在动？第一句是不是“一件具体的事 + 数字 / 时刻 / 反常”（不是日期、问候、背景、
     “这条视频”）？核心数字 / 结论有没有在前 10 秒说出？（我们的后台数据：观众平均只看 6–16 秒，docs/video-craft/hooks.md）
   - idea：全片是不是一个点子、一个转折、一个贯穿的物件，而不是“标题 + 三条要点”？和观众有关的风险题，结尾有没有一个马上能做的
     动作（分享的来源）？教程片有没有一个能截图收藏的清单画面？
   - picture：是不是一句一画、具体代替抽象（道具、数字、物件在“发生事情”），而不是写着字的盒子？
   - text：上屏字是不是只放观众要“看”的（数字、名字、原话）？有没有在复述口播（像加了动画的 PPT）？
   - motion：缓动、间距、预备和跟随、弧线、转场、卡点；数字是不是落在它的词上；有没有死画面或抖动？
   - design：构图、主次、主体大小（关键时刻 ≥ 画面高 1/3）、字体排版（中文也要讲究）、配色是否明亮有对比、不沉闷？
   - phone：手机上字够不够大、重要内容有没有压在平台界面区、字幕有没有挡主体？
   - sound：配乐、音效、和画面的同步、混音（口播清楚、音乐不抢）。
   - fidelity：事实和数字有出处、作者自述标了「据」、模拟数据标了“模拟 / 测试”、没有编造。
   - platform：有没有别的平台水印 / 引流 / 极限词 / 境外服务引导 / 不合规地图（docs/video-craft/平台与合规.md §三）。
3. 列出“致命问题”：任何看起来像通用模板或 AI 套路的、中文不自然的、字体回落或豆腐块、复述口播成片的、事实没出处的。
4. 给 5–10 条修改，按对观感的影响排序。每条：时间码、看得见的问题、为什么要紧、具体怎么改（技法和数字：缓动曲线、帧数、像素、
   颜色、字体、换成什么道具）。宁可几个大升级，不要一堆小毛病。至少一条要提升“哇”的程度，不只是打磨。
5. 和 compare.jpg 里我们最近几支片比：这支是不是又一个样子（结构、开场、招牌镜头、镜头路线、配乐形状、结尾）？
返回：分数表、致命问题、修改清单、和最近几支的比较。
```

## 改一轮（回到做片的会话）

1. 先留一份当前版本（`douyin/<id>/` 里的旧 mp4 改名 `video-v1.mp4` 留在 qa，或用 git 记住提交号）。
2. 致命问题和影响最大的前三条必须改；有更好的改法可以替换，写明为什么。不要把评委说的优点改坏。
3. 重渲、重跑机器检查、重新看帧，确认改到位；再评一轮。两轮分数都写进 [经验.md](经验.md)。
