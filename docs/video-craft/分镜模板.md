# 分镜（storyboard）怎么写

> 写画面代码之前先写分镜：先写**导演 Brief**（[导演层.md](导演层.md) 第一节的八项），再写每个镜头讲清什么、关键词在哪个时刻、谁是主体、受力从哪来、在哪一帧接触、各层怎么错开、音效落在哪。写不出主动作的镜头就是只有字的镜头，要重想画面。
> 改编自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的 `examples/token/分镜.md` 和用法一第 3 步（MIT，© 2026 Dashi AI Lab）。

存放位置：`tutorials/<id>.storyboard.md` 或 `explainers/<id>.storyboard.md`，和配置文件放在一起提交。例子：[`tutorials/workbuddy-15-skills.storyboard.md`](../../tutorials/workbuddy-15-skills.storyboard.md)。

## 文件结构

```markdown
# <标题> · 分镜

- 来源：<原帖 / 原文链接>；作者；改写了什么、没搬什么
- 片长约 N 秒；配音：<edge-tts / CosyVoice 音色、语速>；流水线：<长文讲解 / 操作教程>
- 参考：<画廊里选的 1–2 个作品；需要时加审美参考库里的 1 个网站>；拆出来的关系：<主次 / 运动 / 光 / 声 / 留白与排版各一句>
- A/B 固定色：A =「…」（出现在第几句）、B =「…」；字幕强调词：…
- 只画口播里说了的东西；口播没讲的，不加画面

## 导演 Brief

1. 目标：给谁看？看完记住哪一句？
2. 分镜与主次：起势 / 发展 / 收束各是哪几镜；贯穿全片的主体是什么
3. 轨迹与相机：主体从哪到哪；相机什么时候、为什么动；末镜定住
4. 运动与物理：谁受力、在哪接触、怎么回弹；材质的重量和弹性
5. 材质与光：手感；主光方向；接触影
6. 节拍与声音：底乐怎么分段；哪些事件有音效、用哪种
7. 禁止项：导演层第九节 + 本片补充
8. 验收标准：导演层第十一节 + 本片补充

## 镜头一览

| 镜头 | 台词（含 {a}{b}{c} 卡点、{pace:…} 换档） | 语速（档位 + 理由，见 配音.md §〇·二） | 画面要讲清的 | 主体 / 次主体 / 背景 | 受力起点 → 接触帧 → 恢复（卡在哪个词） | 错相 | 音效 | 转场 / 主体怎么带到下一镜 |
|---|---|---|---|---|---|---|---|

## 自查（写完分镜就过一遍）

- [ ] 每个镜头 1.5–5 秒只讲一件事；长镜头里每 2–3 秒亮起新的一步
- [ ] 每个镜头都有主动作，有受力起点和接触帧，卡在说出那个词的时刻（教程用 `{a}`，长文讲解用 `stamp.phrase`）
- [ ] 同一时刻只有一个主事件；次主体、相机、影子、标签按错相表晚几帧
- [ ] 至少一个主体贯穿多个镜头（变形成下一个状态，而不是每镜重新弹出）
- [ ] 卡点标记放在句子边界上（逗号、句号之后），CosyVoice 逐句合成时这里的时间是精确的
- [ ] 一句里连着念的几个数字（“79 种、192 套、74 组”），每个数字前都放一个卡点，不要把后面的数字卡到下一句
- [ ] 转场至少 3 种，同一种不连用 3 次；换话题用大转场
- [ ] 开头 3 秒至少 2 个变化
- [ ] A/B 两个词在字幕里至少各出现 2 次；一屏强调色 ≤ 2
- [ ] 每个接触帧都写了音效；音效不压人声
- [ ] 对照禁止项过一遍
```

## 镜头一览的写法要点

- **台词**写实际要念的句子，卡点标记一起写进去，这样分镜和 `tutorials/<id>.json` 的 `narration` 是同一份。
- **画面要讲清的**：一句话，观众看完这个镜头该懂什么。
- **主体 / 次主体 / 背景**：例如“任务卡 / 接收的 agent 和它的影子 / 纸纹慢慢流动”。
- **受力起点 → 接触帧 → 恢复**写“说到哪个词时谁被什么推动、在哪一帧接触、怎么回稳”，例如“说到‘交给文案’时任务卡从调研员头上抛出，第 0 帧接触文案，文案压扁 3 帧、下沉后回弹，影子 +6 帧恢复”。不要写“卡片弹出”。
- **错相**写这一镜各层晚几帧，例如“接收者 +4、相机 +5、影子 +6、标签 +8”。
- **音效**写事件和种类，例如“抛出 whoosh −3 帧；接触 tap 0 帧；落定 tick +4 帧”。
- **转场**写进下一镜用哪种：步骤或话题变化用大转场（横扫、翻页、圆形遮罩），同一话题内用小转场（推移、故障、上推）。

## 出片前的静帧确认（原项目的“3 张静帧点头”）

分镜写完、画面写完后，先出 3 张静帧（开头、中段、结尾，各取关键词开始后约 0.3 秒），自己看过再给用户看，用户点头再出整段。没人可问时，把判断和理由写在分镜文件末尾的“静帧判断”一节。静帧之外，再用 `scripts/qa/frames.mjs` 逐帧看一个主事件前后 ±10 帧，确认预备、接触、压扁、回稳和错相真的出现了。
