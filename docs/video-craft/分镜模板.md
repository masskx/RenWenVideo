# 分镜模板（灵活版）

> 2026-10-18 起的模板；2026-10-23 加了必填的 `## 导演` 一节（用户：“把学到的内容内化、用在做片上”）。**必填：`## 简报` 五项 + `## 导演` 十项**，`scripts/qa/brief.mjs` 查这两节和时长（2026-10-23 以前的旧片加 `--legacy`）；`## 镜头表` 强烈建议写（缺了只提醒）；其余各节可选。怎么想这些决定：[导演方法.md](导演方法.md) §三。旧的固定模板（导演 Brief 八项、主体 / 受力 / 错相 / 音效列）在 [archive/分镜模板.md](archive/分镜模板.md)，想做精细动效时可以参考。

存放位置：`tutorials/<id>.storyboard.md`，和配置一起提交。

```markdown
# <标题> · 分镜

## 简报

- 钩子台词：<第一句口播，0–3 秒内说完：一件具体的事 + 数字 / 时刻 / 反常；不报日期、不问候、不讲“这条视频”（brief.mjs 判不过）；写明用了 hooks.md §一 的第几种开法>
- 钩子画面：<0–3 秒画面上是什么：大数字 / 结果 / 对比，必须是片子里真的有的东西>
- 核心看点：<全片最重要的结论或数字，观众看完要记住的那一个；要在前 10 秒说出（观众平均只看 6–16 秒，brief.mjs 按配音时间线查）>
- 收藏点：<可选；教程片（配置写 "kind": "tutorial"）必写：一个能截图的清单画面（步骤 / 命令 / 检查项），在第几秒、停多久>
- 结尾台词：<最后一句口播；写明是 抖音技巧.md §三 五种结尾里的哪一种（动作 / 回扣开头 / 翻转判断 / 站队问题 / 下一集）；说完 1 秒内结束，不喊关注点赞>
- 标题·视频号：<…>
- 标题·抖音：<…>
- 标题·小红书：<…，带能被搜到的关键词>

## 导演

- 模板：<库里的模板 id：lemo/<风格> 或 opuscar98/<号>，按 prompt-library/选用指南.md §〇 选；写一句为什么是它，以及照搬了它的哪几样（版式、字幕、包装、字体、调色、剪辑语法、声音、原生招式）。brief.mjs 查 id 在库里存在>
- 点子：<一句：“___ 想要 ___，但 ___，所以 ___”或“观众以为 ___，其实 ___”。一个主体、一个转折，不是三条要点（lemo、cab）>
- 对标：<1–2 部参考（库里 id / 链接 / 用户给的）；学什么 / 不拿什么（lemo、ovp）>
- 结构候选：<① … ② … ③ …；选 ②，因为 …（lemo：第一个想到的通常是套路；情绪曲线式见 学习/xian-梵高做片法.md）>
- 风格：<库里哪份 STYLE / 提示词 + 抄下来的 3 条关键技法；或 huashu 模板名；为什么它从题材里长出来（Xian：视觉从题材长出来）>
- 底色：<哪些场景深底（钩子、低谷、高潮、结尾）、哪些浅底（讲事实），为什么（Xian：底色就是情绪）>
- 贯穿物件：<一个具体的、会变形的东西，从开头带到结尾，怎么变（pdoom、huashu、mg15 回形针）>
- 招牌镜头：<只有这支片有的一个镜头，在第几秒，用什么做（Remotion / 网页 / huashu 模板）（lemo）>
- 第0帧：<第 0 帧画面上已经有的主体 + 大字结论或数字（huashu、抖音黄金 3 秒、Xian 封面帧）>
- 高潮停留：<哪一刻多停 ≥ 1.5 秒、正好能当封面（Xian：高潮多停 2 秒）；放在最后一句之前，片尾留白 ≤ 1 秒（抖音技巧.md §三）>
- 配乐：<可选但建议：score 的 mood（tension / news / warm / wonder / playful，按底色和情绪选）、climax 场景（落在小节第一拍、整套进来）、lifts（后面的转折）；音效.md §六>
- 和上一支不同：<结构 / 开场 / 招牌镜头 / 镜头路线 / 配乐形状 / 结尾，六项里至少四项和最近三支不同，写出是哪四项（lemo）>

## 镜头表

一句口播一行（Xian：一句一画，纯文字静止不超过 2 秒）。“画面”写**具体的东西和它做了什么**（盖章砸下、数字滚到 89.6、门自己开了），不写“标题 + 面板”。道具在 `src/tutorial/props.tsx`。

| 口播（一句） | 画面：具体道具 / 事件 | 景别 | 运镜 | reads（观众依次看懂什么） | 上屏字（只放要“看”的） |
|---|---|---|---|---|---|
| … | … | 近 | 推 | 1. … 2. … | 89.6% |

## 计划（可选）

| 场景 | 时长 | 画面 | 口播要点 | 语速 |
|---|---|---|---|---|
| hook | 0–3 秒 | … | … | brisk |
| … | | | | |

总长约 N 秒（≤ 60，除非用户同意更长）。

## 素材和出处（可选，但用了外部素材就要写）

- <素材文件> — <作者 / 链接>；用在哪个场景；作者自述的数字标成「据 @作者」

## 参考提示词（可选）

- <提示词库 id + 用了哪一招 → 哪个场景>，例如 `lemo/dark-keynote §8 数字乱码落定 → hook`（[prompt-library/选用指南.md](prompt-library/选用指南.md)）

## 其他（全部可选）

- 风格 / 配色、A/B 固定色、封面卡（见 封面.md）、镜头细节、音效、静帧判断……按需要写。
```

## 写法提示（不是硬规则）

- 写完跑 `node scripts/qa/brief.mjs <id>`；做完画面跑 `node scripts/qa/echo.mjs <id>`（上屏字超过三分之一在复述口播就不过）。
- 场景数量、长短跟着素材走：有一段好录屏，就让它占满全屏多播几秒；只有一个数字，就把数字做大。
- 每 2–3 秒给一个新东西：新数字、换画面、一组对比、一个高亮。
- 卡点标记 `{a}` 放在要卡的那个字前面；时间来自配音的逐字时间戳。一句里连着念几个数字，每个数字前各放一个卡点。
- 需要精细动作时，`src/fx` 里有弹簧、抛落、挤压、相机跟随等工具（[动效与画面变化.md](动效与画面变化.md)）。
