# 分镜模板（灵活版）

> 2026-10-18 起的模板。**必填：`## 简报` 的五项 + `## 参考提示词`**（2026-10-21 起，至少一条提示词库 id），`scripts/qa/brief.mjs` 查这两节和时长；其余各节全部可选，按脚本和素材需要写，不需要就删掉。旧的固定模板（导演 Brief 八项、主体 / 受力 / 错相 / 音效列）在 [archive/分镜模板.md](archive/分镜模板.md)，想做精细动效时可以参考。

存放位置：`tutorials/<id>.storyboard.md`，和配置一起提交。

```markdown
# <标题> · 分镜

## 简报

- 钩子台词：<第一句口播，0–3 秒内说完；脚本给了就照抄，换了的话写明用了 hooks.md 的第几种>
- 钩子画面：<0–3 秒画面上是什么：大数字 / 结果 / 对比，必须是片子里真的有的东西>
- 核心看点：<全片最重要的结论或数字，观众看完要记住的那一个>
- 结尾台词：<最后一句口播>
- 标题·视频号：<…>
- 标题·抖音：<…>
- 标题·小红书：<…，带能被搜到的关键词>

## 计划（可选）

| 场景 | 时长 | 画面 | 口播要点 | 语速 |
|---|---|---|---|---|
| hook | 0–3 秒 | … | … | brisk |
| … | | | | |

总长约 N 秒（≤ 60，除非用户同意更长）。

## 素材和出处（可选，但用了外部素材就要写）

- <素材文件> — <作者 / 链接>；用在哪个场景；作者自述的数字标成「据 @作者」

## 参考提示词（必填，至少一条）

- <提示词库 id + 用了哪一招 → 哪个场景>，例如 `lemo/dark-keynote §8 数字乱码落定 → hook`、`opus55/twoclipping-496100 上一场的卡片变成下一场主体 → step2`（找法：`node scripts/prompts/find.mjs --fit=<脚本类型> --min=2`，[选用指南.md](prompt-library/选用指南.md) §二；id 必须能 `--show` 到）
- 另外照 [quick-reference.md](quick-reference.md) §十 的做片手法；哪条因为素材做不到，在这里写一句为什么

## 其他（全部可选）

- 风格 / 配色、A/B 固定色、封面卡（见 封面.md）、镜头细节、音效、静帧判断……按需要写。
```

## 写法提示（不是硬规则）

- 场景数量、长短跟着素材走：有一段好录屏，就让它占满全屏多播几秒；只有一个数字，就把数字做大。
- 每 2–3 秒给一个新东西：新数字、换画面、一组对比、一个高亮。
- 卡点标记 `{a}` 放在要卡的那个字前面；时间来自配音的逐字时间戳。一句里连着念几个数字，每个数字前各放一个卡点。
- 需要精细动作时，`src/fx` 里有弹簧、抛落、挤压、相机跟随等工具（[动效与画面变化.md](动效与画面变化.md)）。
