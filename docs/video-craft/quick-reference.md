# 速查（每次做片必读，只有这一页）

> 2026-10-18 起，这一页和根目录 `CLAUDE.md` 是仅有的必读规则。`docs/video-craft/` 里其他文档都是**可选参考**，和这一页冲突时以这一页为准；旧的硬规则（导演层禁止项、物理动作链、八项 Brief、旧分镜模板）在 `archive/`。

## 〇、观众、题材、平台（全仓库只在这里定义，改这里就行）

- **观众**：说中文、正在用或想用 AI 工具的人——想知道最近出了什么、它能帮自己做什么。不限定职业或身份，不要把观众写窄（比如只写“研究生”“程序员”）。
- **题材**：AI 工具和 AI 新闻——编程 agent、新模型、工作流、创作者工具、研究工具。
- **平台**：同一条视频发 **微信视频号、抖音、小红书**；发布包里三个平台的标题、描述、话题分开写（小红书标题要带能被搜到的关键词）。

## 一、优先级（从上到下，前面的没做到，后面的不用做）

1. **钩子**：前 1–3 秒就给出、说出最有意思的东西。
2. **留人**：每隔几秒就有新东西（新数字、新画面、新对比）；不值这几秒的一律删。
3. **手机上看得清**：字大、用满全屏、要紧内容不放在平台界面会挡住的区域。
4. **忠于给定的脚本和素材**：不编事实；作者自述的说法标成“作者说”。
5. **打磨**（动效、转场、音效）——前四条都满足了再做。

## 二、脚本和素材怎么用

- 脚本一般来自策划 agent（growth）：钩子、正文、结尾、标题，格式随意。**以脚本为准**，按手里真有的素材决定场景数量、长短和画面——不套固定的场景数、镜头表或动画配方。
- 脚本有钩子就用；钩子弱或没有，从 [hooks.md](hooks.md) 里挑一个改写，并告诉用户用了哪一个。
- 钩子必须有片子里**真的出现**的画面撑着；第一人称只说真发生过的事（配音是用户本人的声音）。
- 脚本里的事实和数字要能在素材里找到出处；找不到的，问用户或删掉，不要补。创作者自己报的数字写成「据 @作者」。

## 三、时长和节奏

- 默认 **≤ 60 秒**；脚本确实需要更长、且用户同意时，在配置里写 `"maxSeconds"`。
- **0–3 秒是钩子**（全仓库统一按 0–3 秒）：第 0 帧就有内容，第一句口播 0.5 秒内开始。
- 每 2–3 秒有一个新变化；单个场景一般不超过 8–10 秒。
- 口播约 4.8–5.5 字/秒；短句（≤ 16 字）、口语、不用省略号。写法参考 [文案.md](文案.md) §七。

## 四、手机可读

- 要读的字 ≥ 40 px，字幕 ≥ 60 px（1080 宽画布）；纯装饰的小字不能带信息。
- 用满全屏；右侧按钮列和底部文案区不放要紧的字。具体版式数字见 [讲解动画规则.md](讲解动画规则.md)。
- 缩到 360 px 宽（`scan.mjs --phone`）还要读得清。

## 五、配音

- 只用用户本人的复刻音色（豆包语音），每个场景整段合成，逐字时间戳驱动字幕和卡点；edge-tts 只在用户同意时作备用。见 [配音.md](配音.md)。
- 每个场景写 `"pace"`（slow / calm / normal / brisk / fast），钩子一般 brisk。

## 六、画面风格

- 基准：`tutorials/deepseek-vs-opus55`——蓝图深底、细网格、等宽小字标注 + 黑体大字、A/B 两个固定强调色（琥珀 / 青）、一屏一个大主体、外部素材原样嵌入并署名。在它上面改进，不要丢掉这套样子。
- **不再有“AI 味”禁止项**：发光、粒子、整幅推拉、渐变都可以用，只要它帮钩子和留人、不挡字。是否用按素材决定。
- 外部素材：静音，右下角「@作者｜案例展示」，作者链接写进发布包 README。

## 七、必填简报（写进 `tutorials/<id>.storyboard.md` 的 `## 简报`）

钩子台词、钩子画面、核心看点（主要结论 / 数字）、结尾台词、三个平台的标题。其余（选题卡、镜头表、分镜细节）都可选，按素材需要写。模板：[分镜模板.md](分镜模板.md)。

## 八、提交前的检查

```bash
node scripts/qa/brief.mjs <id>            # 简报五项、时长和口播字数预算
node scripts/qa/cover.mjs <id>            # 封面
node scripts/qa/richness.mjs douyin/<id>/video.mp4
node scripts/qa/marks.mjs douyin/<id>/video.mp4
node scripts/qa/scan.mjs douyin/<id>/video.mp4 [--phone=s1,s2,s3]
npm run lint
```

另查格式（1080×1920、30 fps、H.264 + AAC）、响度（约 −15 LUFS）、大小（< 100 MB）。静帧自己先看，再给用户看。
