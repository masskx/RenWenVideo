# PDoomVideo：同一首歌的水彩卡通版

> 仓库 JohnHeibel/PDoomVideo。**没有许可证，所以本仓库不复制任何文件**，只记版本（fa546a3）和下面的学习笔记。同一作者把它整理成了 ClaudeAnimationBase（MIT），代码以那份为准：[ClaudeAnimationBase.md](ClaudeAnimationBase.md)。2026-10-23 读。

## 它是什么

p5.js + p5.brush 画的水彩卡通 MV，主角是一个叫 Clawd 的小角色和一位研究员。和 pdoom-video 讲同一首歌，正好对照：一个是冷幽默的版画论文，一个是热闹的绘本舞台剧。

## 最值得学的

1. **字要少**（它的 STORYBOARD 原话）：“每个笑点都用画面和表演讲。全片只用少数几个大拟声词（FOOM、BOOM、CHOMP），很少用一个短词。**不要给东西贴标签，不要字幕说明，不要重复歌词的牌子**（卡拉 OK 已经有了）。**字多的画面更难看**，拿不准就不放字。” → 直接对应我们的毛病：大标题 + 面板里的字在复述口播。
2. **每个镜头都有事发生**：有角色在做事、东西坏了、变形、追逐、掉落。
3. **布景，不是卡片**：每一章发生在一个地方（实验室、舞台、太空、公路、数据中心），镜头在里面移动；四次副歌回到**同一个舞台**，每次升级。
4. **有动机的转场**：章节之间用笔刷擦除；章内靠动作带过切点（一口咬下变黑、火箭、坠落、穿过眼睛的推近、气泡破、门一摔）。
5. **情绪变化不跳**：眼睛先挤、身体压扁伸展“一惊”、冒一个小表情符号，再睁开新的眼神。
6. **每个镜头都有运镜**：推、摇、俯仰、甩、拉远或卡拍的震动。
7. **全片配色弧线**：暖奶油灯光 → 天蓝 → 太空紫金 → 钢蓝爵士 → 数据中心青 → 警报红 → 回到剧院绯红和金。
8. **主角够大**：副歌和舞蹈镜头里主角约占画面高度 40%。
9. **用子代理并行做章节**：先写 `ANIMATION_GUIDE.md` 给每个子代理当共同的规范（共享文件只读、私有 helper 包在 IIFE 里、每帧只由 t 决定、检查方式）。

## 在本仓库怎么用

- 写口播片时把“字少”翻译成：**上屏字只放观众要“看”的东西**（一个数字、一个名字、一句原话），不放复述口播的标题；解释交给画面里发生的事。
- 章节多的片子：先写一份共同规范，再分镜头制作。
