# motion-video-kit（echris6/motion-video-kit）：独立评审循环 + 质量线

> 2026-10-30 读。约 1.2k 星，MIT。文档和脚本原文固定在 `prompt-library/vendor/echris6__motion-video-kit/e4b1c00/`。原仓库：https://github.com/echris6/motion-video-kit

## 一句话

“做的人不给自己打分”：每一轮都交给一个**新的**评审，只给它成片、简报、客户原话和参考，不给它我们的思路；下一轮再换一个新评审逐条核对上一轮的问题（已修 / 部分 / 还在）+ 找新问题，最后给 SHIP 或“再来一轮（最多 3 条）”。

## 和我们的流程对照

| 它的 | 我们的 | 差距 / 建议 |
|---|---|---|
| 全片评审（每 0.2 秒一张接触表 + 每个转场前后 1/30 秒的密帧，算帧差找冻结段，ebur128 量响度） | `jury.mjs` 评审包 + `评审表.md` | 我们只有一轮。**加“核对轮”**：下一版把上一轮报告一起给新评审，逐条判已修 / 部分 / 还在（模板在 `vendor/…/critic-prompts.md` 的 Verification critic） |
| 冻结时间：全片低于阈值的时间每 30 秒 ≤ 约 1 秒，除落版外单段停 ≤ 0.6 秒 | `richness.mjs`：> 2 秒不动才警告 | 我们的阈值宽了 3 倍；但 onetake 说“静是让爆发落地的”——两边折中：**静要是设计出来的**（分镜里写“停”），没写的静 > 0.6 秒报出来 |
| 响度：激昂片 −14 LUFS、安静片约 −16，真峰值 ≤ −1 dBFS；激昂片响度范围 ≥ 3 LU（一堵平的声墙听起来像素材库） | 渲染统一 `loudnorm=I=-15:TP=-1.5:LRA=11` | 响度和峰值够了；**没量响度范围**——配乐有没有起伏可以在 `generate-score.py` 预听时打印 LRA |
| 音效比配乐在自己的频段里高约 4 dB；2–8 kHz 的咔哒声高出 10 dB 以上会刺耳 | 音效按经验放 | 可以加到 `音效.md` 当一条检查 |
| 客户抓到、评审没抓到的：交叉淡化中途的**字压字**、和数值矛盾的状态标签、主角的动作听不见 | `scan.mjs` 只看定住的帧 | `scan.mjs` / 评审包里加“转场前后密帧”一项 |
| 第 0 帧是完成的构图，不是揭开的过程 | hooks.md 已有 | 一致 |
| 主体在要紧的拍子里占可用画面 60–85 % | 经验.md 一直在说“主体太小” | 可写进 `评审表.md` 的画面项 |
| “不是 bug”≠“好”：干净但空、慢、基础的照样被退 | 一致 | — |

## 落点

1. ✅ 2026-10-30 `jury.mjs --previous=<上一轮报告>`：评审包带“核对轮”一节（逐条已修 / 部分 / 还在，SHIP 或再来一轮）。
2. ✅ 2026-10-30 `richness.mjs` 列出每段 > 0.6 秒的静止和每 30 秒冻结总时长（目标 ≤ 约 1 秒；分镜写了“停”的不算问题）。实测：suanli（8 分）0 秒，mistral（telestrator 定格多）16.6 秒。
