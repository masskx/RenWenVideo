## 为什么值得看

它的六支片被它的用户退过的原话，和我们的用户说过的几乎一样：「PPT 式一个一个展示」「依然是 ppt」「美术挺棒但没看出来啥意思」「就缺灵动的跟踪运镜」。它把“为什么像 PPT”拆成了两半，并且各有一个能量出来的数：

1. **节奏（rhythm）**：镜头长度一样长 = 节拍器 = 幻灯片。
   - 镜头长度的变异系数 ≥ 0.25（0.25 秒的字挨着 2.5 秒的停）。
   - 至少 25 % 的帧是“死静”的，至少一段 ≥ 1 秒的静；**静是让爆发落地的东西**，画面不能一直在动。
   - 有“连击”时：1.5 秒内 ≥ 3 个大变化，而且不是匀速出现。
   - 连续两个镜头不要用同一种方式结束（弹出 / 模糊出 / 硬切轮着来）。
2. **承接（carry）**：节奏全对仍然被退——因为**每一拍替换了上一拍**。被接受的版本里，每个段落边界都有一个东西活过去、并且动着变成下一拍（按下去的按钮变成结果；舞台从主角身上打开；镜头推进卡片直到它就是下一场；一群元素收拢成落版）。
   - 它的探针给每个边界打分：**承接**（有东西活过去并移动 ≥ 对角线 2 % 或缩放 ≥ 10 %）= 1，**锚定**（只有一个大而不动的东西留着）= 0.5，**裸切** = 0。分数 < 0.5 判不过，< 0.7 警告。
   - 实测：被退的版本 0.00、0.40，被接受的 0.56、0.75；**节奏的各项指标分不开这几版，只有承接分得开**。
   - 裸切只用在连击和落版。“淡出 / 滑入两个不相关的场景”不算承接。

## 其他能直接用的

- **三个不同的“中心画面点子”再选**（一个元素贯穿变形 / 一个镜头穿过尺度 / 前后对比分屏 / 连锁反应），不是同一组卡片讲三遍——和 lemo 的“三个候选结构”一致，但它要求三个点子**在画面上**不同。
- **先拆参考片再动手**：能量图（什么时候动）、硬切位置、静止比例、动作曲线（t80：动作走完 80 % 用了多少时间——急停还是 S 曲线）。“看一遍看不出来”的东西用数量出来。
- **原因要看得见**：页面自己在动 = 屏保；要有一只手（光标路径）或主角造成每个反应。
- **镜头是“操作出来”的**：跟拍时关键帧比主体早约 0.1 秒、急甩前先把落点定好、停的时候手持微晃归零、落地时一个小震。
- **快动作要快门模糊**：一帧超过 80 px 的位移不加运动模糊会抖成几份残影；CSS blur 不是解法，要在一个快门角度内多次取样再平均。
- **声音是“一个房间里的一套材质”**，不是每个事件一个合成音；事件比拍子少。
- **网页渲染的速度**：截图约 150 ms 一张，开多个浏览器进程并行（核数 − 2，最多 8）；长渲染前先告诉用户预计时间。
