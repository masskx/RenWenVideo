# pdoom-video：一支全代码歌词 MV 的完整工程

> 仓库 mexicat/pdoom-video（MIT；歌曲和歌词不属于作者，本仓库没有复制）。文档 `../prompt-library/vendor/mexicat__pdoom-video/fa164b7/docs/`（TREATMENT、ENGINE），渲染器和场景源码 `../prompt-library/code/mexicat__pdoom-video/fa164b7/app/src/`。2026-10-23 读。

## 它是什么

一首歌的 MV，TypeScript + three.js 网页渲染，每帧只由歌曲时间 t 决定，可以出 4K60。最强的不是技术，是 **treatment**（`docs/TREATMENT.md`）。

## 最值得学的

1. **一个统一的设定**：整片是“一本讲世界末日的插图论文里的图版”。每个图版有**自己的视觉语言**（版画、示波器、官僚表格、钞票纹、蓝图、光线步进 3D、织物、界面），所以片子经常换样子；但**共用一套配色、一套字体、一种颗粒和同一种冷幽默**，所以是一部片。→ 本仓库的“账号层 + 单片风格层”就是这个结构（[账号风格.md](../账号风格.md)）。
2. **一条贯穿的母题**：一个拖着线的橙色火花。它写出第一句歌词、画出 loss 曲线、变成股价、弯成第一个回形针、被揭示是导火索、最后引爆。→ 每支片挑一个能“变形”的物件贯穿。
3. **视觉双关和变形，不做字面插图**：每句词配一个具体的、只属于这句的画面点子（“sudden drop” = loss 曲线断崖、镜头跟着坠进等高线地形；“backward” = 字从右往左排成镜像）。→ 我们以前每句只是“一块面板写字”，这是最大的差距。
4. **数字在世界里演**：P(doom) 不放在角落，每个图版用自己的方式出现（等高线标注、示波器读数、表格栏、电子邮件里的一行），副歌时撑满全屏滚到新值。
5. **字是画面的一部分**：每个图版用不同方式“写”出歌词（火花写出来、沿曲线走、像 token 打出来、盖章、织进布里、被 [MASK] 遮住）；卡拉 OK 规则：每个词在它开始时亮起、结束前亮完，可提前约 0.4 s 淡显整句，高亮绝不抢在声音前。→ 我们的逐字时间戳完全能驱动这种字。
6. **明暗节奏**：有的图版反成米白纸 + 墨线（官僚、蓝图、图表），全片有强烈的明暗交替；信号色在两种底上都不变。
7. **反“AI 糊”清单**：不要紫青霓虹、发光大脑、矩阵代码雨、镜头光晕、通用粒子星云、库存“AI”图；任何看起来像 AI 生成的东西都不要。
8. **工程做法**（`docs/ENGINE.md`）：剪辑点锚定在歌词上、对齐拍子（`timeline.ts` 的 `cut()`：在句首前最后一拍切）；**按内容找歌词，不在场景里写死时间**（`lyrics.get('sudden drop')`）；后期只让信号色发光（bloom）、加光晕、色差、颗粒、暗角；动态模糊用子帧平均（自适应采样）；硬切落在强拍上。

## 在本仓库怎么用

- treatment 照它的格式写：一段话的设定 → 语气 → 配色 → 字体 → 字的规则 → 母题 → 逐场景（每场一个具体点子）。
- 剪辑点：我们的 `{a}` 卡点就是它的歌词锚点；场景切换放在句首。
- 后期“只让信号色发光 + 颗粒”可以作为账号层的统一质感。

## 不要学的

- 歌曲、歌词、它自己的形象（面具、shoggoth）；为 4K60 做的重型优化（竖屏短视频用不上）。
