# lemo-opuscar：51 种风格 + 一套导演方法

> 仓库 lemomo-ai/lemo-opuscar（代码和文档 MIT；样片、poster 为 CC BY 4.0，署名 LemoLab）。本仓库的快照：文档 `../prompt-library/vendor/lemomo-ai__lemo-opuscar/3961ddb/`，引擎和样片源码、poster `../prompt-library/code/lemomo-ai__lemo-opuscar/3961ddb/`。2026-10-23 读。

## 它是什么

一个“挑一种风格 + 给一个题目 → 一支纯代码短片”的库。51 种风格，每种有一份风格圣经 `styles/<slug>/STYLE.md`、一支样片的完整工程 `styles/<slug>/demo/`（页面 + 时间轴 + 配乐 + 混音）和一张 poster。外加两份通用方法：`DIRECTOR.md`（怎么导）、`TECHNIQUE.md`（怎么造）。

知识类可直接选的风格（poster 拼图：[lemo-知识类风格.jpg](lemo-知识类风格.jpg)）：`briefing-board`（工程白板）、`dataviz`、`data-physical`（数据做成实物）、`archive-lighttable`（档案灯台，原始照片 + 标注）、`halftone-dossier`（网点档案）、`living-screencast`（录屏活起来）、`swiss-motion`、`whiteboard`、`teardown`（拆解爆炸图）、`iso-infographic`、`satellite-briefing`、`ascii-crt`、`hologram-hud`、`dark-keynote`、`one-line`、`pictogram-motion`、`microscope`、`risograph`。

## 最值得学的（按影响排）

1. **导演方法**（`DIRECTOR.md`）。成片按“声音、节奏、镜头、导演”评判，好看的画面只是起点。
   - 先选**对标作品**（为这个题目选，不借样片的），写“学什么 / 不拿什么”。对质量的提升大于任何规则。
   - **一个主体、一个目标、一个转折**；钩子 3 秒内；结尾呼应开头；**一个只有这个媒介能做的“原生招式”**放在情绪高点。
   - 动手前写 treatment：**三个候选结构**再选一个（第一个想到的通常是风格的套路）；logline + 起承转合；**镜头表写清景别、角度、运镜、时长和“为什么这样拍”**；逐秒节拍；卡点表；声音设计表；字幕和标题设计（字是风格的一部分）。
   - **先证明画面**：用真代码出 3 张风格帧（其中一张是招牌镜头），对照 STYLE.md 检查，再做全片。
   - 声音是一半：每个看得见的动作都有声音；三层（环境、拟音、音乐）；高潮前至少两次真正的安静；至少两次用声音做转场（J-cut / L-cut）。
   - 节奏：快慢交替，有一次明显加速或减速，给观众一口气；字幕至少停 1.8 s 且 ≥ 口播 + 0.6 s；中文上屏字停留 ≈ 字数 ÷ 4.5 + 1.5 s。
   - 镜头：至少四种不同运镜和真实的景别变化；**一个让人记住的招牌镜头**；转场在媒介内部完成（翻页、墨晕、刻线生长），不用默认淡入淡出；关键时刻主体至少占画面高度 1/3。
   - 交付前“**不要又做成样片**”：结构、开场、招牌镜头、镜头路线、配乐形状、结尾六项至少四项不同。
2. **风格圣经的写法**（`styles/*/STYLE.md`，以 `swiss-motion` 为例）。每份都有：本质和“它不是什么”、材质与渲染、配色逻辑（一个信号色、它属于谁）、字体与字幕（**字幕是版式的一部分，不是底部一条**）、动效质量（**只用两条曲线**，入场是擦除 / 裁切显现，从不淡入；删除是“刀切”）、**镜头语法表**（每种运镜表达什么、能服务什么内容）、声音调色板（按材质配拟音）、**原生招式菜单**（每招“适合什么内容”）、媒介的坑、变化空间（结构、开场、结尾的备选）。这就是本仓库“风格”应有的深度。
3. **技术路线**（`TECHNIQUE.md`、`core/`）：一个时间轴驱动画面、配音、配乐、拟音、字幕；画面是 `render(t)` 的网页，无头 Chrome 逐帧截图（JPEG 截图、一 worker 一浏览器、颗粒在 ffmpeg 里加）；`readcheck.mjs` 检查每段上屏字停够时间；`cuecheck.py` 检查每个画面卡点和音乐对齐（目标 0 ms）；“**一个世界 → 屏幕的函数**”，跟随主体的效果（光圈、推近、聚光）都走它，不手写屏幕坐标。
4. **竖屏可用**：渲染工具都有 `--size 1080x1920`，页面按 `innerWidth × innerHeight` 排版。

## 在本仓库怎么用

- 每支片按题材从上面的清单挑 1 种风格，**读完整份 STYLE.md**，再按 [导演方法.md](../导演方法.md) 写 treatment。对照 poster 和 `demo/` 源码看它怎么实现（例如 `swiss-motion/demo/film.js` 的裁切显现、刀切、栅格重排）。
- 画面可以直接写成网页（`scripts/page-render.mjs` 渲染），也可以把招式移植成 Remotion 组件。
- 配音仍用用户的复刻音色（不用它的 edge-tts / Kokoro），字幕用我们的逐字时间戳。

## 不要学的

- 16:9 构图照搬到 9:16；它的英文旁白节奏（英文字数换算不适用中文）。
- 样片本身（“不要又做成样片”是它自己的规则）；任何现实品牌、角色、旋律。
