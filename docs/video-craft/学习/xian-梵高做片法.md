## 一、它为什么好看（看截图就能看出来）

《梵高：活着只卖出一幅画》横版，6 张截图（在 skill 仓库的 `screenshots/`）：

- **每一句话都有一个具体的东西在发生**：画像被木板钉住、小鸡走进来（“拿去堵了鸡窝”）；三张职业卡片被“失败”章砸中变灰；600+ 封信堆成山、信纸上一行行写出字和向日葵；“怪人”被红线划掉、金色“天才”砸下来；拍卖槌落下、$82,500,000 滚到底、“当时的世界纪录”贴纸。**没有一个画面是“写着字的盒子”。**
- **字很少**：一个大数字 + 一两个贴纸 + 字幕。字幕说话，画面演事。
- **两种底交替**：夜空蓝旋涡（开场、低谷、高潮、结尾）和亚麻画布（讲事实）。底色本身就是情绪节奏。
- **视觉从题材里长出来**：梵高 → 《星月夜》的笔触 + 美术馆金画框 + 宋体大字。不是套一个“科技风”模板。

这正好是我们 cinema 片的反面（[../复盘-2026-10-23.md](../复盘-2026-10-23.md)）。

## 二、文章里能直接用的东西

### 原理

Claude 不画画，它写“画画的程序”：一秒 = 30 帧 = 30 张网页截图。好处：每个像素可控（中文不糊）、能反复改、能批量、版权干净。——这就是本仓库的两条路：Remotion，和 `scripts/page-render.mjs`（任意网页逐帧渲）。

### 4 条技术路线（我们怎么对应）

| 路线 | 文章里的工具 | 本仓库 |
|---|---|---|
| ① 代码生成视频 | Remotion（+ 官方 skills）、HyperFrames（HTML + GSAP）、Manim、Motion Canvas | Remotion 主线；HTML + GSAP 走 huashu-motion 的模板 + `page-render.mjs`（同一个“暂停的 GSAP 时间轴”约定，见 [../huashu-motion.md](../huashu-motion.md)） |
| ② 网页即动画 | p5.js、Three.js、SVG、Anthropic algorithmic-art | `page-render.mjs`（Canvas / WebGL / three.js / p5 都行） |
| ③ 让 Claude 操作专业软件 | Blender MCP、After Effects MCP、Lottie | 暂不接（容器里没有这些软件）；文章自己也说“Blender MCP 擅长操作不擅长审美” |
| ④ 混合编排 | AI 生成素材（数字人、插画）+ 代码组装 | `scripts/generate-tutorial-images.mjs` + `<Plate>`，只在缺素材时用（[../导演方法.md](../导演方法.md) §一） |

### 11 种风格（选风格时当菜单）

产品发布片 / UI 动效；动态排版；数据信息图；3Blue1Brown 式数学；**科普信息图卡片**（方格纸、粗描边卡片、歪贴纸、手绘红圈、大字幕、章节进度条——文章说这是抖音 / 视频号 / 小红书知识口播最常见的样子）；艺术笔触 / 名画；生成艺术；3D 场景；角色 / 吉祥物；纸质拼贴 / 复古；白板手绘。
**心得：别只用一种风格。** 梵高那集是“艺术笔触 + 动态排版 + 纸质拼贴 + 白板手绘”的混合，所以不像模板。

### 案例

- 国内做得好的：meng shao「AI 启蒙小伙伴」（Remotion Skills，视频号单条 8 万观看、4 千转发）；每条结构 **Hook → Why → Process → Essence → Tips → End Card，每段 4–8 秒，总长 1 分钟以内**。
- 宝玉：JS + Canvas 画手绘卡通风教学视频。

### 素材从哪来

① 代码画（零版权）；② 公有领域名画 / 老照片（维基共享、大都会 Open Access、芝加哥艺术博物馆 Public Domain、荷兰国立博物馆；**要确认是公有领域 / CC0**）；③ AI 生成（同一角色前后不一致，商用看条款）；④ 配音配完用 Whisper 转回文字核对；⑤ 音效：Pixabay、Freesound（看每个文件的授权），或代码合成；⑥ 字体：系统字体不一定能商用，用思源宋体 / 黑体。

### 提示词的 5 个要素 + 分步

背景、内容、视觉风格、时间节奏、约束；**先确认分镜，再做动画，最后配音和音效，不要一次生成完整作品。** ——对应我们的“先写导演一节和镜头表 → 先证明画面 → 再做全片”。

### 8 步做片法（梵高那条）

1. **选题：冷知识 + 巨大反差**（活着只卖出一幅画，死后一幅一亿美元）。开场不讲“梵高是谁”，先讲一个荒诞的冷知识。
2. **按情绪曲线写**：钩子 → 困境 → 温暖 → 跌落 → 反问翻转 → 谷底 → 大反转 → 金句。
3. **配音 + 逐字核对**：数字写成读音；配完转回文字比对。
4. **定视觉：从题材里长出来。**
5. **一句一画（决定炫不炫）**：说到“全都失败了”，三张卡片上的“失败”章依次砸下；说到“疯子变成了天才”，“疯子”被红线划掉、金色“天才”砸下；说到“八千二百五十万美元”，拍卖槌落下、价格滚到底。
6. **截帧质检**：每段截一帧拼成总览，查重叠、遮挡、空画面。
7. **选封面帧放片头**：挑最丰富、没有字幕的一帧放开头 0.5 秒。
8. **多平台出片**；发国内平台前查敏感词。

### 让动画“看起来很贵”的 6 条

1. 一句话一个画面：纯文字静止不超过 2 秒。
2. 具体代替抽象：用道具代替人（两把椅子抖动 = 两个人吵架），用数字代替形容词。
3. 底色就是情绪：低谷和高潮用深色，讲事实用浅色。
4. 视觉从题材长出来：不同题材，不同视觉语言。
5. 一个画面一个主角：周围最多 1–2 个贴纸。
6. 高潮多停 2 秒：让观众看清，也正好当封面。

### 踩坑

第一次渲染基本不会完美，正常做 2–3 轮；提示词太空泛出来就是模板感，一定写清风格、颜色、节奏；中文字体、竖屏尺寸国外教程不讲，要自己调。

## 三、skill 仓库里的做法（读过，没拷）

- **招式库**（`references/recipes.md`）：按叙事位置分组——开场钩子（年份倒拨、名画现场画出、反差大数字 + 碎片、签名写出、千里挑一点阵、冷知识道具）、讲经历（年龄尺、卡片 + 盖章、作品墙褪色、翻日历、大问号揭晓）、关系 / 过程（寄信飞线、信件堆积、写信、引言打字 + 高亮、天平、地图钉、翻书、年份进度）、冲突 / 低谷 / 高潮（两把椅子吵架、红闪 + 裂纹、请愿书签名、铁窗 → 名画、反问 + 盖章否定、生命线、吊牌价签）、反转（字被风吹散、删除线反转、信封聚成画像、拍卖槌、博物馆聚光）、结尾（星座、≠ 对比 → 金句逐字、回信互动）。
- **零件**（`template/kit.tsx`）：大字、等宽注释、歪贴纸、印章、删除线、逐字出现、签名、画框、纸、卡片、信封、星、手绘红圈、贝塞尔飞行、手写字迹、价签、进度条、碎片、两种底。
- **时间**：`at('段id', 第几句, 句内比例)` 把动作卡到旁白的某个词；`pop`（弹出）/ `ramp`（渐变）。——我们的 `{a}` 卡点 + `cue('a')` 是同一个思路，精度到字。
- **工序脚本**：截样片（一次打包截多帧）、每段 85% 处一帧拼封面候选总览、带封面帧渲染、英文句数核对。
- **视觉规则**：字号层级（大字 90–250 > 贴纸 40–60 > 注释 22–30）；音效卡点（盖章、揭晓、数字滚动、高潮、低谷、翻页、划掉，音量 0.3–0.55）；舞台安全区；滑出画面要滑够远。
- **敏感词软化**（发抖音 / 小红书前）：自残、自杀、精神疾病的直白说法改软（“割下耳朵”→“弄伤耳朵”，“自杀”→“离开了这个世界”，“疯子”→“怪人”，“精神病院”→“疗养院”），画面上的字同步改。已并入 [../平台与合规.md](../平台与合规.md) §三.12。
