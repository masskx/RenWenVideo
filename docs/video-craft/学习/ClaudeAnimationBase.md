# ClaudeAnimationBase：手绘角色动画的起步包

> 仓库 JohnHeibel/ClaudeAnimationBase（MIT；Clawd 形象属于 Anthropic，商用前确认）。指南 `../prompt-library/vendor/JohnHeibel__ClaudeAnimationBase/0ac8bf2/ANIMATION_GUIDE.md`；引擎、角色、模型表 `../prompt-library/code/JohnHeibel__ClaudeAnimationBase/0ac8bf2/`（`src/core.js` 画法和时间、`src/clawd.js` 角色和 31 种表情、`docs/emotions.jpg`、`docs/views.jpg`）。2026-10-23 读。

## 它是什么

p5.brush 水彩 + 墨线的角色动画底座：一个能做 31 种表情、五个视角转身、按拍子跳舞的角色，一套 `paint()` / `inkLine()` 画法，一套审片工具（拼图、逐帧条、局部放大、跟着世界坐标的放大）。

## 最值得学的

1. **三个目标**：手作感、活着、一部片。下面每条规则都服务其中之一。
2. **时间：替观众建模**（它说这是模型最常做错的）。
   - **写 reads**：每个镜头按顺序列出观众要看懂的几件事，每件给“找到它 + 看懂它 + 记住它”的时间。
   - **一次一件**；因和果按先后，不要叠在一起。
   - **动作可以快，意义要慢**：动作有预备就能很快，意义需要停住的时间。快慢对比就是节奏。
   - **先把视线引过去**（角色看它、镜头移过去、它先动或先亮），再出重点。
   - **reads 决定镜头长短**，包括最后一个镜头。
3. **“牌子复述剧情”是经典失败**：角色举着“我迷路了”的牌子就是失败，要演出迷路（左看右看、地图拿反、一滴汗）。
4. **每个镜头必须有事件**：第一帧和最后一帧之间有东西变了；有因有果，反应常常是最好笑的部分，给够时间；埋下的东西要收回。
5. **动画原理在代码里的样子**：预备、挤压拉伸、慢入慢出、重量、弧线、跟随与重叠（眼睛先动、身体跟、配件最后停）、**避免对称复制**（两只手同角度、一群角色同步弹跳是代码的通病）、夸张、关键姿势先成立、先想再做、次要动作不抢戏。
6. **转场处处都有**：每个接缝都要转场，且挑属于故事的那种（笔刷擦除、形状光圈、甩镜带模糊、匹配剪辑、动作剪辑、跨镜运镜）；镜头内的变化（表情、转身）也是转场。
7. **审片三档放大**：拼图看整体；逐帧条看一个动作的每一帧（转身、一惊、跳、扔、转场）；局部放大看脸、手、接触点。每个镜头至少一张拼图，每个关键动作一条逐帧条，每张讲故事的脸一张放大。读拼图时问：“这一帧观众在看哪里？看懂了没有？”数每个 read 有几帧。

## 在本仓库怎么用

- 分镜里每个镜头写 reads（[导演方法.md](../导演方法.md) 的镜头表有这一列）。
- 审片照它的三档（`scripts/qa/frames.mjs` 已能出逐帧页，补局部放大）。
- 题材需要角色时（AI 翻车、拟人、轻松向），可直接用它的引擎在网页里画，用 `scripts/page-render.mjs` 渲染。

## 不要学的

- “完全不要字”：口播知识片要有字幕和关键数字，但它的原则（不复述）要守。
- 照搬 Clawd 形象。
