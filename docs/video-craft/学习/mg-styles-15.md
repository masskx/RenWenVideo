# mg-styles-15：15 种 MG 风格，每种一支 10 秒成片 + 提示词 + 源码 + 评审

> 仓库 Vincentwei1021/mg-styles-15（MIT；字体文件不在仓库）。提示词、模板、评审 `../prompt-library/vendor/Vincentwei1021__mg-styles-15/49052d8/`；15 支样片源码、渲染 harness、成片缩略图 `../prompt-library/code/Vincentwei1021__mg-styles-15/49052d8/`。抽帧拼图：[mg15-成片抽帧.jpg](mg15-成片抽帧.jpg)。2026-10-23 读，并用本仓库的 `scripts/page-render.mjs` 跑通了它的竖屏样片 `18-hanazi`。

## 它是什么

每种风格一份完整提示词（`prompts/*.md`：风格、输出规格、技术路线、创意种子、**风格特征和关键技法**、工作方法、规则、工艺清单、自评）、一支成片的全部源码（`demos/<slug>/index.html` 定义 `window.renderAt(t)`）、一份写新风格的模板（`template.md`）、一份让另一个 AI 当评委的评审提示词（`rubric.md`）。每支片都“制作 → 独立评审 → 按评审修改 → 再评审”改了两轮，评委终评 7.57–8.21 / 10。

## 最值得学的

1. **风格特征写成可检验的技法**（`template.md`）：不写“动效要有弹性”，写“overshoot 用 cubic-bezier(0.34,1.56,0.64,1)，错峰 2–4 帧”；每条特征对到片中一个时刻。
2. **工作方法**（每份提示词的 How to work）：先 treatment（0.5 秒内的钩子，开场空黑不超过 0.3 秒；一次升级；约 60–75 % 处一个不会认错的高光时刻；结尾构图停 0.8–1.2 秒且有微动）→ **先出 6–10 张关键帧、每张都要能当海报** → 再做动效（逐帧看最快的动作：间距、缓动、弧线、重叠、预备、跟随、动态模糊）→ 声音锁在同一张卡点表上 → 终检 → 写诚实的自评（最强、最弱、多给时间会改什么）。
3. **独立评审**（`rubric.md`）：另开一个 AI 当评委，不是做片的那个；按七项打分（风格忠实、概念惊艳、动效工艺、设计与字体、完成度与质感、声音与同步、技术），**5 = 学生作业，6 = 模板水平，7 = 扎实专业，8 = 高端机构**，“多数初版应在 5–7，不许虚高”；给 5–10 条按影响排序的修改，每条带时间码、可观察的问题、为什么、具体做法（曲线、帧数、像素、颜色）；至少一条提升“惊艳”而不只是打磨；看起来通用 / AI 模板、中文不自然、回退字体或豆腐块都算严重问题。然后回到做片的会话按评审改一轮。
4. **一切皆代码，包括声音**：每支片的 `audio.py` 合成配乐和音效，读同一份 `cues.json`。

## 在本仓库怎么用

- 知识类口播片的默认参考是 `19-paperclip` 的做法（大画布 + 贴纸化素材 + 精确图表 + 逐句新元素 + 图形匹配转场），竖屏重排。
- 有照片素材时参考 `18-hanazi` 的贴纸化 / 包装手法（换成账号自己的克制版本，见 [账号风格.md](../账号风格.md)）。
- 每支片交付前用 `rubric.md` 的评委提示词做一轮独立评审（[导演方法.md](../导演方法.md) §审片）。
- 源码可直接用 `scripts/page-render.mjs` 渲染来看（`--root` 指向含素材的克隆；缺的字体会回退到 Noto Sans CJK）。

## 不要学的

- 10 秒 / 16:9 的规格；它为评奖做的“品牌名”虚构（我们讲真事）；综艺花字的吵闹程度（账号要克制，只借手法）。
