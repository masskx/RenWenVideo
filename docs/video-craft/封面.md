# 封面：先定锚点，再分层摆，缩到 80 像素还要看得懂

> 2026-10-17 加入。来源：Lonely__MH 的文章《封面微调太折磨？自制封面工具正式开源！3 秒指哪改哪》（https://x.com/Lonely__MH/status/2111108574378369504 ），介绍他做的 Cover Studio（https://cover.aigce.com/ ），以及它引用的两套封面方法：ponyodong2026 的 *Ponyo 封面锚点系统*（公开仓库）和 Adrian Punk 的 *Punk-Skill*（版权保留，只学原则，不抄文字和素材）。
> 用户的要求：**不做新片，把里面的好想法用到我们的做片流程里。** 这份文件就是结论。

## 〇、这套方法里值得学的五件事

| 想法 | 原文怎么做 | 我们怎么用 |
|---|---|---|
| **封面是分层的，改一层不重画** | Cover Studio 先用 Ming-Image-0.1-Design 出一张封面，再用 Ming-Image-0.1-Design-Layer 拆成文字 / 人物主体 / 装饰 / 背景几层（被挡住的地方会补全），之后每层单独移动、缩放、隐藏、调前后，最后导出，不用为了挪一个字重新生成整张 | 我们的封面本来就是代码画的（`TutorialCover`），天生分层。把标题、锚点、标签、背景做成**各自的参数**，调整只改参数，不改场景代码（§四） |
| **3 秒决定点不点** | 封面只解决一件事：在信息流里 3 秒内让人决定点开。两个变量：**信息密度**（缩略图里看得出“看了有什么用”）和**视觉锚点**（眼睛第一下落在哪） | 封面卡写清这两项（§一） |
| **按内容类型选模板** | 知识 / 观点 → 冲突型；干货 / 教程 → 数字型；案例 / 对比 → 截图（对比）型；情感 → 情绪型 | 模板从选题卡推出来，不靠感觉（§二） |
| **缩略图测试** | 标题在 80 像素宽的缩略图里还能认出来；文字对比度至少 4.5:1，缩略图里争取 7:1 | `scripts/qa/cover.mjs` 出 80 / 160 / 360 像素的缩略图拼图，人眼看（§五） |
| **换比例要重排，不加黑边** | 换画幅时重新定断行、位置、占比；不拉伸、不加黑边、不机械缩放；新画布要填满 | 3:4、6:7、9:16 三张封面各排一遍，不能都从一张 9:16 裁出来（§四·二） |

## 一、封面卡（写进分镜，`## 封面卡`，和选题卡放在一起）

| 项 | 写什么 | 规则 |
|---|---|---|
| 模板 | 数字型 / 冲突型 / 对比型 / 情绪型 | 按 §二 从选题卡推 |
| 封面标题 | **单独写**，不等于视频标题，也不等于第一句口播 | 字数按 §三；从观众的好处出发；必须是真的 |
| 锚点 | 眼睛第一下落在哪：一个巨大数字、一个主体物、一组对比、一个关键词 | **只有一个**；占画面高的 30%–40% |
| 辅助句 | 可选，一句，补充标题没说的（结果、范围、对象） | 占文字分量的 20%–30% |
| 标签 | 可选，左上角小字：栏目名、系列、“教程”之类 | 占文字分量的 5%–10%；不放唯一的关键承诺 |
| 颜色 | 字色 / 底色（十六进制）+ 至多一个强调色 | 对比度 ≥ 4.5:1，标题争取 ≥ 7:1；沿用全片的 A/B 色 |
| 冒充检查 | 有没有假 logo、假数据、假截图、真人肖像 | 一项都不许有（发布规则和导演层都禁止） |

写法示例见 §六。

## 二、四种模板（锚点放哪、标题多长）

| 模板 | 适合的内容 | 锚点 | 标题字数（中文） | 例子（句式） |
|---|---|---|---|---|
| **数字型** | 干货、教程、清单、路线、“N 步” | 一个巨大的数字（或数字 + 单位），高度占画面 30%–40% | 数字 + 4–10 字 | “5 个项目”“3 步搭好” |
| **冲突型** | 知识、观点、反常识、“你可能做错了” | 主体物（不是真人脸）+ 标题放在反差色块上 | 6–12 字 | “不要再……”“先别……”“……其实是错的” |
| **对比型**（原文叫截图型） | 案例、改前改后、A 和 B | 左右或上下两块，中间一道清楚的分界 | 8–14 字 | “改前 VS 改后”“……这样用” |
| **情绪型** | 故事、感受、现象 | 一个有情绪的画面或物件 | 4–10 字，最多 8 字更好 | 一句话，像一声感叹 |

- 标题超过 16 个字一律拆：主标题 + 辅助句。
- 断行按意思断，不按字数断（“Agent / 工程师路线图”可以，“Agent 工程 / 师路线图”不行）。
- 原文的模板举的是“人脸 + 标题”。**我们不用真人肖像**（导演层），人脸的位置换成片子里的主体（机器、模块、那张“卡片”），或者巨大的数字、关键词。
- 句式（“不要再……”“N 个……”）是起点，不是套话：内容不支持就不用；不许夸大，不许写视频里没有的承诺。

## 三、位置、层级和颜色

- **标题在上三分之一**，锚点在中间，标签在左上；**右下角不放要紧的东西**（视频号界面和角标多在那里）。
- 文字分量：主标题 60%–75%，辅助句 20%–30%，标签 5%–10%。**全封面文字不超过三层**：页眉、镜头里的小标注、刻度数字这些视频里的东西，封面上要么删掉，要么压到看不见的程度。
- 字号按短边 S（= min(宽, 高)）定，起稿参考：主标题字身 11%–21% S（1080 宽约 120–230 px）；短词冲击字可以到 25%–38% S；标签 2%–6% S。比视频里的字大得多，这是对的：封面是在缩略图里看的。
- 颜色：底色 + 字色 + **最多一个强调色**（就是这部片子的 A 或 B 色）。科技题材用蓝图 / 黑底科技的色板（`发布与风格偏好.md` 二）。不用没有光源的辉光、霓虹描边（导演层禁止项照样适用）。
- 字效只用一套：描边或底托二选一，辅助字不叠效果。
- 四边留白：先试短边的 4%–6%；字、主体、数字都不贴边。视频号个人主页还会再裁一次，所以标题尽量放在中间区域。

## 四、做法：把封面当成分层的设计稿

### 4.1 现在的做法和问题

`TutorialCover` 是“冻结某个场景的最后一帧 + 底部写 `subtitle`”，再由 `render-tutorial.mjs` 从这张 9:16 图里**裁出** 3:4 和 6:7。问题（`agent-engineer-roadmap` 的封面，§六有完整的诊断）：

1. 画面里的所有字都被带上了封面：页眉、阶段标签、FIG 编号、刻度。文字层太多，没有一个锚点。
2. 标题在底部，16 个字两行，在缩略图里是最晚被看到的位置。
3. 三个比例都是裁出来的，不是排出来的：3:4 里标题贴着下边，6:7 里差点被裁掉。

### 4.2 以后的做法（下一部片子开始，做到 `TutorialCover` 里）

封面按四层来做，每层都是配置里的参数，**调封面只改配置，不改场景代码、不重渲染视频**：

| 层 | 内容 | 来源 |
|---|---|---|
| 背景 | 主题色板的底 + 网格 / 纸纹，降低对比，不抢 | 主题 |
| 锚点 | 巨大数字、主体物（从场景里拿一个组件，不拿整幅画面）、对比的两块 | 封面卡的“锚点” |
| 文字 | 主标题、辅助句 | 封面卡 |
| 标签 | 左上角小字 + 作者署名（原作者署名照样要有，放小） | 封面卡 |

配置的样子（**已实现**，2026-10-17，第一部用它的片子是 `anatomy-explain`；类型在 `src/tutorial/types.ts` 的 `CoverCard`，组件 `TutorialCoverCard`，三个合成 `TutorialCover34 / 67 / 916`；`render-tutorial.mjs` 发现 `coverCard` 就按三个比例各渲染一张，不再从 9:16 裁；只出封面用 `--cover-only`）：

```json
"coverCard": {
  "template": "conflict",
  "headline": ["会动，", "不等于看懂"],
  "support": "AI 做科普视频的一条规矩",
  "tag": "ANATOMY · 素材：数字生命卡兹克",
  "anchor": "an.cover",
  "layouts": {
    "3:4":  {"headline": [80, 150], "size": 132, "anchor": [540, 730, 0.95], "support": 1230},
    "6:7":  {"headline": [80, 110], "size": 120, "anchor": [540, 560, 0.75], "support": 1010},
    "9:16": {"headline": [80, 380], "size": 132, "anchor": [540, 955, 0.95], "support": 1400}
  }
}
```

- `headline` 一到两行，最后一行用 A 色；`tag` 是左上小字（把原作者署名放这里）；`support` 居中。
- `anchor` 是场景注册表里的一个“封面用”主体组件（例如 `an.cover` 只画静止的机芯，不画标签和标题），不是冻结整个镜头；`layouts.*.anchor` 写的是舞台中心 (440, 400) 落在哪、缩放多少。
- `layouts` 里每个比例单独给坐标和大小，**三个比例各排一次**（下一节）。
- 在 Remotion Studio 里打开 `TutorialCover` 调参数，看着改，一个参数一个参数地挪，就是 Cover Studio“指哪改哪”的做法。

### 4.3 换比例：重排，不裁、不加黑边

| 比例 | 用在哪 | 排法 |
|---|---|---|
| 3:4（1080×1440） | 视频号封面（当前做法） | 标题在上，锚点居中偏下，辅助句在锚点下方 |
| 6:7（1080×1260） | 信息流里的显示区域 | 比 3:4 矮：标题和锚点靠得更紧，锚点小一点，辅助句可以删 |
| 9:16（1080×1920） | 点开后全屏、备用 | 不要把字和锚点无限放大；多出来的高度给背景和留白，要紧的东西仍在中间 6:7 带里 |

每个比例都过一遍 §五 的缩略图测试。

### 4.4 AI 插图封面（讲解片管线，可选）

讲解片（`explainers/`）的画面是 `gpt-image-2` 生成的。想用 AI 出封面时，按原文的经验：

- **生成前先把标题文字定稿**：AI 画进图里的字拆层后就是图片，改不了；能不让 AI 写字就不让——字由我们在上层排。
- 拆层模型可能把两个元素合成一层；放大不会增加细节；换比例会出黑边，要重新排。
- 原文用的是 inclusionAI 的 Ming-Image-0.1-Design（出图）和 Ming-Image-0.1-Design-Layer（拆层），6B 参数，开源。我们没有它们的接口和 key，**现在不接**；用 `gpt-image-2` 只出“没有字的主体 / 背景”，文字和锚点仍由代码排，效果相当于自带分层。

## 五、检查（封面不是截一帧了事）

```bash
node scripts/qa/cover.mjs <id>     # 检查封面卡字段、标题字数、颜色对比度；把封面缩到 80 / 160 / 360 px 拼成一张图
```

然后**亲眼看**拼图（`douyin/<id>/cover-thumbs.png`），按下面十条打分，每条 0–1 分，**低于 8 分就改**，分数和扣分原因写进分镜的“静帧判断”：

1. 80 px 宽时，还认得出主标题吗？
2. 只看缩略图，知道这条片子讲什么、看了有什么用吗？
3. 有一个且只有一个锚点吗？眼睛第一下落在它上面吗？
4. 模板和内容类型对得上吗（§二）？
5. 标题字数在范围内吗？断行是按意思断的吗？
6. 文字最多三层吗？主次分量对吗（标题占大头）？
7. 标题和底色的对比够吗（≥ 4.5:1，标题争取 7:1）？
8. 除底色外最多一个强调色，和片子的 A/B 色一致吗？
9. 三个比例都是重排的，没有字贴边、被裁、加黑边吗？
10. 没有假 logo、假数据、真人肖像、夸大的承诺吗？原作者署名在吗？

## 六、例子：诊断 `agent-engineer-roadmap` 的封面（只诊断，不重做）

**现状**（`douyin/agent-engineer-roadmap/cover.jpg`）：蓝图底，上方页眉“Agent 工程师路线图 + 01–05 阶段”，中间是 5 列的阶段卡片（10 个标签），底部两行大字“面试没过，拿到一份 / Agent 工程师路线图”。

| 条目 | 分 | 问题 |
|---|---|---|
| 1 80 px 认得出标题 | 0.5 | 底部大字勉强可认，中间 10 个小标签糊成一片 |
| 2 看得出讲什么 | 1 | “Agent 工程师路线图”很清楚 |
| 3 唯一锚点 | 0 | 5 张一样大的卡片，没有一个地方先被看到 |
| 4 模板对路 | 0 | 内容是路线 / 清单，应当是数字型或冲突型，现在两者都不是 |
| 5 字数和断行 | 0.5 | 两行共 16 字，到了上限；断行是对的 |
| 6 文字层数 | 0 | 页眉、副标题、卡片、GUIDE 注释、底部标题、刻度，六层以上 |
| 7 对比度 | 1 | 浅字深底，没问题 |
| 8 颜色 | 1 | 只有青色一种强调 |
| 9 三个比例 | 0.5 | 是裁出来的；3:4 里标题压在底边 |
| 10 可信 | 1 | 没有假东西，有署名 |
| **合计** | **5.5** | 不合格 |

**按这份文件改，会是这样**（封面卡）：

- 模板：冲突型（选题卡的冲突就是一句扎心的评价）；备选数字型。
- 封面标题：“工程能力不太行？”（7 字；是面试官原话，真实），或数字型“5 个项目 / 测出你的工程能力”。
- 锚点：冲突型用一台机器（`Machine` 本体，不带标签）在中间，标题放在上方的琥珀色反差块上；数字型就是一个占画面高 35% 的“5”。
- 辅助句：“一份 Agent 工程师路线图”。
- 标签：左上“Agent 路线”；署名“路线整理：Chasen”放在小字里。
- 颜色：字 `#e8f0fa` / 底 `#0c1a2c`（对比 15.2:1）；强调 `#ffab40`（A 色）。
- 删掉：页眉、阶段卡片、GUIDE 注释、刻度数字。
