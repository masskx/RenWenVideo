# 3D：用 three.js 做“立体拆开讲”的镜头

> 用户 2026-11-04：“I would like to have a 3D feature that allows for a detailed, three-dimensional analysis and explanation.”（在做 CPU / GPU / NPU / TPU 那支科普时提出。）之前的规矩是“知识类视频 2D 优先，用户不要求就不上 3D 引擎”——这次是用户要求的，所以有了这套工具。**什么时候用**：要讲的是一个有内部结构的东西（芯片、硬件、机构、数据怎么在里面走），而且“拆开、换个角度看”能讲清楚 2D 讲不清的东西。纯概念、纯新闻还是 2D。

## 一、是什么

- `src/tutorial/three-kit.tsx`：three.js（经 `@remotion/three`、`@react-three/fiber`）做的 3D 舞台，照 lemo/teardown 的系统写（`prompt-library/vendor/lemomo-ai__lemo-opuscar/3961ddb/styles/teardown/STYLE.md`）：
  - `Stage3D`：铺满 1080 × 1920 的 3D 舞台——石墨径向底（`ground` 可换）、棚拍光（暖主光、跟着机位走的冷轮廓光 `rim`、顶光）、RoomEnvironment 环境反射（强度 0.45，太亮会把颜色洗白）、ACES 色调映射；`overlay(cam)` 画在画布上面、用同一个相机投影的标签和尺寸线。
  - 相机：`CamKey3[]`（帧、位置、看向、fov），**单调三次插值**（不冲过头，停住就是真停住）；`shiftY` 把主体在画面里上下挪（给标签 / 字幕让位，不动物体）。
  - `Label3`：teardown 标签——零件上的锚点、折一次的引线、外侧一栏的「编号（强调色）+ 名称 + 一行等宽规格」；`colX` 靠左（70）或靠右（1010），字永远朝画面里排，不出画。
  - `Dim3`：在场景透视里画的尺寸线（两端短线、深色底板上的读数，字跟着线的角度、不倒着）。
  - `ContactShadow3`：地面只剩一团柔和的接触阴影（SwiftShader 下不用阴影贴图）。
  - `MAT`：硅（深灰 + 清漆）、基板（深绿）、转接板（金属灰）、铜、金、塑料；`useDieTexture`：用色块画芯片版图贴到顶面（可发光）；`explode`：分层分离（上层先走、错开、长停稳）。
- 第一支用它的片子：`src/tutorial/scenes/chips-cpu-gpu-npu-tpu.tsx`（CPU / GPU / NPU / TPU 封装、HBM 16 层堆叠、TPU 脉动阵列、同比例的内存总线）。
- 试镜：`npx remotion still src/index.ts SceneLab qa/lab/x.png --frame=60 --gl=swangle --props='{"visual":"chip.bus"}'`（`host` / `pk` 参数可以叠上主持人小窗看位置）；冒烟测试 `ThreeLab`。

## 二、渲染

- 云容器里没有 GPU：WebGL 走 SwiftShader（`--gl=swangle`；`angle` 在这里渲不出来）。配置里写 `"render3d": true`，`tutorial:render` 会自动带上（`REMOTION_GL` 可覆盖）。
- 速度：4 核下一张静帧约 10 秒（含打包）；整支 60 秒片子约一小时。几何保持简单（实例化网格、少量灯、不做后期泛光 / 景深），一个场景几千个物体以内。
- 比细过像素的东西（5,120 根走线）不要一根根建模：用一张按真实密度画条纹、开了 mipmap 的贴图，否则满屏摩尔纹。

## 三、规矩（teardown 的，加上我们的）

- **只上有出处的数字**；没有 CAD 时按公开尺寸 / 数量建“示意模型”，画面上一直标「示意」（teardown §2：说清楚这是模型）。不画任何公司的商标。
- 产品是画面里最亮、最饱和的东西；界面墨色两档（名称满、规格 66%）+ 一个强调色，只给“量出来的东西”。
- 每个镜头里相机都在动（慢环绕 / 推），停住的那一下是高潮；标签在相机停稳前就打开（一屏一个事实，读得完）。
- 竖屏：先按 9:16 算取景——竖向 fov 30° 时横向只有约 17°，相机要比横版退远很多（宽 6 个单位的东西大约要离 20 个单位）；上下排列的两个东西放在 z 的前后，用高角度俯视。
- 字号照手机规矩：标签名 ≥ 40 px，规格 ≥ 26 px（只是补充），带信息的角标（「示意」「估算」）≥ 32 px。
- 主持人小窗要在空处（分镜里先留位置），不压在模型上。
